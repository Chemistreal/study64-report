목소리

현재 기기와 브라우저에서 실제 사용 가능한 음성만 표시합니다. 온라인 음성은 제공업체에 글이 전송될 수 있습니다. 자연스러운 AI 음성은 해당 제공업체가 지원해야 합니다.

서버 스트리밍 낭독 · 실험 기능

유튜브 뮤직처럼 서버가 준비된 음성 구간부터 공급합니다. 글 전체를 MP3로 다운로드할 필요가 없습니다. 다만 외부 서버 연결이 필요하며, 현재 연결하지 않았다면 기존 낭독 방식으로 작동합니다.

서버가 아직 연결되지 않았습니다. 원문은 동의 전까지 서버로 전송되지 않습니다.

원문은 연결한 서버와 음성 제공업체로 전송됩니다. 서버 음성은 비공식 연동을 사용하는 실험 기능이며, 무료 서비스가 재시작되면 음성 스트림이 중단될 수 있습니다.

AI 자동 백그라운드 듣기 · 실험 기능

책의 글을 AI가 기기 안에서 자동으로 MP3로 변환합니다. 최초 약 380MB 모델 다운로드와 화면을 켠 상태에서의 변환 시간이 필요합니다. 아이폰에서는 처리 속도 및 메모리 한계로 실패할 수도 있습니다. 생성 후에는 잠금 화면에서도 오디오를 재생할 수 있습니다.

AI로 생성된 음성입니다. 외부 음성 API 키는 필요하지 않습니다.

오디오 파일 직접 연결

아이폰의 일반 음성합성(TTS)은 화면 잠금이나 앱 전환 후 중단될 수 있습니다. 백그라운드 재생이 필요하다면 MP3/M4A 음성 파일을 이 글에 연결하세요. 오디오는 이 기기에 저장되며 서재 JSON 백업에는 포함되지 않습니다.

이 글에 연결된 오디오가 없습니다.

아이폰에서 잠금 화면 재생을 시작할 때는 아래 Safari 기본 플레이어의 재생 버튼도 사용해 보세요. 같은 오디오를 제어합니다.

백그라운드 재생 진단

60초 테스트음을 재생한 뒤 화면을 잠그거나 다른 앱을 열어 보세요. 소리가 계속 들리면 이 브라우저에서 일반 오디오 백그라운드 재생이 가능한 것입니다. 이 검사는 AI 음성 생성과 무관합니다.

여백 사용 안내

글 담기
파일을 선택하거나 끌어다 놓고, 직접 글을 붙여넣을 수도 있습니다. 문서의 텍스트를 읽기 좋은 형태로 불러옵니다. 그림과 복잡한 편집 모양은 그대로 보이지 않을 수 있으며, 이미지로만 된 PDF는 읽을 수 없습니다.

이어 읽기와 듣기
마지막으로 읽거나 듣던 문단이 자동으로 저장됩니다. 문단을 누르면 그 부분부터 읽어줄 수 있습니다. 하단 재생 버튼과 설정에서 속도와 목소리를 조절하세요. iPhone의 음성합성은 화면 잠금 후 중단될 수 있습니다. MP3/M4A 오디오 파일을 연결하면 지원하는 브라우저의 미디어 재생 기능을 사용할 수 있습니다. 오디오 재생 위치는 글 읽기 위치와 별도로 저장됩니다.

보관과 이동
서재와 읽기 위치는 지금 사용 중인 브라우저에 저장됩니다. 기기 간 자동 동기화는 되지 않습니다. 브라우저 데이터를 삭제하면 서재도 지워질 수 있으니 백업을 이용해 주세요. 온라인 목소리는 음성 제공업체로 글이 전송될 수 있습니다. 오디오 파일은 JSON 백업에 포함되지 않으므로 원본 파일을 별도로 보관하세요.
