AI 오디오 책 (현수 목소리)

추천 글에서 ‘AI 낭독 오디오 포함’ 책을 ‘오디오와 함께 담기’로 받으면 그 책은 AI 낭독 오디오(현수 목소리)로 읽습니다. 지금 읽는 문단부터 나오고, 소리를 따라 문단 표시가 움직이며, 화면을 잠가도 이어집니다. 오디오는 PC의 여백 작업실에서 만들어 올립니다.

내가 담은 책도 현수 오디오로 · 책 관리의 ‘현수 오디오 만들기’를 누르거나 아래를 켜면, 글을 GitHub(오디오 저장소)로 보내 현수 오디오를 만들고 완성되면 그 책에 알아서 붙입니다(강의 1개 약 5분, 이 화면이 열려 있을 때 붙습니다. 50MB가 넘는 것은 카드의 ‘현수 오디오 받기’로 받습니다). 이 기기에 다 받으면 서버에서는 지웁니다. 보낸 글은 받기 전까지 공개 저장소에 있어 누구나 볼 수 있습니다.

GitHub 키 만드는 법 (처음 한 번)
  1. github.com에 Chemistreal 계정으로 로그인 → 오른쪽 위 사진 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름(예: 여백 아이폰) · 기간(예: 1년) · Repository access: Only select repositories → yeobaek-audio
  4. Permissions → Repository permissions → Contents: Read and write (다른 권한은 그대로)
  5. Generate token → 나온 키(github_pat_…)를 복사해 위 칸에 붙여 넣고 ‘키 저장’
키는 이 기기에만 저장되고 서재 백업에는 들어가지 않습니다. 이 키로는 오디오 저장소의 파일만 올릴 수 있습니다.
오디오 파일 직접 연결

아이폰의 일반 음성합성(TTS)은 화면 잠금이나 앱 전환 후 중단될 수 있습니다. 백그라운드 재생이 필요하다면 MP3/M4A 음성 파일을 이 글에 연결하세요. 오디오는 이 기기에 저장되며 서재 JSON 백업에는 포함되지 않습니다.

이 글에 연결된 오디오가 없습니다.

아이폰에서 잠금 화면 재생을 시작할 때는 아래 Safari 기본 플레이어의 재생 버튼도 사용해 보세요. 같은 오디오를 제어합니다.

여백 사용 안내

글 담기
파일을 선택하거나 끌어다 놓고, 직접 글을 붙여넣을 수도 있습니다. 문서의 텍스트를 읽기 좋은 형태로 불러옵니다. 그림과 복잡한 편집 모양은 그대로 보이지 않을 수 있으며, 스캔 이미지 PDF는 20쪽 이내에서 한국어·영어 OCR을 선택해 시도할 수 있지만, 이미지 인식 오류가 발생할 수 있습니다.

이어 읽기와 듣기
마지막으로 읽거나 듣던 문단이 자동으로 저장됩니다. 문단을 누르면 그 부분부터 읽어줄 수 있습니다. 하단 재생 버튼과 설정에서 속도와 목소리를 조절하세요. iPhone의 음성합성은 화면 잠금 후 중단될 수 있습니다. MP3/M4A 오디오 파일을 연결하면 지원하는 브라우저의 미디어 재생 기능을 사용할 수 있습니다. 오디오 재생 위치는 글 읽기 위치와 별도로 저장됩니다.

오프라인과 집중 모드
지원 브라우저에서는 여백 웹앱을 홈 화면에 설치할 수 있습니다. 저장된 글은 인터넷 없이도 열 수 있지만 AI 오디오 책 받기·PDF 변환은 인터넷이 필요합니다. 구절을 선택하고 펜 버튼으로 하이라이트하거나, 책갈피·메모를 남길 수 있습니다. 취침 타이머는 iOS 백그라운드 정책 때문에 종료 시각이 지연될 수 있습니다.

보관과 이동
서재와 읽기 위치는 지금 사용 중인 브라우저에 저장됩니다. 기기 간 자동 동기화는 되지 않습니다. 브라우저 데이터를 삭제하면 서재도 지워질 수 있으니 백업을 이용해 주세요. 온라인 목소리는 음성 제공업체로 글이 전송될 수 있습니다. 오디오 파일은 JSON 백업에 포함되지 않으므로 원본 파일을 별도로 보관하세요.

암호화된 전체 백업

글·원본·오디오를 하나의 암호화 파일로 묶습니다. 비밀번호는 이 기기에 저장되지 않고 잊어버리면 복원할 수 없습니다. 용량이 큰 백업은 메모리 제한으로 사용할 수 없습니다.
