# 28주차 산출 과제

대응 강의: 3초 반응 계단 1과 불동의 덩어리
분량: 400자 이상. Q1은 100자, Q2는 250자였고 Q4에서 600자가 된다.

## 과제

두 사람이 다르게 보는 일을 놓고 주고받는 글을 쓴다. 한쪽이 뒤집고 다른 쪽이 다시 받는다.

조건: 불동의 세 조각을 다 쓴다. 인정이 뒤집기보다 먼저 나와야 한다.

## 만드는 방법

한 문장씩 번갈아 만든다. 각자 쓰고 나중에 합치지 않는다.

1. 남편이 첫 문장을 소리 내어 말한다
2. 아내가 그 문장을 받아 적는다
3. 아내가 다음 문장을 말하고 남편이 받아 적는다
4. 끝까지 번갈아 간다

받아 적는 쪽이 이상하다고 느끼면 그 자리에서 말한다.
말한 쪽이 고칠지 그대로 둘지 정한다. 적는 쪽이 마음대로 고치지 않는다.

Q3에서 분량이 400자로 늘었다. Q2보다 문장이 절반쯤 더 붙는다.
길어지면 한 사람이 몰아 쓰고 싶어진다. 그 자리에서 규칙이 깨진다.
문장 수를 미리 세어 두고 반씩 나눈다.

## 확인

세 조각에 각각 밑줄을 긋고 순서가 맞는지 본다.

확인은 맞고 틀림을 가르는 자리가 아니다. 조건을 지켰는지만 본다.

## 교정 요청 프롬프트

아래를 그대로 복사해서 쓴다. 매번 설명을 다시 쓰지 않기 위해 미리 적어 둔다.

```
아래는 영어를 배우기 시작한 지 아홉 달이 안 된 성인 두 사람이 함께 쓴 28주차 글이다.
1년 과정의 Q3 구간이고 목표는 정확성이 아니라 덩어리가 자리에 맞게 나오는 것이다.

다음 순서로만 봐 달라.
1. 뜻이 안 통하는 자리만 먼저 짚어 달라. 통하면 넘어가 달라
2. 문법 오류는 뜻이 바뀌는 것만 짚어 달라. 어색한 정도는 넘어가 달라
3. 고친 문장을 다시 써 주되 원문보다 길어지지 않게 해 달라
4. 이 구간에서 안 배운 것은 쓰지 말아 달라. 시제는 현재와 현재진행과
   단순과거와 과거진행과 will 과 going to 까지만, 조건은 if 와 when 을 쓴 것과
   If I were you 형태까지만, 명사에 붙는 조각은 형용사와 전치사구까지만,
   관계대명사와 분사구문은 쓰지 말아 달라
5. 슬랭과 유행어를 쓰지 말아 달라

마지막에 잘한 자리를 하나만 짚어 달라. 여러 개는 필요 없다.

글:
(여기에 붙여 넣는다)
```

Q2 프롬프트에서 4번만 바뀌었다. 과거진행과 조건과 명사에 붙는 조각이 열렸다.
관계대명사와 분사구문은 그대로 막아 둔다. Q3에서 안 배운 것이다.

교정 결과에서 뜻이 바뀐 자리만 고친다.
어색하다고만 지적된 것은 안 고친다.
