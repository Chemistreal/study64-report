# Q4 대조판 001. 한 사람이 오래 말하는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 73강 3분 발화의 뜻, 74강 처음 만난 사람
대응 자리: 열두째 칸 마무리 앞의 이음매

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 토막 둘을 이음매로 잇기

A: I go there every Sunday. It is close to my house. I walk for ten minutes.
B: Really?
A: Yes. The walk is nice. In fact, I like the walk more than the place.
B: Me too. I walk a lot.
A: Do you walk in the morning?
B: Yes, before work.

---

## [2층] 외부 자료

출처: lle1-34, VOA Learning English Lesson 34
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Hello! Halloween is very popular in the United States.
Anna: Children trick-or-treat. They ask people for candy. Children and adults wear costumes and go to parties!
Anna: In fact, there is a Halloween party tonight. I need my friend, Genie. Genie!
Anna: Hi!
Genie: Hi, Anna! What do you need?

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
37주와 38주 항목이 이 칸에 붙는다.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 한 사람이 안 끊기고 낸 문장 수의 최대 |  |  |
| 토막이 몇 개인가 |  |  |
| 이음매에 쓴 방법이 몇 가지인가 |  |  |
| In fact 가 나온 횟수 |  |  |
| 상대가 받은 말의 낱말 수 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
어색하다고 느낀 이유는 안 적어도 된다. 자리만 짚으면 된다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
