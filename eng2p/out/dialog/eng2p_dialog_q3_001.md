# Q3 대조판 001. 거절하는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 49강 3초의 뜻, 50강 거절 덩어리
대응 자리: 아홉째 칸 거절

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 거절 세 층과 시간 버는 소리

A: Can you help me now?
B: I can't. Something came up. Maybe next time.
A: Okay. Can we do it later?
B: Let me think. After lunch?
A: After lunch is good.
B: Good.

---

## [2층] 외부 자료

출처: lle1-27, VOA Learning English Lesson 27
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Ms. Weaver, Hi. I can't come to work today.
Caty: Why not? What is wrong?
Anna: Well, yesterday I felt fine.
Anna: In the morning, I painted for hours. In the afternoon, I cut wood. Then, I built a fire.
Caty: Anna, what do you mean? Why can't you come to work today?
Anna: I do not feel well. I think I'm sick.

---

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
25주와 26주 항목이 이 칸에 붙는다.

---

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 거절이 몇 층까지 갔는가 |  |  |
| 1층이 이유보다 먼저 나왔는가 |  |  |
| 시간 버는 소리가 나온 횟수 |  |  |
| 이름을 부른 횟수 |  |  |
| 한 사람이 한 번에 낸 문장 수 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
어색하다고 느낀 이유는 안 적어도 된다. 자리만 짚으면 된다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
