# Q4 대조판 004. 상대가 안 듣고 거리가 흔들리는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 85강 3분이 무너진 자리 복구, 90강 세 레지스터를 한자리에서
대응 자리: 열한째 칸 되돌리기와 거리 유지

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 안 듣는 상대를 물어서 끌어오기

A: Could you look at this for a moment?
B: Sure.
A: The first part is done. The second part is not. I am not sure about the third.
B: Hmm.
A: What do you think about the second part?
B: Sorry. Say that again?
A: The second part is not done. Should I finish it today?
B: Yes, today is better.

---

## [2층] 외부 자료

출처: lle1-44, VOA Learning English Lesson 44
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Wow! This supermarket is huge! Look at all of these fruits and vegetables! I should eat more vegetables.
Healthy: Good idea, Anna. You must eat more vegetables … like celery!
Junky: Celery?! Do you know what the web says about celery?
Anna: No, what?

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
43주와 44주 항목이 이 칸에 붙는다.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 물어서 상대를 끌어온 자리가 몇 번인가 |  |  |
| 거리가 처음과 끝이 같은가 |  |  |
| 되묻는 자리가 몇 번인가 |  |  |
| 한 사람이 안 끊기고 낸 문장 수의 최대 |  |  |
| 짧게만 받은 순번이 몇 번 이어졌는가 |  |  |

세고 나서 한 가지를 말로 적는다. 두 자료 중 어느 쪽이 거리가 더 일정한지 각자 고른다.
고른 것이 갈리면 갈린 채로 둔다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
