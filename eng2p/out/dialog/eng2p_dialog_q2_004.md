# Q2 대조판 004. 의견 자리와 확인 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 37강 의견 덩어리, 40강 확인하는 덩어리
대응 자리: 여덟 자리 중 다섯째와 여섯째

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 의견 세기 세 묶음과 확인 네 묶음

A: I think this place is good.
B: Right. Good how?
A: I like the coffee here.
B: The coffee. So you come here often?
A: I really love this coffee. It's my favorite.
B: Your favorite. Okay, I will try it.

## [2층] 외부 자료

출처: lle1-21 과 lle1-29, VOA Learning English Lesson 21, 29
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.

Anna: Washington, D.C. has some great coffee shops. My favorite is this one -- Busboys & Poets.
Anna: Actually it's more than a coffee shop. It's also a bookstore, a restaurant and a theater!
Anna: Marsha and I love coming here.

Anna: Thanks. This was a good idea. Working outdoors is nice.
Marsha: Um-hum, it is.
Anna: I am tired. Today was a busy day at work. And I still have work to do!
Marsha: Hmm, that's too bad.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 약하게 낸 의견 수 |  |  |
| 세게 낸 의견 수 |  |  |
| 소리로 확인한 횟수 |  |  |
| 되풀이로 확인한 횟수 |  |  |
| 확인 없이 넘어간 차례 수 |  |  |

1층은 확인을 매 차례 넣었다. 2층에서 확인이 없는 차례를 세어 견준다.
어느 쪽이 실제에 가까운지 두 사람이 각각 짐작해 적는다. 답은 안 맞춘다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
