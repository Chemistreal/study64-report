# Q4 대조판 002. 원하는 것이 다를 때 맞추는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 75강 잡담 덩어리, 77강 협상의 구조
대응 자리: 열째 칸 협상

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 협상 네 단계

A: I want to leave at seven.
B: I want to leave at nine. What time do you have to be there?
A: I agree. Seven is early. If you can drive, we leave at eight.
B: Okay. I will drive. We leave at eight.

---

## [2층] 외부 자료

출처: lle1-23, VOA Learning English Lesson 23
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Hi Jonathan! Hey, we are meeting Ms. Weaver for lunch at noon, aren't we?
Jonathan: Yes.
Anna: What time is it now?
Jonathan: 11:50.
Anna: 11:50! We have to go!
Anna: So, where is this world food restaurant?
Caty: We're not eating at a restaurant.
Anna: Where are we eating?

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
39주와 40주 항목이 이 칸에 붙는다.

---

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 원하는 것을 먼저 낸 사람이 몇 명인가 |  |  |
| 조건을 붙여 낸 자리가 몇 번인가 |  |  |
| 하나로 정해졌는가 |  |  |
| 물음이 몇 번 나왔는가 |  |  |
| 한 사람이 한 번에 낸 문장 수의 최대 |  |  |

세고 나서 한 가지를 말로 적는다. 2층이 협상인지 아닌지 각자 판단해 적는다.
판단이 갈리면 갈린 채로 둔다. 그것이 이 대조판의 산출물이다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
