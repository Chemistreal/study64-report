# Q2 대조판 003. 시간 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 34강 시간 덩어리
대응 자리: 여덟 자리 중 넷째

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 시간 덩어리 세 묶음과 앞뒤 자리

A: Yesterday I went to the park.
B: I go there these days too.
A: Have you ever seen the birds there?
B: I have never seen them. I was there last year.
A: Today the birds were everywhere.
B: I will go this week.

---

## [2층] 외부 자료

출처: lle1-48, VOA Learning English Lesson 48
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.

Anna: I like the Sculpture Garden. Have you ever seen sculptures in a garden? It is really artistic!
Jean: I have never seen a garden of sculptures! I'll write that on my list!
Anna: Have you been to the Museum of the American Indian? I've visited that museum many times. It is very peaceful.
Jean: I have always liked American Indian culture.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 시간 덩어리가 문장 앞에 온 횟수 |  |  |
| 문장 뒤에 온 횟수 |  |  |
| 가운데에 온 횟수 |  |  |
| 시간 덩어리가 아예 없는 문장 수 |  |  |
| 세 묶음 중 제일 많이 나온 묶음 |  |  |

가운데에 온 것은 ever 와 never 뿐인지 확인한다. 다른 것이 있으면 적어 둔다.
34강에서 예외를 둘로 잡았는데 셋째가 나오면 그것이 그 강의 수정 항목이 된다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
