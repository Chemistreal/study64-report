# Q3 대조판 005. 설명하는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 65강 설명 덩어리 확장, 67강 겹침 속에서 3초
대응 자리: 설명 칸

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 설명을 여는 덩어리와 끊고 들어가는 표시

A: It's like a game. You have to find things.
B: Excuse me. Do you play it on your phone?
A: Yes. First you look at the phone. Then you walk.
B: It's like a scavenger hunt.
A: That's right.
B: I see.

## [2층] 외부 자료

출처: lle1-33, VOA Learning English Lesson 33
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: To play baseball, you really only need a bat, a ball and a glove. Each team has many players.
(가운데 배역 이름을 하나씩 부르는 대목이 들어간다. 여기서는 줄인다)
Anna: First, the pitcher pitches the ball to the batter. The batter bats the ball. Then, the runner runs to first base.
Anna: Each time a batter bats, the runners run around the bases. Each time a runner runs across home plate, they score a run! There are nine innings in a game. The team with the most runs at the end of nine innings wins the game!

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
33주와 34주 항목이 이 칸에 붙는다.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 무엇인지 설명한 횟수 |  |  |
| 어떻게 하는지 설명한 횟수 |  |  |
| 받는 쪽이 요약해 되돌린 횟수 |  |  |
| 끊고 들어간 횟수 |  |  |
| 한 사람이 한 번에 낸 문장 수 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
2층은 받는 쪽이 없다. 그것이 설명에 어떤 차이를 만드는지 한 줄로 적는다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
