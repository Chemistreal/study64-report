# Q2 대조판 002. 되돌리는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 31강 되돌리는 덩어리
대응 자리: 여덟 자리 중 셋째

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 되돌리는 덩어리 네 묶음

A: I had a long day. How about you?
B: Mine was fine. What do you think about the weather?
A: It's too hot. Don't you think?
B: Yes, it is. And then what happened at work?
A: Nothing much. Have you tried the new place?
B: Not yet. And you?

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 되돌리는 덩어리가 나온 횟수 |  |  |
| 되돌림 없이 끝난 차례 수 |  |  |
| 한 낱말로 되돌린 횟수 |  |  |
| 두 사람의 차례 수 차이 |  |  |
| 문장 하나의 평균 낱말 수 |  |  |

1층은 되돌림을 일부러 과하게 넣었다. 그것이 어디서 어색해지는지 짚는다.
2층에서 되돌림이 안 나온 자리도 하나 짚는다. 왜 안 나와도 되는지 말로 해 본다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
