# Q2 대조판 006. 마무리 자리와 화제 전환

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 46강 마무리 덩어리, 47강 대화 유지와 화제 전환
대응 자리: 여덟 자리 중 여덟째

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 마무리 세 단계와 화제 전환 네 방법

A: So we are meeting on Friday.
B: Speaking of Friday, are you working that day?
A: Yes, until five. By the way, did you call your sister?
B: Not yet. Anyway, that's the plan for Friday.
A: Sounds good. See you then.
B: Take care.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 닫기 전에 알린 횟수 |  |  |
| 지금까지 한 것을 묶은 횟수 |  |  |
| 다음을 정한 횟수 |  |  |
| 화제가 바뀐 횟수 |  |  |
| 화제를 바꾼 사람이 한쪽으로 몰렸는가 |  |  |

마지막 항목만 값이 아니라 예 또는 아니오로 적는다.
2층에서 한쪽이 계속 바꿨으면 그것이 그 대화의 관계 형태다.
우리 세션의 47강 기록과 나란히 놓는다. 같은 형태면 그것을 표시해 둔다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.

이 대조판이 Q2 마지막이다. 여섯 장의 어긋난 항목을 모아 분기 마감에 넘긴다.
그 목록이 Q3 대조판의 첫 입력이 된다.
