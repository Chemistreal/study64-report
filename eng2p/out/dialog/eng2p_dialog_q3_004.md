# Q3 대조판 004. 세 사람이 말하는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 61강 LRE 만들기, 63강 세 사람 대화에서 차례 잡기
대응 자리: 차례와 겹침 칸

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 이름으로 차례 잡기와 언어를 놓고 여는 문장

Anna: I want to go on Friday.
Pete: Friday is not good for me.
Marsha: Pete, Anna, I can go on Friday.
Anna: Marsha, can you drive?
Marsha: I can. Well, if it works.
Pete: You mean you will drive?

---

## [2층] 외부 자료

출처: lle1-04, VOA Learning English Lesson 4
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Yes. Yes it is, Pete. I know I have a pen, though...
Anna: I have a ....
Marsha: It is not a pen, Anna ... a toy?
Pete: And it is a pillow!
Anna: Pete, Marsha, I know I have a pen.
Marsha: Anna, it is a map.
Pete: Why do you have a map of the world?

---

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
31주와 32주 항목이 이 칸에 붙는다.

두 사람만 있는 집에서는 32주 항목을 못 채집한다.
밖에서 본 것을 적어 온다. 못 적어 온 주는 빈칸으로 두고 그 사실을 적는다.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 이름을 부른 횟수 |  |  |
| 이름을 둘 다 부른 자리 수 |  |  |
| 차례가 넘어간 횟수 |  |  |
| 이름 없이 던진 말의 수 |  |  |
| 언어를 놓고 이야기한 자리 수 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
Q1 2인 대조판 하나를 꺼내 이름 부른 횟수를 같이 견준다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
