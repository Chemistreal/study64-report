# Q4 대조판 003. 하던 것을 그만두고 옮기는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 78강 3분 중에 끊긴 자리, 84강 잘못 시작한 이야기 되돌리기
대응 자리: 열한째 칸 되돌리기

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 닫고 표시하고 새 화제 열기

A: I read about the new road last week. It will open in June. The city said so.
B: Okay.
A: The road is long. It goes to the river. Hmm.
A: Anyway, did you finish the book?
B: Almost. Two more days.

## [2층] 외부 자료

출처: lle1-43, VOA Learning English Lesson 43
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: I'm stuck downtown without any money. Would you be able to come downtown? Please?
Marsha: Anna, I can't. I'm too busy. I have to give a big presentation in one hour. Sorry!
Anna: That's ok. Good luck with your presentation!
Marsha: Thanks!
Anna: Time for Plan D.

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 그만두기 전에 한 문장으로 닫았는가 |  |  |
| 넘어간다는 표시가 나왔는가 |  |  |
| 새 화제를 여는 데 쓴 문장 수 |  |  |
| 거절이 몇 층까지 갔는가 |  |  |
| 매달린 자리가 있는가 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
어색하다고 느낀 이유는 안 적어도 된다. 자리만 짚으면 된다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
