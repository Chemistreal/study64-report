# Q2 대조판 001. 이어 붙이는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 27강 시작 덩어리, 29강 이어 붙이는 덩어리
대응 자리: 여덟 자리 중 첫째와 둘째

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 이어 붙이는 덩어리 세 방향

A: So, I went to the market today.
B: And what did you buy?
A: I bought some fish. But it was expensive.
B: So you spent a lot?
A: Yes. For example, one fish was ten dollars.
B: That's a lot. Still, fish is good for you.

---

## [2층] 외부 자료

출처: lle1-30, VOA Learning English Lesson 30
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Excuse me. Can you help me?
Pete: Sure! What do you need?
Anna: Pete!
Pete: Anna!
Anna: What are you doing here?
Pete: I work here. You know, it's not easy to be a writer.
Anna: Yeah, I heard that. Sorry.
Pete: But this job is great. I work outside by the river. And I can eat all the free seafood I want!

---

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.

---

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 한 사람이 한 번에 낸 문장 수 |  |  |
| 이어 붙이는 덩어리가 나온 횟수 |  |  |
| 이름을 부른 횟수 |  |  |
| 목표 형식과 상관없는 말의 비율 |  |  |
| 문장 하나의 평균 낱말 수 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
어색하다고 느낀 이유는 안 적어도 된다. 자리만 짚으면 된다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
