# Q4 대조판 006. 안 맞춰지고 끝나는 자리와 잘못 듣고 이어 간 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

**이것이 이 과정의 마지막 대조판이다.** 열여덟 장 중 열여덟째다.

대응 강의: 92강 협상에서 물러나는 자리, 96강 Q4 마감 측정
대응 자리: 열째 칸 협상과 열두째 칸 마무리

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 인정만 하고 안 내놓기와 다 내놓기

A: I think the morning is better.
B: That's a good point. But I can only go at night.
A: You might be right. Night is quiet.
B: So we said night. Is that okay?
A: Okay, let's do it your way. Night.
B: Good. See you then.

## [2층] 외부 자료

출처: lle1-50, VOA Learning English Lesson 50
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Anna: Here is my report on "Violins in the City."
(가운데 네 줄 줄임)
Dr. Jones: Anna! The topic is "Violence in the city." Violence. Not violins.
Anna: Until next time …Like I was saying, many people are saying that violence in the city is a problem. A very big problem.

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
47주와 48주 항목이 이 칸에 붙는다.
**48주 항목이 이 과정의 마지막 채집이다.**

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 인정만 하고 안 내놓은 자리가 몇 번인가 |  |  |
| 다 내놓은 자리가 몇 번인가 |  |  |
| 하나로 정해졌는가 |  |  |
| 잘못 들은 것을 고칠 때 처음부터 다시 했는가 |  |  |
| 마무리 네 단계 중 몇 개가 나왔는가 |  |  |

세고 나서 한 가지를 말로 적는다. 두 자료가 같은 종류의 대화인지 각자 판단한다.
2층은 협상이 아니고 1층은 협상이다. 그 차이를 각자 한 줄로 적는다.

**마지막 대조판이라 한 가지를 더 한다.**
열여덟 장을 다 펴 놓고 2층-나 칸이 빈 장이 몇인지 센다.
빈 칸은 채집을 못 한 주다. 지어내 채우지 않고 몇 장인지만 적는다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
