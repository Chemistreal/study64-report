# Q3 대조판 002. 조건을 붙이는 자리

기준서 6.4를 따른다. 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾는다.
정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.

대응 강의: 53강 조건 표현 뽑기, 54강 겹쳐 말할 때 처리
대응 자리: 열째 칸 조건

---

## [1층] 학습용 인공물

이 대화는 학습용으로 만들어진 것이다. 실제 대화 녹음이 아니다.
목표 형식 하나를 집중해서 노출시키려고 쓴 것이라 실제 대화보다 규칙적이다.

목표 형식: 조건 덩어리와 겹쳤을 때 물러나는 소리

A: If you want, we can start now.
B: If it works, I will come at two.
A: When you get there, send me a message.
B: Sorry, go ahead.
A: No, go ahead.
B: So, I will send a message.

---

## [2층] 외부 자료

출처: lle1-25, VOA Learning English Lesson 25
성질: 연출된 대본이다. 배우가 읽은 것이고 즉흥 발화가 아니다.
학습자가 조준표로 모아 올 즉흥 발화는 아래 2층-나에 붙인다.

Dan: You have to find things that aren't really there.
Anna: How can you find things that aren't really there?
Dan: They're in your phone. See?
Anna: I see. It's like a scavenger hunt.
Dan: That's right!
(가운데 한 줄 줄임)
Dan: Then you should play this game! When you find an American symbol, you win points and a Fun Fact about a U.S. President.

---

## [2층-나] 학습자 채집

출처:

조준표 채집 지시로 모은 것을 여기 붙인다. 제작 시점에는 비어 있다.
27주와 28주 항목이 이 칸에 붙는다.

---

## [3층] 대조

다음 다섯 가지를 각각 1층과 2층에서 세어 적는다.
정답은 이 문서에 없다. 두 사람이 센 값을 맞춰 본다.

| 항목 | 1층 | 2층 |
|---|---|---|
| 조건 표현이 나온 횟수 |  |  |
| 조건 조각이 앞에 온 횟수 |  |  |
| 겹친 자리가 있는가 |  |  |
| 물러나는 소리가 나온 횟수 |  |  |
| 문장 하나의 평균 낱말 수 |  |  |

세고 나서 한 가지를 말로 적는다. 1층에서 어색한 자리를 하나 짚는다.
겹친 자리가 2층에 없다는 것이 무엇을 뜻하는지 한 줄로 적는다.

## 판정 세션 입력

두 사람의 값이 어긋난 항목만 적는다. 맞은 항목은 안 적는다.
어긋난 것이 미해결 LRE 가 되고 주간 판정 세션으로 간다.
