# 6주차 대조 교차 세트 031-036

세트당 30분이다. 031 부터 033 은 11강, 034 부터 036 은 12강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

## 세트 031

대응강의: eng2p_q1_l011

### 1단계 A 설명 (8분)

설명 대상: 낱말 경계가 소리에서 사라지는 조건
필수 포함 요소:
  1. 앞 낱말이 자음으로 끝나고 뒤 낱말이 모음으로 시작할 때다
  2. 앞의 끝소리가 뒤 낱말의 앞자리로 넘어간다
  3. 그래서 띄어쓰기가 있는 자리에서 소리가 안 끊긴다

### 2단계 B 재구성 (8분)

재구성 방식: 반례 제시
지시: 조건에 맞는데도 안 넘어가는 자리를 하나 찾는다.
못 찾으면 조건이 맞게 잡힌 것이다. 그것도 결과로 적는다.

### 3단계 상호 검토 (10분)

합의 지점 1개 이상, 불일치 지점 1개 이상을 각자 적는다.
조건을 소리로 말했는지 철자로 말했는지 확인한다.

규칙: "틀렸다"고 말하지 않는다. "나는 이렇게 이해했다" 형식만 쓴다.
