# 2주차 대조 교차 세트 007-012

세트당 30분이다. 007 부터 009 는 03강, 010 부터 012 는 04강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.

## 세트 007

대응강의: eng2p_q1_l003

### 1단계 A 설명 (8분)

설명 대상: 어말 자음 뒤에 모음을 붙이면 안 되는 이유
필수 포함 요소:
  1. 한글은 자음을 모음 없이 적을 수가 없다
  2. 그래서 끝 자음에 모음이 하나 딸려 나온다
  3. 딸려 나온 모음만큼 음절이 늘고 다른 낱말로 들린다

### 2단계 B 재구성 (8분)

재구성 방식: 예시 추가
지시: 끝 자음에 모음이 붙으면 다른 낱말이 되는 예를 두 개 찾는다.
카드 015 와 017 의 낱말에서 골라도 된다.

### 3단계 상호 검토 (10분)

합의 지점 1개 이상, 불일치 지점 1개 이상을 각자 적는다.
다른 낱말이 되는 것과 그냥 어색해지는 것을 갈라 본다.

규칙: "틀렸다"고 말하지 않는다. "나는 이렇게 이해했다" 형식만 쓴다.
