# 19주차 대조 교차 세트 109-114

세트당 30분이다. 주 6세트이므로 19주차에 여섯 개를 다 돈다.
109 부터 111 은 37강, 112 부터 114 는 38강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

18주차 105 에서 각자 정한 카드를 이번 주 페어 드릴에서 따로 돌린다.
세트는 같이 한다. 갈리는 것은 드릴이지 세트가 아니다.
