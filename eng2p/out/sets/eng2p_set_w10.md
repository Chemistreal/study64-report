# 10주차 대조 교차 세트 055-060

세트당 30분이다. 055 부터 057 은 19강, 058 부터 060 은 20강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

기준서 12장이 지목한 지루함 구간의 한가운데다.
이 주의 세트가 다른 주보다 실행 비중이 높다. 설명보다 돌리는 시간이 많다.

대응강의: eng2p_q1_l019

설명 대상: 되묻기 세 형태의 강도가 다른 이유
필수 포함 요소:
  1. 1형은 아무것도 몰라도 쓴다
  2. 3형은 대부분 알아들어야 쓴다
  3. 그래서 형태를 고르는 것 자체가 얼마나 들렸는지의 신호다

### 2단계 B 재구성 (8분)

재구성 방식: 상황 적용
지시: 카드 125 의 다섯 상황에 세 형태를 각각 붙인다.
상황마다 셋 중 어느 것이 제일 자연스러운지도 표시한다.

### 3단계 상호 검토 (10분)

합의 지점 1개 이상, 불일치 지점 1개 이상을 각자 적는다.
자연스러운 형태 고르기가 갈리면 그것을 불일치로 적는다.
