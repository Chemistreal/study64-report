# 4주차 대조 교차 세트 019-024

세트당 30분이다. 019 부터 021 은 07강, 022 부터 024 는 08강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

## 세트 019

대응강의: eng2p_q1_l007

### 1단계 A 설명 (8분)

설명 대상: going to 가 줄어드는 조건
필수 포함 요소:
  1. 뒤에 동사가 오면 줄어든다
  2. 뒤에 장소가 오면 안 줄어든다
  3. 같은 철자인데 뒤에 오는 것으로 갈린다

### 2단계 B 재구성 (8분)

재구성 방식: 상황 적용
지시: A의 조건을 카드 045 의 다섯 쌍에 적용해 줄어드는 쪽을 예측한다.
예측을 적은 뒤에 A가 읽어 주면 맞았는지 확인한다.

### 3단계 상호 검토 (10분)

합의 지점 1개 이상, 불일치 지점 1개 이상을 각자 적는다.
예측이 어긋난 쌍이 있으면 조건의 어느 부분에서 갈렸는지 찾는다.

규칙: "틀렸다"고 말하지 않는다. "나는 이렇게 이해했다" 형식만 쓴다.
