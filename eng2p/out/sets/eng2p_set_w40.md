# 40주차 대조 교차 세트 235-240

세트당 30분이다. 주 6세트이므로 40주차에 여섯 개를 다 돈다.
235 부터 237 은 79강, 238 부터 240 은 80강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

**Q4 첫 넉 주가 여기서 끝난다.** 40주차 끝에 40주 점검 다섯 항목을 한다.
이 파일 끝에 적어 두었다.

## 40주 점검

세트 240 을 마친 뒤에 한다. 30분을 잡는다. 8주차와 32주차와 같은 형식이다.

다섯 항목을 본다. 판정이 아니라 방향을 보는 자리다.

| 항목 | 무엇을 보나 |
|---|---|
| 발화 지분 | 두 사람의 3분 판 횟수가 한쪽으로 몰렸는가 |
| 역할 고착 | 늘 같은 사람이 먼저 여는가 |
| 기분 | 세션 뒤에 남는 것이 부담인가 아닌가 |
| 결석 | 넉 주에 몇 번 빠졌고 이유가 무엇인가 |
| 비상판 | 넉 주에 몇 번 썼는가 |

**Q4는 3분 발화라 발화 지분이 제일 잘 몰린다.** 이 자리에서 그것부터 본다.
31강 발화 지분 선인 일곱 대 셋을 넘었으면 다음 넉 주에 순서를 고정한다.

값을 진행 대장에 옮겨 적는다. 여기서 판정은 안 한다.
판정은 96강 마감 측정에서 한 번만 한다.
