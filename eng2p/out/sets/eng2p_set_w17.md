# 17주차 대조 교차 세트 097-102

세트당 30분이다. 주 6세트이므로 17주차에 여섯 개를 다 돈다.
097 부터 099 는 33강, 100 부터 102 는 34강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

이번 주에 미디어가 2회차로 넘어간다. 앞의 열두 과를 다시 듣기 시작한다.
같은 자료를 다시 쓰는 것이라 1회차에 표시해 둔 종이를 같이 편다.
