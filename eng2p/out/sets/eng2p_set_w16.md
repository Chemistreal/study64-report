# 16주차 대조 교차 세트 091-096

세트당 30분이다. 주 6세트이므로 16주차에 여섯 개를 다 돈다.
091 부터 093 은 31강, 094 부터 096 은 32강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

이번 주에 문법 트랙이 처음 열린다. 32강 세트 셋은 규칙을 뽑는 절차를 다룬다.
규칙 자체를 설명 대상으로 삼지 않는다. 절차를 설명 대상으로 삼는다.

## 세트 091

대응강의: eng2p_q2_l031

### 1단계 A 설명 (8분)

설명 대상: 되돌리는 덩어리가 왜 이 과정의 안전장치인가
필수 포함 요소:
  1. 받기만 하고 안 되돌리면 대화가 한쪽으로만 흐른다
  2. 기준서 2.4는 지배와 수동으로 굳는 것을 최대 위험으로 본다
  3. 한국어에서 굳은 패턴은 영어로 바꿔도 안 바뀐다

### 2단계 B 재구성 (8분)

재구성 방식: 상황 적용
지시: 두 사람의 한국어 대화 3분을 녹음 없이 세어 누가 더 물었는지 적는다.
설명을 다시 말하지 않는다. 센 수만 적는다.

### 3단계 상호 검토 (10분)

합의 지점 1개 이상, 불일치 지점 1개 이상을 각자 적는다.
한쪽으로 몰려 있으면 그것을 적어 두고 다음 주에 다시 센다.

규칙: "틀렸다"고 말하지 않는다. "나는 이렇게 이해했다" 형식만 쓴다.
