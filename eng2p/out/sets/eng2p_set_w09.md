# 9주차 대조 교차 세트 049-054

세트당 30분이다. 049 부터 051 은 17강, 052 부터 054 는 18강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

9주차부터 세트 성격이 바뀐다. 소리를 다루던 자리에서 말을 다루는 자리로 넘어간다.
설명 대상이 음운 현상이 아니라 형태 목록과 절차가 된다.

## 세트 049

대응강의: eng2p_q1_l017

### 1단계 A 설명 (8분)

설명 대상: 틀이 무엇이고 어떻게 알아보는가
필수 포함 요소:
  1. 문장 여럿을 나란히 놓고 안 바뀌는 앞부분을 찾는다
  2. 그 앞부분이 틀이고 뒤가 갈아 끼우는 자리다
  3. 틀 하나를 저장하면 뒤를 바꿔 여러 문장을 만든다

### 2단계 B 재구성 (8분)

재구성 방식: 상황 적용
지시: A가 말한 방법으로 대본에서 틀을 두 개 뽑는다.
뽑은 틀로 문장을 세 개씩 만든다.

### 3단계 상호 검토 (10분)

합의 지점 1개 이상, 불일치 지점 1개 이상을 각자 적는다.
뽑은 틀이 서로 다르면 둘 다 놓고 어느 쪽이 더 자주 나오는지 본다.

규칙: "틀렸다"고 말하지 않는다. "나는 이렇게 이해했다" 형식만 쓴다.
