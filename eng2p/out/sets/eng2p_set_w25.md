# 25주차 대조 교차 세트 145-150

세트당 30분이다. 주 6세트이므로 25주차에 여섯 개를 다 돈다.
145 부터 147 은 49강, 148 부터 150 은 50강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

### 1단계 A 설명 (8분)

설명 대상: 0.5초보다 3초가 왜 더 어려운가
필수 포함 요소:
  1. 0.5초는 덩어리 하나를 꺼내는 시간이고 3초는 대화 한 번을 여는 시간이다
  2. 3초 안에는 알아듣기와 정하기와 꺼내기가 다 들어간다
  3. 재는 대상이 낱개에서 자리로 바뀌었다

재구성 방식: 예시 추가

설명을 다시 말하지 않는다. 예만 든다.
