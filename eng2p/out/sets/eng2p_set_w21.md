# 21주차 대조 교차 세트 121-126

세트당 30분이다. 주 6세트이므로 21주차에 여섯 개를 다 돈다.
121 부터 123 은 41강, 124 부터 126 은 42강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

20주차 관계 점검에서 한 항목만 몰려 있었으면 이번 주에 다시 잰다.
그 측정은 세트 시간에서 빼지 않는다. 따로 15분을 잡는다.
