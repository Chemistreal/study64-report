# 32주차 대조 교차 세트 187-192

세트당 30분이다. 주 6세트이므로 32주차에 여섯 개를 다 돈다.
187 부터 189 는 63강, 190 부터 192 는 64강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

**Q3 관계 점검 주다.** 세트 여섯을 다 돈 뒤에 한다.
이 파일 끝에 절차를 적어 두었다. 20주차와 같은 형식이다.

## 32주차 관계 점검

기준서 2.4가 관계 유형을 이 과정 최대 위험으로 본다.
20주차에 한 번 했고 Q3에서 한 번 더 한다. 세트 여섯을 다 돈 뒤에 한다.
30분을 따로 잡는다. 세트 시간에서 빼지 않는다.

Q3는 항목이 하나 는다. 거절과 불동의가 열렸기 때문이다.

| 항목 | 어디서 | 견줄 값 |
|---|---|---|
| 한국어 대화의 질문 분포 | 20주차 값 | 지금 다시 센 값 |
| 세게 낸 의견의 분포 | 20주차 값 | 지금 다시 센 값 |
| 발화 지분 | 31강 통과 기준의 관찰 항목 | 7 대 3을 넘는가 |
| 정리를 도맡은 횟수 | 36강 통과 기준의 관찰 항목 | 20번 중 14번을 넘는가 |
| 거절과 불동의 뒤의 기분 | 28주차와 30주차 한 줄 요약 | 나빠지는 쪽인가 |

다섯 중 둘 이상이 한쪽으로 몰려 있으면 매뉴얼의 교정 절차로 간다.
하나만 몰려 있으면 33주차에 다시 재고 그때 판정한다.

**다섯째 항목은 다른 넷과 다루는 방식이 다르다.**
넷은 몰림을 보고 다섯째는 방향을 본다.
나빠지는 쪽이면 그 자체로 065 와 066 을 Q4로 미루는 근거가 된다.
30주차 세트 175 에서 이미 미뤘으면 여기서 다시 확인만 한다.

이 점검은 실력 점검이 아니다. 영어가 얼마나 늘었는지는 여기서 안 본다.
둘이 계속 같이 할 수 있는 상태인지만 본다.

점검 결과를 진행 대장에 한 줄로 남긴다. Q3 마감 판단의 입력이 된다.
