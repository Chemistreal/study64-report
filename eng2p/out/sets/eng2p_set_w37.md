# 37주차 대조 교차 세트 217-222

세트당 30분이다. 주 6세트이므로 37주차에 여섯 개를 다 돈다.
217 부터 219 는 73강, 220 부터 222 는 74강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

**Q4 첫 주다.** 통과 조건이 3분 발화와 3레지스터와 주도권 전환으로 바뀐다.
압박형 제한 시간이 2초가 되고 관계 여섯 중 마지막인 처음 만난 사람이 열린다.
