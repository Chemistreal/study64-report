# 36주차 대조 교차 세트 211-216

세트당 30분이다. 주 6세트이므로 36주차에 여섯 개를 다 돈다.
211 부터 213 은 71강, 214 부터 216 은 72강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

**Q3 마지막 주다.** 세트 여섯을 다 돈 뒤에 분기 마감 절차를 한다.
이 파일 끝에 네 단계로 적어 두었다.

## Q3 분기 마감 절차

세트 216 을 마친 뒤에 한다. 60분을 잡는다. 24주차와 같은 형식이다.

### 1단계. 통과 조건 판정

네 항목으로 판정한다. 누적 시간 통과선은 576시간 총량에서 파생한 432시간이다.

| 항목 | 값이 어디 있나 | 통과선 |
|---|---|---|
| 3초 반응 | 70강과 72강 측정, 낮은 쪽 | 항목마다 10개 중 6개 |
| LRE | 최근 6세션 평균 | 8회. 미해결 절반 넘은 세션은 안 셈 |
| 겹침 처리 | 67강 값 | 세 경우마다 10번 중 6번 |
| 누적 시간 | 진행 대장 | 432h |

하나라도 못 하면 그 항목만 2주 더 한다. 분기 전체를 다시 하지 않는다.

### 2단계. 900 목록 세기

71강 두 규칙으로 센다. 틀로 묶은 뒤의 값을 쓴다.
새 자리 넷 합계 240 이상이고 자리별 최소도 본다.
기존 여덟 자리가 600 이상으로 유지되는지도 본다. 줄었으면 줄어든 자리를 적는다.

낱말 칸은 안 센다. 900은 덩어리를 세는 값이다.

### 3단계. 진행 대장 분기 기록

누적 시간, 수행일, 비상판 사용 횟수를 적는다.
미해결 LRE 목록을 세트 145 부터 216 까지에서 모은다.
대조판 여섯 장의 어긋난 항목도 같이 모은다.
32주차 관계 점검 다섯 항목의 값도 옮겨 적는다.

### 4단계. Q4로 넘길 것 정리

일곱 항목을 적는다. Q2 24주차 여섯에 하나가 는다.

1. Q3 통과 조건의 측정값과 못 넘긴 항목
2. 열한 칸 종이와 낱말 칸. 이것이 Q4의 재료다
3. 미해결 LRE 목록
4. 32주차 관계 점검 값과 기분 기록의 방향
5. 안 되던 카드 유형과 그 이유
6. 카드 147 의 2초 값. Q4 첫 주 배분의 근거다
7. 세트 192 에서 적은 3인 흉내로 못 잡히는 것

여섯째와 일곱째가 Q4로 바로 이어지는 항목이다.
여섯째는 압박형 제한 시간이 2초로 줄기 때문이고
일곱째는 Q4에서 처음 만난 사람 관계가 열리기 때문이다.
둘 다 이 과정이 2인 전용이라는 한계에서 나온다.

065 와 066 을 미뤘으면 그것도 적는다. Q4 첫 주에 다시 판단한다.

Q3가 여기서 끝난다. Q4는 73강부터다.
