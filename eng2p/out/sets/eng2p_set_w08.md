# 8주차 대조 교차 세트 043-048

세트당 30분이다. 043 부터 045 는 15강, 046 부터 048 은 16강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

8주차가 끝나면 실행 데이터를 모아 제작자에게 돌려준다.
그 자리가 기준서 16장의 필수 정지다. 그때 낼 것을 이 주에 미리 정리한다.
