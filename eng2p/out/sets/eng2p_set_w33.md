# 33주차 대조 교차 세트 193-198

세트당 30분이다. 주 6세트이므로 33주차에 여섯 개를 다 돈다.
193 부터 195 는 65강, 196 부터 198 은 66강에 붙는다.

A와 B는 날짜로 정해진다. 짝수 날은 남편이 A, 홀수 날은 아내가 A다.
기준서 4장이 그렇게 고정한다. 세트 번호로 정하지 않는다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

이번 주 세트는 형식이 65강 내용과 겹친다. 1단계가 설명이고 2단계가 받는 자리다.
