# 44주차 대조 교차 세트 259-264

세트당 30분이다. 주 6세트이므로 44주차에 여섯 개를 다 돈다.
259 부터 261 은 87강, 262 부터 264 는 88강에 붙는다.

A와 B는 세트마다 바꾼다. 짝수 세트는 남편이 A, 홀수 세트는 아내가 A다.
1단계에서 설명한 사람이 3단계에서 먼저 말하지 않는다.

**44주 끝에 44주 점검 다섯 항목을 한다.** 40주차와 같은 형식이다.
이 파일 끝에 적어 두었다.

## 44주 점검

세트 264 를 마친 뒤에 한다. 30분을 잡는다. 40주차와 같은 다섯 항목이다.

| 항목 | 무엇을 보나 |
|---|---|
| 발화 지분 | 두 사람의 3분 판 횟수가 한쪽으로 몰렸는가 |
| 역할 고착 | 늘 같은 사람이 먼저 여는가 |
| 기분 | 세션 뒤에 남는 것이 부담인가 아닌가 |
| 결석 | 넉 주에 몇 번 빠졌고 이유가 무엇인가 |
| 비상판 | 넉 주에 몇 번 썼는가 |

40주차 값을 옆에 놓고 방향을 본다. **값이 아니라 방향을 본다.**
발화 지분이 40주차보다 더 몰렸으면 남은 넉 주에 순서를 고정한다.

여기서도 판정은 안 한다. 96강 마감 측정이 판정 자리다.
