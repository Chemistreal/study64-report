# 2인 전용 영어 1년 과정 · 진행 대장

신뢰도: A 생성 (2인 프로토콜, 측정 설계)
상위 규격: docs/spec.md 3장
용도: 학습자 2인이 직접 기록하는 대장

이 대장은 성적표가 아니다.
매일 적는 칸은 활동량이고, 실력 판정은 분기 칸에서만 한다.
매일 칸을 보고 잘하고 못하고를 따지면 이 대장은 실패한 것이다.

---

## 0. 기록 규칙

| 항목 | 단위 | 주기 | 기록 위치 |
|---|---|---|---|
| LRE 발생 횟수 | 회 | 매 세션 | 2장 |
| LRE 해결 여부 | 해결/미해결/보류 | 매 세션 | 2장 |
| 미해결 LRE 목록 | 문장 | 매 세션 | 2장, 5장으로 이월 |
| 발화 시간 | 분 | 매일 | 1장 |
| 드릴 소화량 | 장 | 매일 | 1장 |
| 수행 여부 | 정상/비상판/결석 | 매일 | 1장 |
| 관계 유형 점검 | 4항목 | 분기 | 4장 |
| 통과 조건 대조 | 트랙별 | 분기 | 4장 |

세 가지를 지킨다.

첫째, 매일 칸은 세션이 끝난 직후 30초 안에 적는다. 나중에 적으면 안 적는다.
둘째, 미해결 LRE는 반드시 문장 형태로 적는다. "관사 헷갈림"이 아니라 실제 문장을 적는다.
셋째, 분기 칸은 분기 마지막 주 주간 점검에서만 연다.

### 0.1 LRE가 뭔지 한 줄 정의

둘이 지금 쓰는 영어 자체에 대해 얘기한 순간이다.
"이거 이렇게 말하는 게 맞나", "너는 왜 그렇게 말했어", "아 내가 잘못 말했다".
이 셋 중 하나가 나오면 1회로 센다.

세는 기준을 통일한다.
한 덩어리 이야기가 한 항목을 다루면 1회다. 주고받은 횟수로 세지 않는다.
횟수를 채우려고 억지로 만들지 않는다. LRE는 양보다 질이다.

## 1. 일일 기록표

한 주에 한 장. 세션 끝나고 그 자리에서 적는다.

```
[ ____주차 ]   [ ____년 __월 ]

일자 | 요일 | 오늘 A | 수행 | 발화(분) | 드릴(장) | LRE | 미해결
-----|------|--------|------|----------|----------|-----|--------
  /  |      | 남/아  |      |          |          |     |
  /  |      | 남/아  |      |          |          |     |
  /  |      | 남/아  |      |          |          |     |
  /  |      | 남/아  |      |          |          |     |
  /  |      | 남/아  |      |          |          |     |
  /  |      | 남/아  |      |          |          |     |
  /  |      |  점검  |      |          |          |     |

수행 표기 : 정 = 정상 2시간 / 비 = 비상판 15분 / 결 = 결석
오늘 A    : 짝수 날 남편, 홀수 날 아내. 날짜대로 적었는지 확인용
발화(분)  : 2~4블록에서 둘이 영어든 한국어든 소리 내어 말한 총 시간
드릴(장)  : 3블록에서 소화한 카드 장수
LRE       : 그날 세션 전체 합계
미해결    : 해결 못 한 항목 개수만. 내용은 2장에 적는다

주간 합계
  수행일 __ / 6      비상판 __일      결석 __일
  발화 합계 ___분    드릴 합계 ___장   LRE 합계 ___회
  누적 학습 시간 ____h  (지난주 누적 ____h + 이번 주 ____h)
```

### 1.1 경보 규칙

아래에 걸리면 그 주 주간 점검에서 원인을 적는다.
적기만 한다. 계획을 바꾸지 않는다. 방법론 변경 금지는 여기에도 적용된다.

| 경보 | 조건 | 조치 |
|---|---|---|
| 결석 연속 | 결 2일 연속 | 즉시 다음 날 비상판이라도 수행. 원인 기록 |
| 비상판 의존 | 비 2일 연속 | 경고 표시 |
| 비상판 과다 | 비 3일 이상 | 주간 점검에서 원인 기록 |
| 역할 미교대 | 오늘 A 칸이 날짜와 어긋남 | 다음 주 첫 세션에서 확인 |
| 드릴 정체 | 드릴 장수가 3주 연속 감소 | 압박형 시간 설정을 확인 |

LRE 횟수가 적은 것은 경보가 아니다.
그건 활동량이지 성과가 아니고, 조용한 주가 있는 게 정상이다.

## 2. 세션 LRE 기록표

대조 교차 4단계(기록 4분)에서 적는다.
세션마다 한 장이고, 미해결 항목은 5장 판정 세션으로 넘어간다.

```
[날짜]  __월 __일     [오늘 A] 남편 / 아내     [세션 회차] 제 ___회

LRE 합계 : ___회
  해결 ___  미해결 ___  보류 ___

-- 미해결 목록 (문장으로 적는다) ------------------------------

1) 우리가 말한 문장 :
   무엇이 걸렸나 :
   각자 생각 : 남편 -
               아내 -
   상태 : 미해결 / 보류

2) 우리가 말한 문장 :
   무엇이 걸렸나 :
   각자 생각 : 남편 -
               아내 -
   상태 : 미해결 / 보류

3) 우리가 말한 문장 :
   무엇이 걸렸나 :
   각자 생각 : 남편 -
               아내 -
   상태 : 미해결 / 보류

-- 오늘 채집한 표현 (외부 자료에서 본 것) ----------------------

표현 :
어디서 :
궁금한 점 :

--------------------------------------------------------------
3단계 규칙 : "틀렸다"를 쓰지 않는다. "나는 이렇게 이해했다"만 쓴다.
```

"각자 생각"을 비워 두지 마라.
두 사람 생각이 어떻게 갈렸는지가 판정할 때 제일 중요한 정보다.
같은 결론이면 "둘 다 같음"이라고만 적는다.

## 4. 분기 기록표

분기 마지막 주 주간 점검에 20분을 더해서 한다. 1년에 네 번이다.
이 대장에서 실력을 판정하는 칸은 여기뿐이다.

### 4.1 통과 조건 대조

트랙마다 따로 판정한다. 전부 통과해야 다음 분기로 가는 게 아니라,
통과한 트랙만 먼저 넘어간다.

```
[ Q__ 종료 점검 ]     [ __월 __일 ]     누적 학습 시간 ____h

Q1 조건 (누적 180h)
  축약 20종 청취 식별 90% 이상    맞힌 개수 __ / 20   ( ) 통과 ( ) 미통과
  강세 박자 재현                  상대 판정 __ / 10문장  ( ) 통과 ( ) 미통과
  되묻기 3형 자동 (2초 내)        __ / 3형           ( ) 통과 ( ) 미통과

Q2 조건 (누적 365h)
  고빈도 600청크 0.5초 인출       표본 50개 중 __개    ( ) 통과 ( ) 미통과
  90초 무중단 발화                최장 __초           ( ) 통과 ( ) 미통과
  자기수정 자연화                 3분 중 성공 __회     ( ) 통과 ( ) 미통과

Q3 조건 (누적 550h)
  3초 내 반응                     20문항 중 __개       ( ) 통과 ( ) 미통과
  LRE 세션당 8회 이상             분기 평균 __회       ( ) 통과 ( ) 미통과
  겹침 상황 처리                  10회 중 __회 복구    ( ) 통과 ( ) 미통과

Q4 조건 (누적 730h)
  3분 발화                        최장 __초           ( ) 통과 ( ) 미통과
  3레지스터 구분                  6문항 중 __개        ( ) 통과 ( ) 미통과
  대화 주도권 전환                10회 중 __회         ( ) 통과 ( ) 미통과

측정은 둘이 서로에게 한다. 재는 사람이 A, 재이는 사람이 B다.
같은 항목을 역할 바꿔 두 번 잰다. 둘 다 기록한다.
```

미통과 트랙은 그대로 그 분기에 남는다.
남는 게 지연이 아니라 설계다. 트랙마다 속도가 다른 게 정상이다.

### 4.2 관계 유형 점검

운영 매뉴얼 7.2 절차대로 각자 따로 적고 동시에 공개한 결과를 옮긴다.

```
[ Q__ ]   [ __월 __일 ]

항목            | 남편이 적은 것 | 아내가 적은 것 | 일치
----------------|----------------|----------------|------
1 발화 지분     |    __ : __     |    __ : __     |
2 주도권        | 남 / 아 / 비슷 | 남 / 아 / 비슷 |
3 수정 방향     | 남>아/아>남/양 | 남>아/아>남/양 |
4 질문 발생     | 남 / 아 / 비슷 | 남 / 아 / 비슷 |

신호 판정
  ( ) 발화 지분이 7대 3을 넘음
  ( ) 수정이 한 방향으로만 흐름
  ( ) 주도권이 두 분기 연속 같은 쪽
  ( ) 같은 항목에 두 사람 답이 반대

걸린 신호가 있으면 적용할 처방 (매뉴얼 7.4)
  ( ) 타이머 고정      ( ) 교정 횟수 상한
  ( ) 개시권 이양      ( ) 3단계 형식 강제

적용 시작일 : __월 __일       재점검일 : __월 __일 (2주 뒤)
재점검 결과 :
```

신호가 하나도 없어도 이 표는 매 분기 채운다.
변화를 보려면 정상일 때 값이 남아 있어야 한다.

## 5. 판정 세션 기록표

주 1회 고정. 입력은 둘이다.
미해결 LRE 목록(2장)과 채집 표현 목록(조준표 지시).

```
[ ____주차 판정 ]   [ __월 __일 ]

-- 올린 항목 --------------------------------------------------

번호 | 구분        | 내용 | 출처 | 궁금한 점
-----|-------------|------|------|-----------
  1  | LRE / 채집  |      |      |
  2  | LRE / 채집  |      |      |
  3  | LRE / 채집  |      |      |
  4  | LRE / 채집  |      |      |
  5  | LRE / 채집  |      |      |

채집 항목은 출처 없이 올리지 않는다. 출처가 없으면 판정이 안 된다.

-- 판정 결과 --------------------------------------------------

번호 | 판정 | 신뢰도 | 대체 표현 | 대장 반영
-----|------|--------|-----------|-----------
  1  |      | A/B/C  |           |
  2  |      | A/B/C  |           |
  3  |      | A/B/C  |           |
  4  |      | A/B/C  |           |
```

판정에 C가 붙으면 그건 내가 확답하지 않고 채집 조건만 주는 항목이다.

## 6. 누적 집계표

주간 점검에서 한 줄씩 채운다. 이 표만 봐도 완주 여부가 보인다.

```
주차 | 수행일 | 비상판 | 결석 | 주간 시간 | 누적 시간 | LRE 합 | 판정 건
-----|--------|--------|------|-----------|-----------|--------|--------
  1  |        |        |      |           |           |        |
  2  |        |        |      |           |           |        |
  3  |        |        |      |           |           |        |
  4  |        |        |      |           |           |        |
 ... |        |        |      |           |           |        |
 48  |        |        |      |           |           |        |

목표선
  12주  180h   24주  365h   36주  550h   48주  730h
```

이 표에서 볼 것은 누적 시간 한 줄이다.
잘하고 있는지가 궁금하면 실력이 아니라 이 숫자를 본다.
730시간을 채우는 것이 1년차의 전부다.
