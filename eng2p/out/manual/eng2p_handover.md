## 2. 어디서 여는가

```
https://chemistreal.github.io/study64-report/english.html
```

**암호가 없다. 아무나 볼 수 있다.** 그래서 저작권 있는 클립을 저장소에 안 넣는다.


## 3. 지금 당장 정해야 하는 것 둘

`docs/spec.md` 는 사용자만 고친다. 개정문 열세 건이 `docs/spec_amendments.md` 에 있다.
그중 **둘은 미루면 미룰수록 값이 커진다.**

### 5번. 블록 비중 Q1 45퍼센트

제작물 96편이 51퍼센트로 만들어졌고 검사기는 45로 잰다.
그래서 **Q1 경고 11건이 매번 난다.** 지금은 맞는 경고다.

기준서를 51로 고치거나 강의 96편을 다시 쓰거나 둘 중 하나다. 고치는 쪽을 제안한다.
45는 제로 시작 구간을 안 만들어 본 상태에서 잡은 값이고 51은 스물네 편을 만들어 본 실측이다.

**안 정하면 무엇이 나쁜가.** 경고 11건이 1년 내내 난다.
그 경고를 무시하는 습관이 생기는 것이 진짜 손해다. 다른 경고도 같이 안 보게 된다.

### 11번. 역할 교대를 날짜에서 세션 번호로

기준서 4장이 "매일 교대한다" 와 "짝수 날 남편 = A" 를 같이 적는다.
**뒷줄이 앞줄을 1년에 일곱 번 어긴다.** 31일로 끝나는 달의 다음 1일이다.
결석이 잦으면 더 자주 그렇다.

**붙는 순간 코드가 바뀐다.** 앱의 `roleOf` 와 세트 48편의 역할 문장이 같이 간다.
한 턴이 든다. 그것을 모르고 붙이면 그날 앱과 자료가 어긋난다.

나머지 열한 건은 미뤄도 쓰는 데 지장이 없다. 갈래별 표가 개정문 머리에 있다.

## 5. 고칠 때 지켜야 하는 것

**마크다운이 원본이고 나머지는 다 파생물이다.**
`out/data/*.js` 도 `out/handouts/*` 도 손으로 안 고친다.

```
python3 scripts/all.py
```

이 한 줄이 서른두 걸음을 정해진 순서로 돈다.
파생 열하나, 어긋남 하나, 규격 일곱, 대조 여덟, 화면 둘, 상태 셋이다.
**하나라도 실패하면 커밋하지 않는다.** 화면 검사와 리허설은 브라우저가 있어야 돈다.

```
node scripts/check_ui.js     화면이 그렇게 도는가
node scripts/rehearse.js     엿새를 실제로 돌고 화면 글을 옮겨 적는다
```

리허설은 검사가 아니다. **뽑힌 글을 사람이 읽는 것이 그 도구의 값이다.**

새 검사를 쓸 때 지킬 것이 둘 있다. 1년치 세션에서 되풀이 배운 것이다.

- **새 검사가 처음 내는 실패는 검사 자신을 먼저 의심한다.** 세 번 다 검사가 틀렸다
- **검사가 볼 자리는 두 사람이 읽는 자리다.** 도우미 함수를 부르면 고친 자리를 안 본다

## 6. 이 저장소가 자기를 지키는 방식

두 학습자가 영어를 모른다. **그래서 내 잘못을 아무도 못 잡는다.**
기준서 1.3 이 그것을 구조적 위험으로 적어 뒀고 검사기 열일곱이 그 자리를 메운다.

| 무엇을 지키는가 | 누가 |
|---|---|
| 글자 규칙과 등급 표시 | `check.py` 444편 |
| 기준서 자신 | `check_spec.py` 알고 있는 실패 둘 |
| 앱의 한국어 | `check_app.py` |
| 매뉴얼이 앱을 맞게 설명하는가 | `check_manual.py` |
| 파생물이 원본과 어긋났는가 | `check_derived.py` |
| 받은 것이 온전한가 | `derive_manifest.py`, `derive_media_manifest.py` |
| 영어 재료가 실제 대본에 있는가 | `ground.py`, `check_ground.py`, `check_ground_cite.py` |
| 주제 편중 | `check_rotation.py` 등록 118건 |
| 화면이 그렇게 도는가 | `check_ui.js` |

**이 목록에서 하나를 지우려면 왜 지우는지를 글로 적는다.** 지운 검사는 통과한 것처럼 보인다.

## 7. 남은 위험 넷

1. **실행 데이터가 없다.** 96편이 실제로 어떤지는 두 사람이 돌아 봐야 안다
2. **B등급 106건이 보류다.** 근거 없이 쓰는 표현 217개가 그대로 있다
3. **개정문 둘이 미결이다.** 5번은 경고를 계속 내고 11번은 역할을 이레 안 바꾼다
4. **영상은 망에 기댄다.** 저장소에 못 넣는다. 그래서 세션이 영상 없이도 끝나게 짰다
