# Q1 입력 조준표

기준서 10장 규격이다. 이 문서는 재료가 아니라 재료를 겨누는 방법이다.

음성은 내가 만들지 않는다. 만들 수 없다.
그래서 조준표가 하는 일은 하나다. 무엇을 찾으며 들을지 지정하는 것.
주목 없는 입력은 그냥 지나간다. 12주 동안 계속 지나가면 12주가 없어진다.

## 1. 재료 조건

| 항목 | Q1 조건 |
|---|---|
| 길이 | 2분에서 4분 |
| 속도 | 느림. VOA Level One 급 |
| 화자 수 | 1인에서 2인 |
| 주제 범위 | 일상, 집, 음식, 이동 |

화자 수 상한이 2인이다. 3인이 넘으면 누가 말하는지 가르는 데 주의가 다 간다.
Q1에서 주의는 소리에만 써야 한다.

길이를 4분으로 자른 이유는 3회 반복 때문이다.
4분짜리를 세 번 들으면 12분이고 그것이 블록 1 병렬 침묵의 절반이다.
더 길면 한 회차를 끝내기 전에 세션이 끝난다.

## 3. 대체 재료 유형 5종

저장소 안 12과가 모자라거나 지겨워지면 아래에서 가져온다.
조건은 1장 그대로다. 조건을 못 맞추면 안 쓴다.

| 유형 | 출처 | 라이선스 | 조건 충족 | 한계 |
|---|---|---|---|---|
| VOA Learning English Level One 기사 | learningenglish.voanews.com | 퍼블릭 도메인. 출처 표기 | 길이 2~4분, 느림, 대본 있음 | 낭독이라 겹침과 중단이 없다 |
| LibriVox 단편 낭독 | librivox.org | 퍼블릭 도메인 | 원문 텍스트가 붙는다 | 낭독체. 녹음 품질이 들쭉날쭉하다 |
| 교과서 부속 음원 | 학습자가 가진 교재 | 사적 이용 | 속도와 어휘가 통제돼 있다 | 대본이 교재 안에만 있다 |
| 느린 속도 뉴스 낭독 | VOA, BBC Learning English 등 | 각 사이트 표기를 따른다 | 속도가 느리고 원고가 붙는다 | 주제가 시사라 어휘가 튄다 |
| 동일 화자의 짧은 독백 | 위 출처에서 발췌 | 원 출처를 따른다 | 화자 1인이라 부담이 제일 적다 | 주고받는 자리가 없다 |

다섯 유형 다 1층이거나 낭독이다. 2층 자료는 Q1에 넣지 않는다.
2층은 Santa Barbara Corpus 를 Q2 3층 대조판부터 쓴다.
그 자료는 CC BY-ND 라 자르거나 편집해서 재배포하지 않는다. 원본을 그대로 듣는다.

C-gen 은 이 목록에 없다. 기계가 만든 음성은 1층 연습에만 쓰고 통과 판정에 안 쓴다.
`docs/audio_intake.md` 가 그 규격이다.

## 4. 반복 횟수와 회차별 청취 과제

같은 자료를 최소 3회 듣는다. 회차마다 찾을 것을 바꾼다.
과제는 항상 하나다. 한 번에 두 가지를 찾게 하지 않는다.

| 회차 | 초점 | 찾을 것 | 안 하는 것 |
|---|---|---|---|
| 1회 | 소리 | 어디가 줄었는지 | 무슨 말인지 묻지 않는다 |
| 2회 | 청크 | 통째로 굴러가는 덩어리 | 낱말로 쪼개지 않는다 |
| 3회 | 의미 | 내용 | 앞의 두 회차를 건너뛰지 않는다 |

Q1에서 의미는 3회차에만 온다. 1회차와 2회차에 뜻을 물으면 소리에서 주의가 빠진다.

강의가 지정하는 과제는 이보다 좁다. 12주치를 아래에 편다.

| 주차 | 강 | 회차 | 찾을 것 |
|---|---|---|---|
| 1주 | 01, 02 | 1회 | 소리로 살아남는 낱말 / 자음이 붙어 지나가는 자리 |
| 2주 | 03, 04 | 1회 | 낱말이 끝나는 자리 / l 이 나오는 자리 |
| 3주 | 05, 06 | 1회 | s 가 나오는 자리 / 어떤 형태로도 받아 적지 않기 |
| 4주 | 07, 08 | 1회 | to 가 앞에 붙는 자리 / to 앞에서 소리가 바뀌는 자리 |
| 5주 | 09, 10 | 1회 | of 가 들어갈 자리 / 낱말 경계가 붙는 자리 |
| 6주 | 11, 12 | 1회 | 낱말이 붙어 지나가는 자리 / 흐릿하게 지나가는 자리 |
| 7주 | 13, 14 | 2회 | 살아남는 낱말만 받아 적기 / 제일 세게 들리는 낱말 하나 |
| 8주 | 15, 16 | 2회 | 문장 끝의 방향 / 통째로 굴러가는 덩어리 |
| 9주 | 17, 18 | 2회 | 통째로 굴러가는 자리 / 부탁하고 응답하는 자리 |
| 10주 | 19, 20 | 2회 | 서로 확인하는 자리 / 화자 사이의 거리 |
| 11주 | 21, 22 | 2회 | 말하다 고쳐 잡는 자리 / 시간과 장소가 붙는 자리 |
| 12주 | 23, 24 | 2회 | 말이 멈추는 자리와 채우는 것 / 대화가 열리고 닫히는 자리 |

3회차는 12주 안에 배정하지 않았다.
12주를 다 돌고 나서 앱의 회전 탭이 3회차를 순서대로 낸다.
Q1 통과 조건에 의미 항목이 없으므로 3회차는 분기 판정에 안 들어간다.

## 5. 채집 지시

채집은 2층 자료를 모으는 일을 겸한다. 특히 대화가 끊기고 고쳐지는 자리다.
저장소 안 12과는 낭독이라 그런 자리가 없다. 그래서 밖에서 모아 와야 한다.

주마다 하나씩 적어 온다. 다섯 줄 넘게 적지 않는다.

| 주차 | 적어 올 것 |
|---|---|
| 1주 | 영어 소리가 들린 자리에서 어느 낱말이 제일 크게 들렸는지 하나 |
| 2주 | 끝 자음 뒤에 소리가 안 붙는 것을 확인한 낱말 하나 |
| 3주 | s 와 sh 가 갈리는지 안 갈리는지 판단이 선 낱말 하나 |
| 4주 | 축약형이 실제로 들린 자리 하나. 어떤 형태였는지 적는다 |
| 5주 | 낱말 수를 못 세겠던 덩어리 하나 |
| 6주 | 같은 철자가 두 소리로 난 낱말 하나 |
| 7주 | 내용어만 듣고 뜻이 잡힌 문장 하나 |
| 8주 | 끝 방향으로 뜻이 갈린 문장 하나 |
| 9주 | 실제로 들은 인사나 부탁 덩어리 하나 |
| 10주 | **누군가 되묻는 것을 본 자리.** 어떤 형태였는지 그대로 적는다 |
| 11주 | **누군가 말하다 고쳐 잡는 것을 본 자리.** 그대로 적는다 |
| 12주 | **누군가 말이 막혀 시간을 버는 것을 본 자리.** 그대로 적는다 |

10주, 11주, 12주 것이 2층 자료 채집이다. 굵게 표시한 이유가 그것이다.
영어 대화가 아니어도 된다. 영상이든 실제 자리든 상관없다.
지어내지 않고 본 것을 그대로 적는다. 그것만 지키면 된다.

적어 온 것은 판정하지 않는다. 모으기만 한다.
Q2 3층 대조판을 만들 때 이 목록이 재료가 된다.

## 6. 상호 확인 절차

혼자 듣고 끝내지 않는다. 매 회차에 아래를 한다.

| 회차 | 확인 방법 |
|---|---|
| 1회 | 각자 표시한 지점을 대조한다. 겹치는 지점과 안 겹치는 지점을 센다 |
| 2회 | 각자 덩어리를 세 개씩 적고 겹치는 것을 본다 |
| 3회 | 한 사람이 요약하고 다른 사람이 보탠다 |

1회차 대조에서 안 겹치는 지점이 많으면 그 자료를 한 번 더 듣는다.
많다는 것은 표시 지점의 절반을 넘는다는 뜻이다.

2회차에서 세 덩어리가 하나도 안 겹치면 덩어리 판정 기준이 아직 안 잡힌 것이다.
16강 통과 기준의 네 번째 항목이 그 판정이다. 그 항목을 다시 잰다.

3회차 요약에서 두 사람의 요약이 어긋나면 그것을 미해결 LRE 로 적는다.
누가 맞았는지 정하지 않는다. 어긋났다는 사실만 기록한다.

## 7. 쓰는 순서

```
1. 이번 주 강의 두 편의 블록 4에서 미디어 id 를 확인한다
2. 4장 표에서 이번 주 찾을 것을 확인한다
3. 블록 1 병렬 침묵에서 각자 헤드폰으로 반복해 듣는다
4. 블록 4 공동 입력에서 같이 듣고 6장 절차로 대조한다
5. 5장의 채집 지시를 한 줄 적어 둔다
6. 주간 점검에서 채집한 것을 모은다
```

앱에서는 자료 탭이 1장부터 3장까지를 보여 주고
회전 탭이 회차 진행을 관리한다. 종이로 쓸 때는 이 문서를 그대로 쓴다.

## 8. 안 하는 것

- 자막을 켜고 듣기. 1회차와 2회차는 소리만이다
- 대본을 먼저 읽고 듣기. 순서가 반대다
- 한 번에 두 가지 찾기. 과제는 항상 하나다
- 3회차 없이 다음 자료로 넘어가기
- C-gen 음성으로 Q1 소리 트랙 통과 판정하기
- 조건에 안 맞는 재료를 그냥 쓰기. 화자 3인 이상이면 Q1에서 뺀다
