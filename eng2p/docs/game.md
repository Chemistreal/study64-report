# 게임으로 바꾼다. 호놀룰루에서 사는 1년

신뢰도: A 생성 (설계)
상위 규격: docs/spec.md / docs/blocks.md / docs/play_blocks.md
작성일: 2026-10-07

## 1. 결정

**게임이 모든 공부를 대체한다.** 사용자가 2026-10-07 에 정했다.
하루 2시간, 주 엿새, 48주, 288세션이 그대로 게임 속 1년이 된다.

앱(`english.html`)은 두 사람 앞에서 물러난다. 대신 **두뇌로 남는다.**
그날 무엇을 하는지를 정하는 셈과 지금까지 만든 자료가 전부 앱 쪽에 있고,
그것을 게임 안에서 다시 짜면 두 벌이 되고 언젠가 어긋난다 (T396).

    앱의 셈과 자료  ->  out/game/sessions.json  ->  언리얼 게임
                                                     |
    앱의 대장       <-  결과 JSON  <------------------+

게임은 그날 할 일을 스스로 정하지 않는다. **세션 JSON 을 받아서 그린다.**

## 2. 지키는 것

| 규칙 | 게임에서 |
|---|---|
| 확신 없는 영어를 짓지 않는다 | NPC 대사는 전부 고정이다. 세션 JSON 과 `out/data` 에 있는 것만 말한다 |
| 슬랭 금지 | 표준 미국 영어. 하와이 현지 말투는 안 쓴다 |
| C-gen 은 1층 전용 | NPC 목소리는 TTS 라 연습용이다. 소리 판정은 52과 실제 녹음으로만 한다 |
| 판정은 사람이 한다 | 게임이 발음을 채점하지 않는다. **상대가 알아들었다** 를 파트너가 누른다 |
| 1인 지시 금지 | 모든 미션이 둘이 있어야 풀린다 |
| 실제 상표와 인물 금지 | 가게와 사람은 다 가상이다 |

## 3. 하루가 어떻게 생겼나

블록 넷이 하루 일과가 된다. 분은 그대로다.

| 블록 | 분 | 지금 앱 | 게임 속 |
|---|---|---|---|
| 1 | 40 | 각자 듣기. 서로 안 본다 | 아침. **둘이 다른 곳에 있다.** 그날 과 녹음이 라디오와 TV 와 옆 사람 말로 들린다. 수첩에 찾은 것을 적는다 |
| 2 | 30 | 세트로 맞춰 본다 | 점심. 둘이 만나 수첩을 편다. 강의는 멘토 NPC 가 짧게 전하고 전문은 가이드북에 있다 |
| 3 | 30 | 카드와 판 | 오후. 동네 일을 본다. 카드가 NPC 만남이 되고 판이 협동 미니게임이 된다 |
| 4 | 20 | 같이 듣고 적는다 | 저녁. 숙소에서 같이 듣고 일기를 쓴다. 그것이 그날 기록이다 |

비상판 15분은 **바쁜 날**이다. 숙소 앞에서 짧은 심부름 하나를 한다.

## 4. 무대

**지도는 하나고 분기마다 넓어진다.** 마흔여덟 동네를 안 만든다.
같은 장소를 다음 분기에 다른 시간과 다른 사람으로 다시 쓴다.

이 표가 원본이다. `scripts/derive_game.js` 가 읽는다.

| 분기 | 무대 | 블록 1 A | 블록 1 B | 블록 2 | 블록 3 | 블록 4 |
|---|---|---|---|---|---|---|
| Q1 | 도착 | 숙소 방 | 버스 정류장 | 로비 카페 | 편의점 | 숙소 방 |
| Q2 | 동네 | 동네 도서관 | 공원 벤치 | 시장 식당 | 시장 | 숙소 방 |
| Q3 | 일과 사람 | 사무실 휴게실 | 통근 버스 | 직원 식당 | 사무실 | 숙소 방 |
| Q4 | 정착 | 새 집 | 해변 산책로 | 이웃집 | 동네 모임 | 새 집 |

블록 1 은 A 와 B 가 **다른 곳**에 있다. 각자 듣기라 서로 안 보는 것이 규칙이고
게임에서는 그것이 거리로 선다.

## 5. 자료가 어디로 가나

| 자료 | 수 | 게임 속 |
|---|---|---|
| 강의 | 96 | 멘토 브리핑과 가이드북. 전문은 가이드북에서 읽는다 |
| 강의록 | 96 | 가이드북의 한 장 |
| 세트 | 288 | 그날 블록 2 의 맞춰 보기 절차 |
| 카드 | 600 | 블록 3 의 NPC 만남. 유형 다섯이 장르가 된다 |
| 대본과 녹음 | 52과 | 동네 라디오와 TV. **실제 사람 목소리다** |
| 조준표 | 4권 | 주마다 수첩 미션 |
| 과제집 | 48주 | 주말 숙제 |
| 비상판 | 80 | 바쁜 날 심부름 |
| 판 | 20 | 협동 미니게임. 그날 덱은 세션 JSON 에 미리 뽑혀 있다 |
| 퀘스트 배지 연속일 회복권 | | 주간 협동 퀘스트와 업적과 거주 일수 |
| 분기 점검 | 4 | 분기 끝의 큰 장면. 비자 연장 면접 같은 것 |

카드 유형은 이렇게 간다.

| 유형 | 장면 |
|---|---|
| 판정형 | 점원이 맞는지 확인해 준다. 정답은 A 화면에만 |
| 압박형 | 시간이 있다. 버스 문이 닫힌다 |
| 확장형 | 같은 가게에서 다른 날 다른 주문 |
| 역할형 | 상황 관계 목적 격식 끝 조건 다섯이 **원래 퀘스트 명세다** |
| repair형 | NPC 가 웅얼거리거나 끊는다. 되물어야 풀린다. 실패가 정상이다 |

## 6. 덱을 미리 뽑는 까닭

판이 그날 낼 것을 게임이 다시 뽑으면 앱의 `roundPick` 을 C++ 로 한 벌 더 짜야 한다.
**미리 뽑아 세션 JSON 에 넣는다.** 두 PC 가 같은 파일을 읽으니
망으로 맞추지 않아도 둘이 같은 덱을 본다.

뽑을 때 시작일을 `2026-08-10` 으로 둔다. 덱은 세션 번호로 정해지므로
실제 시작일이 달라도 같은 세션에는 같은 덱이 간다.

A 와 B 를 누가 맡는지는 미리 안 정한다. 지금처럼 그날 날짜로 정한다
(`index.json` 의 역할 규칙). 게임이 그날 정한다.

## 7. 안 넘어가는 것

| 무엇 | 왜 |
|---|---|
| 강의 본문을 게임 안에서 길게 읽기 | 편당 3천 자다. 가이드북으로 두고 멘토는 짧게 말한다 |
| 카드 600장마다 장면 | 장소와 NPC 를 다시 쓴다. 역할형과 repair형만 장면으로 짓는다 |
| NPC 자유 대화 | 아직 안 정했다. 정하기 전에는 **안 넣는다** |
