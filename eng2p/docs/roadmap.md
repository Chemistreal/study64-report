검사는 매 턴 끝에 여섯 개를 돌린다. 하나라도 실패면 그 턴은 안 끝난 것이다.

```bash
python3 eng2p/scripts/check.py eng2p/out/

python3 eng2p/scripts/check_cards_plan.py
python3 eng2p/scripts/check_blocks.py

```

검사기가 늘어난 것은 매번 사람이 못 본 것을 하나씩 잡았기 때문이다.
check_media 는 조수가 화자 수를 낮춰 통과한 것을 잡았고,

검사기를 늘리는 쪽이 눈으로 다시 보는 쪽보다 언제나 싸다.

Q3는 개수를 통과 조건으로 잡는다. 그러면 일부러 만들어야 한다.

61강이 그것을 다룬다. 자동화 트랙에 넣은 이유가 있다.
LRE 는 막히는 자리에서 생기고 막히는 자리는 인출이 안 되는 자리다.
자동화 진단과 같은 자리를 다른 눈으로 보는 것이다.

**개수를 목표로 잡으면 형식적으로 채우게 된다.** 그 위험을 61강에 적는다.
해결한 LRE 와 미해결 LRE 를 갈라 세고 미해결이 절반을 넘으면 8회를 못 채운 것으로 본다.

### 11.1 왜 100턴을 더 쓰는가

강의 96편을 다 쓴 자리에서 사용자가 편의성이 떨어진다고 했다. 확인해 보니 맞다.
**지금 산출물은 마크다운 파일 더미이고 그것은 대화 세션이 주는 것과 같은 형태다.**

앱을 열어 확인한 것이다.

| 자리 | 지금 | 문제 |
|---|---|---|
| 학습자가 펴 놓을 것 | 없다 | 강의 파일은 제작 설계서다. 블록 3과 4가 제작 지시라 세션 중에 못 쓴다 |
| 앱이 아는 자료 | 없다 | renderDocs 가 GitHub 링크만 던진다. 96편도 600장도 288개도 앱 밖이다 |
| 복습 탭 | LRE 만 돈다 | 커리큘럼 카드 600장을 앱이 모른다 |
| 첫 페이지 | 입력 폼이다 | 오늘 몇 강인지 어느 카드인지가 화면에 없다 |
| 영상 | 라이브러리 탭에만 있다 | 세션 흐름에 안 붙어 있고 구간 반복이 안 된다 |
| B등급 | 96건 전부 보류 | 확인 안 된 그럴듯함 |

### 11.2 영상에 대해 먼저 확인한 사실

계획을 짜기 전에 재 봤다. 짐작으로 계획을 세우면 그 계획이 틀린다.

| 확인 | 값 |
|---|---|
| 앱이 이미 영상을 재생하는가 | **한다.** renderLibPlay 가 `video` 요소를 만들어 catalog 의 video 를 건다 |
| 어디서만 되는가 | 미디어 탭 하나. 세션 블록에 안 붙어 있다 |
| 원격 재생이 되는가 | 된다. `access-control-allow-origin: *` 이고 range 요청을 받는다 |
| 영상을 저장소에 넣을 수 있는가 | **못 넣는다.** 1과 15.7MB, 21과 19.2MB, 45과 24.6MB다 |
| 52개면 | 1GB 를 넘는다. 저장소가 지금 164MB 이고 GitHub Pages 한도에 걸린다 |
| 소리는 | 52개 53MB 가 이미 로컬에 있다 |

그래서 방향이 정해진다.

**영상 파일은 안 받아 온다. 원격 주소를 앱 안에서 재생한다.**
링크로 새 창을 여는 것이 아니라 세션 화면 안에서 돈다. 그 차이가 사용자가 말한 것이다.
range 를 받으므로 구간 반복과 배속도 원격 파일에서 된다.

**그리고 소리는 망 없이 되고 영상은 망이 있어야 한다.**
세션 설계가 이 사실을 알아야 한다. 블록 1 소리 입력은 mp3 로 돌리고
영상은 블록 4 공동 입력에만 건다. 망이 끊기면 영상 자리가 소리로 내려간다.

### 11.12 이 계획의 위험

넷을 미리 적어 둔다.

1. **E구간이 제일 크고 제일 불확실하다.** 20턴이 모자랄 수 있다.
   모자라면 블록 5 카드 뷰어까지만 하고 나머지는 링크로 둔다.
   카드가 제일 자주 쓰이고 A면 B면 규칙이 거기 걸리기 때문에 그 순서다.
2. **F구간 대본 동기는 재료가 있는지 아직 모른다.** 11.9 에 대안 셋을 적어 뒀다.
   시간 표시가 없으면 어림으로 가고 **어림이라고 화면에 적는다.**
3. **영상은 망에 기댄다.** 저장소에 못 넣는 것이 확인된 사실이라 다른 길이 없다.
   그래서 세션이 영상 없이도 끝나게 짠다. T134 가 그 일이다.
4. **G구간은 검증이 아니라 근거 붙이기다.** A등급 승급은 사용자가 대화 세션에서 한다.
   **그 경계를 안 넘는다.**
