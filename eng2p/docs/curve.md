# 난이도 곡선. 등급 구간에 맞추기

신뢰도: B (낱말 종류는 영문 소문자 낱말꼴의 수다. 어간 처리를 안 했다. 카드 분은 종이 기준 추정이다. 표는 `scripts/check_curve.py` 가 다시 센 값과 견준다)
검증로그: 2026-10-12 / 사용자 결정 "난이도 등급에는 맞춰줘" 를 H1 감사 1.2 의 같은 계산으로 세었다 / 부분 통과 / 카드 쪽 지표 셋은 A1 에서 B2 로 오른다. 새 낱말 종류는 역방향이고 자료를 옮겨서는 못 고친다. 까닭과 필요한 새 콘텐츠를 아래에 계산했다
상위 규격: docs/spec.md 2.1, 8.1 / docs/game_data.md 11장 (등급 구간) / docs/parts/H1_learning_design_audit.md 1.2

등급 구간은 `out/game/acts.json` 이다 (A1 1~50, A2 51~100, B1 101~200, B2 201~288). 이 문서는 그 구간을 안 옮긴다.
새 낱말 종류는 세션 s 에서 처음 나오는 영어 낱말의 수다. 녹음 대본(그 과가 처음 쓰인 날), 카드 재료(카드가 처음 나온 날), 나들이 미션 줄(미션이 열리는 날)의 합집합을 센다. H1 감사 4장 `b6` 과 같은 정의다.

## 2. 왜 자료를 옮겨서는 못 고치나

계산한 것을 적는다. 추측이 아니다.

1. **A1 에 이미 바닥이 있다.** A1 의 카드와 나들이 미션이 처음 내는 낱말만 세어도 세션당 약 9.9종이다 (카드 재료 327종과 미션 줄 270종의 합집합 497종 나누기 50). 1년 전체 평균이 세션당 6.5종이다. 모든 구간을 A1 바닥 이상으로 올리려면 공급이 모자란다.
2. **첫 공개 1~48 규칙이 A1 의 미션을 묶는다.** 나들이 미션 18개는 모두 세션 48 이하에서 열린다 (`release.throughSession` 48, `derive_outings.py` 가 지킨다). A1 에서 빼 낼 수 없다.
3. **녹음 과와 카드는 강에 묶여 있다.** 강 96편의 블록 4(드릴 연결)가 카드 번호와 "미디어는 lle1-NN 을 쓴다" 를 직접 적는다. 강 순서는 강 본문의 "12강에서" 같은 참조, 분기 통과 조건, 주 이야기가 쥔다. 새 낱말을 뒤로 미루려면 녹음 과를 다른 강에 붙여야 하는데 그러면 강 본문이 거짓이 된다. 세트 열다섯 개도 과 번호를 적는다.
4. **나들이 미션은 지금 A1 18개뿐이다.** A2 이후 미션이 없어서 미션 쪽으로는 구간 B1 B2 를 못 올린다.

그래서 이 개정에서는 **곡선 자료를 안 옮겼다.** 옮겨서 얻는 것과 잃는 것을 가정으로 계산했다.

## 3. 가정 계산. 녹음 과를 다르게 붙이면 (적용하지 않았다)

강은 그대로 두고 강마다 붙는 녹음 과만 다시 정한다. 과는 앞 카드와 미션이 이미 낸 낱말을 빼고 새 낱말이 적은 것부터 들어온다. 구간마다 새 과가 들어오는 수를 바꿔 본다.
`python3 scripts/report_curve.py --md whatif` 가 낸다.

- 가장 좋은 줄(4 6 16 26)도 A1 은 10.5 에서 안 내려간다 (2장 1번의 바닥). A2 부터는 오른다 (3.8, 4.4, 8.1).
- 잃는 것: 강 블록 4 의 "미디어는 lle1-NN 을 쓴다" 가 대부분 거짓이 된다. 나들이 줄의 "이미 들은 낱말" 기준(`authored_lib.heard_vocab`)이 세션의 녹음 과로 정해지므로 줄마다 새 낱말 상한(`authored_lib.py` 의 줄당 4개)을 다시 확인해야 한다. 강 본문을 고치는 것은 사용자 결정이다.
- 그래서 **자료를 옮기지 않았다.** 사용자가 강 블록 4 의 미디어 문장을 고쳐도 된다고 하면 위 줄로 옮길 수 있다.

## 4. 곡선을 내려가지 않게 하려면 새 콘텐츠가 얼마나 필요한가

가정 계산이다. 새로 짓지 않았다. 목표 둘 중 하나를 고르면 된다.

<!-- gen:need -->
| 목표 | 세션당 목표 | A2 에서 더 필요한 종류 | B1 | B2 | 합 |
|---|---|---|---|---|---|
| 가) A1 수준으로 평평 | 16.3 | 375 | 1340 | 1105 | 2820 |
| 나) A2 수준으로 평평 (A2 부터) | 8.8 | 0 | 590 | 445 | 1035 |

**종류를 콘텐츠 개수로 바꾸면.** 확장층 LLE2 30과는 핵심 어휘 밖의 새 낱말을 906종 가져온다 (과당 30.2종, 이미 있는 실제 대본).
합 2820종은 그런 과로 약 93과 어치다. 나들이 미션으로 채운다면 미션 하나가 처음 내는 낱말이 평균 7.4종이라 약 382개다 (지금 18개).
<!-- /gen:need -->

- (가) 는 A1 의 값으로 모든 구간을 올리는 것이다. 2,820종이면 지금 곡선이 반복된다는 뜻이라 현실적이지 않다.
- (나) 는 A2 에서 B2 까지만 안 내려가게 하는 것이다. B1 에 590종, B2 에 445종이 모자란다. 확장층(`docs/expansion.md`)의 LLE2 30과를 핵심에 넣으면 906종이다 (주 25~48 에 놓인 대본이 이미 있다).
  그 대본은 새로 짓지 않았다. 다만 핵심 하루에 넣는 것은 설계 변경이라 사용자 결정이다. 블록 4 의 남는 시간이 Q2 이후 2분뿐이라 들어갈 자리는 블록 1 이나 일요일이다.

**어느 구간에 어떤 콘텐츠가 몇 개 더 필요한가.**

| 구간 | 필요한 새 낱말 종류 (나 목표) | 콘텐츠로 바꾸면 |
|---|---|---|
| A1 | 0 | 없음 |
| A2 | 0 | 없음 (A2 가 기준이다) |
| B1 (101~200) | 590 | LLE2 급 대본 약 20과, 또는 B1 나들이 미션 약 80개 |
| B2 (201~288) | 445 | LLE2 급 대본 약 15과, 또는 B2 나들이 미션 약 60개 |

## 5. 사용자가 정할 것

1. 곡선을 어디까지 맞출지. (나) 목표(A2 부터 안 내려감)면 B1 B2 에 새 대본 약 34과가 필요하다. 확장층 LLE2 30과를 핵심으로 올리면 거의 채워진다.
2. 강 블록 4 의 미디어 문장을 고쳐 녹음 과를 옮겨도 되는지 (3장). 옮기면 A1 이 16.3 에서 10.5 로 내려가고 A2 이후가 오른다. 거짓이 되는 강 문장을 고쳐야 한다.
3. 나들이 미션을 A2 이후로 늘릴지 (계획은 55개이고 지금 18개다. `docs/outings.md`).

## 6. 검사

`check_curve.py` 가 이 문서의 표 넷을 다시 세어 견준다. 그리고 두 가지를 못 박는다: 카드 쪽 지표 셋(블록 3 예상 소요, 처음 나온 카드 분, 역할형 비중)은 A1 에서 B2 로 올라야 하고,
새 낱말 종류의 역방향 폭은 이 문서의 13.4 를 넘으면 안 된다. 폭이 줄면 이 문서의 폭과 표를 고쳐야 통과한다. 알려진 어긋남을 숨기지 않고 더 나빠지는 것만 막는 자리다.
