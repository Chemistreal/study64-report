# 마찰 측정 기록

신뢰도: A 생성 (측정 기록)
상위 규격: docs/roadmap.md 12.10 A단계
측정일: 2026-08-08 (T159)

앱을 열고 무엇을 하기까지 몇 번 누르고 몇 초 걸리는지 잰 것이다.
**고치기 전에 잰다.** 안 재고 고치면 좋아졌는지 알 수 없고, 나중에 나빠져도 모른다.

재는 방법은 `scripts/check_friction.py` 가 그대로 다시 돌린다.
이 문서의 숫자가 그 검사의 기준선이다. **늘면 실패다.**

## 2. 세션 시작까지

| 길 | 누름 | 입력칸 | 첫 그림 | 세션이 돌기까지 |
|---|---|---|---|---|
| 처음 여는 사람 | 2 | 3 | 1017ms | 1622ms |
| 이튿날 | **1** | 0 | 516ms | 866ms |
| 끊긴 데서 이어 | **1** | 0 | 538ms | 895ms |

**내 진단이 틀렸다.**

로드맵 12.6 에 "세션 시작까지 여러 번 누른다"고 적었다. 재 보니 **한 번이다.**
2차 로드맵 D구간에서 원탭 시작을 이미 넣었고 그것이 제대로 돌고 있다.
끊긴 세션도 "이어서 하기" 단추 한 번으로 그 블록으로 돌아간다.

**여기는 고칠 것이 없다.** 지키기만 하면 된다.
그래서 이 셋이 `check_friction.py` 의 첫 세 줄이 된다. 늘면 실패다.

## 3. 첫 화면의 부피

| | 390px | 900px |
|---|---|---|
| 문서 높이 | 4262px | 3145px |
| 화면 몇 개분 | **5.0** | 3.7 |
| 세션 판 하나 높이 | 2592px | |
| 큰 단추 위치 | 300px (첫 화면 안) | 246px |
| 시계 위치 | **1165px** | |
| 누를 것 전체 | **70개** | 70개 |
| 첫 화면에 보이는 누를 것 | 14개 | 18개 |
| 첫 화면 제목 | 오늘, 33강 | 오늘, 33강 |

**여기가 걸린다.**

오늘 화면 하나가 손전화에서 다섯 화면이다. 세션 판 하나가 2592px 이다.
그리고 **시작 단추와 시계가 865px 떨어져 있다.**
시작을 누르면 화면이 통째로 미끄러진다. 지금은 그것을 부드럽게 미는 것으로 덮고 있다.
덮는 것과 없는 것은 다르다.

누를 것이 화면 하나에 70개다. 그중 열넷이 첫 화면에 있다.
Pimsleur 가 하나만 두는 자리에 열넷이 있다.

## 5. 오늘 것에 닿기까지

**이것이 T159 에서 나온 제일 큰 것이다.**

오늘 칸은 여섯 가지를 알려 준다.

```
33강 빠른 속도에 적응하는 법
Q2 · 소리 트랙 · 17주 3일째 · 오늘이 99번째 세션이다
세트 Q2-099 / 카드 049 ~ 054 / 미디어 lle1-40 / 과제 250자 / 비상판 29
```

그 칸 안에서 누를 수 있는 것이 **0개다.**

| 오늘 것 | 앱이 데려다주는가 | 사람이 하는 일 |
|---|---|---|
| 33강 본문 | 아니오 | 자료 탭(2번) 열고 96편에서 33강을 찾는다 |
| 세트 Q2-099 | 아니오 | 자료 탭에서 288편 중 찾는다 |
| 카드 049 ~ 054 | 아니오 | 복습 탭에서 600장 중 찾는다 |
| 미디어 lle1-40 | 아니오 | 미디어 탭에서 52개 중 찾는다 |
| 과제 250자 | 해당 없음 | 숫자다 |
| 비상판 29 | 예 | 오늘 화면에서 펴진다 |

**여섯 중 하나만 닿는다.**

미디어 탭은 52개가 다 펼쳐져 있어 문서 높이가 21540px 이다. **25.5 화면이다.**
검색칸이 있으니 `lle1-40` 을 쳐서 갈 수는 있다. 그런데 그것은 앱이 이미 아는 값이다.
**앱이 오늘 무엇인지 알면서 사람에게 그것을 찾아오라고 시키고 있다.**

이것은 누름 횟수의 문제가 아니다. 누름은 두세 번이다.
문제는 **화면이 알려 준 것과 화면이 열어 주는 것이 이어져 있지 않다는 것**이다.
두 사람이 앉아서 "33강이 어디 있지"를 매일 한다. 그것이 하루 이 분이면 1년에 열여섯 시간이다.

## 6. 그래서 A단계가 무엇을 고치는가

측정이 계획을 고쳤다. 로드맵 12.10 을 이 결과로 다시 잡는다.

| 원래 계획 | 측정 결과 | 바뀐 것 |
|---|---|---|
| 세션 시작을 한 번 누름으로 (T168) | **이미 한 번이다** | 지키는 검사로 바꾼다 |
| 이어 하기 (T169) | **이미 된다** | 지키는 검사로 바꾼다 |
| 첫 화면 새로 (T166) | 5화면, 누를 것 70개 | 그대로 간다. 더 급해졌다 |
| (없었다) | **오늘 것 여섯 중 하나만 닿는다** | **새로 넣는다. 오늘 칸을 누를 수 있게** |

**빈 자리에서 재 보니 안 급한 것과 급한 것이 뒤바뀌었다.**
안 재고 계획대로 갔으면 이미 되어 있는 것에 두 턴을 쓰고,
매일 걸리는 자리는 계획에 아예 없는 채로 지나갔을 것이다.
