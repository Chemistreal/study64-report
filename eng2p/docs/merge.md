# 합치기. 둘이 다른 값을 들고 만났을 때 무엇을 남기는가

신뢰도: A 생성 (규격)
상위 규격: docs/pair.md / docs/roadmap.md 12.13 D단계
작성일: 2026-08-09 (T237)

검증로그: 2026-08-09 / 저장소의 값 열아홉을 갈래로 나누고 갈래마다 합치는 법을 정했다 / 통과 / 자동으로 못 정하는 것 넷은 사람에게 묻는다

## 1. 지금은 덮는다

`docs/pair.md` 5장과 6장이 이렇게 적었다.

> 나중에 JSON 을 가져온다 → **덮어쓴다.** 합치지 않는다.
> **가져오기는 덮는 것이고 합치는 것이 아니다.** 합치는 자리를 따로 만든다.

`imFile` 이 `S=o` 한 줄로 통째로 바꾼다. T184 에 되돌리기를 붙였지만
**되돌리는 것과 합치는 것은 다르다.** 되돌리면 가져온 것이 없어진다.

덮으면 무엇을 잃는가. 제일 아픈 것이 **적어 둔 글**이다.

| 잃는 것 | 어디 |
|---|---|
| 미해결 LRE 문장 | `days[].unres` |
| 채집한 문장 | `days[].coll` |
| 블록 1과 4에 적은 것 | `days[].aim` |
| 블록 2 상호 검토에 적은 것 | `days[].xchk` |
| 주간 점검에 적은 것 | `wchk` |

두 사람이 각자 적은 것이라 **한쪽만 남기면 절반이 없어진다.**
셈은 다시 셀 수 있고 글은 못 그런다.

## 2. 갈래 넷

저장소의 값마다 합치는 법이 다르다. 넷으로 나눈다.

| 갈래 | 어떻게 | 왜 |
|---|---|---|
| **안 건너감** | 이 기기 것을 그대로 둔다 | 그 기기에서 무엇을 보고 있는가는 그 기기의 일 |
| **큰 것** | 둘 중 큰 값 | 안 한 쪽이 0이다. 진도는 뒤로 안 간다 |
| **모음** | 둘을 합쳐 겹친 것을 뺀다 | 각자 적은 글이다. 한쪽만 남기면 절반이 없어진다 |
| **물음** | 자동으로 안 정한다. 사람이 고른다 | 둘 다 값이 있고 다르면 어느 쪽이 맞는지 기계가 모른다 |

**넷째가 제일 중요하다.** 자동으로 정할 수 없는 것을 자동으로 정하면
그것이 덮는 것과 같아진다. 조용하다는 것만 다르다.

## 3. 값마다 어느 갈래인가

### 3.1 안 건너가는 것

`docs/pair.md` 3장이 정한 여섯이다. 여기에 하나도 안 늘린다.

| 값 | 무엇 |
|---|---|
| `device` | 이 기기를 누가 쓰는가 |
| `fs` | 글자 크기 |
| `session` | 끊긴 세션 이어 하기 |
| `card` | 보던 카드 자리 |
| `wk` | 대장에서 보던 주 |
| `cardMode` | 카드 고르는 꼴 |
| `rate` | 배속 |
| `recOpen` `emgOpen` `onboarded` | 화면 여닫이 |
| `solo` `soloSeat` `soloHand` | **돌려 보기.** 기기가 하나인 날의 절차 (T241) |
| `veiled` | **즉시 가리기.** 지금 이 화면이 덮여 있나 (T244) |
| `rstep` `rseat` | **판의 회 번호와 지난번 자리.** 각자 센다 (T247) |

`veil` 은 저장소에 없다. 세션 안에서만 산다. 그래서 여기 안 적는다.

### 3.2 큰 것

| 값 | 왜 큰 것인가 |
|---|---|
| `days[].speak` `cards` `lre` `h` | 안 적은 기기가 0이다 |
| `media.lec[강]` | 회차는 뒤로 안 간다. 1회차를 끝냈으면 끝난 것이다 |
| `media.pass[과]` | **셈이 아니라 회차 켜짐표다.** 아래를 본다 |
| `media.done[과]` `fav[과]` | 켜짐이다. 한쪽에서 켰으면 켜진 것이다 |
| `cardDue[카드]` | **늦은 날짜.** 늦다는 것은 누군가 그 카드를 돌렸다는 뜻이다 |

`cardDue` 만 방향이 반대로 보인다. 이른 날짜를 고르면 이미 돌린 카드를 또 돌린다.
**돌린 일을 무르지 않는다.**

`media.pass[과]` 는 `{1:true, 2:true}` 꼴이다. 셈이 아니다.
회차마다 따로 모은다. 한쪽이 1회차를 켰고 다른 쪽이 2회차를 켰으면 둘 다 켜진다.

T237 에 이것을 셈으로 다뤘다. **빈 표를 빈 표로 덮으면서 바뀐다고 적었다.**
자기 파일을 다시 합치는 판에서 걸렸다 (T238).

### 3.3 모음

| 값 | 무엇으로 겹침을 보나 |
|---|---|
| `days[].unres` | **한 건 전부가 같아야** 같은 것. 문장과 걸린 것과 둘이 적은 것 |
| `days[].coll` | 같다 |
| `rot` | 날짜와 조합이 같으면 같은 것 |
| `clips` | 파일 이름과 시작과 끝이 같으면 같은 것 |
| `scripts[파일]` | 파일 이름마다 줄이 더 많은 쪽 |

**한 건 전부를 본다. 문장만 안 본다.** 문장만 보면 같은 문장에 서로 다른 것을
적은 두 건이 하나로 줄고, 줄어드는 쪽은 나중에 온 것이다.

사람이 같은 것을 조금 다르게 적으면 둘 다 남는다. 그것이 맞다.
**지우는 것보다 두 번 적히는 것이 낫다.**

### 3.4 물음

둘 다 값이 있고 서로 다를 때만 묻는다. 한쪽이 비어 있으면 안 묻고 채운다.

| 값 | 다르면 무슨 뜻인가 |
|---|---|
| `start` | **시작일이 다르다.** 이것이 다르면 48주가 통째로 어긋난다 |
| `names` | 이름이 다르다. 한 번만 맞추면 되는 값이다 |
| `days[].status` | 같은 날을 한쪽은 정상 한쪽은 결석으로 적었다 |
| `days[].aim` `xchk` | 같은 칸에 서로 다른 글을 적었다 |
| `wchk[주]` | 주간 점검을 양쪽에서 따로 했다 |
| `q[분기]` | 분기 판정이 다르다 |
| `cues[과][줄]` | 같은 줄의 시각을 다르게 고쳤다 |

**묻는 것이 일곱이다.** 이것을 자동으로 정하면 합치기가 아니라 조용한 덮기다.

## 4. 합치기가 지키는 것 넷

**하나. 지우지 않는다.** 합친 결과가 어느 쪽보다도 작아지지 않는다.
셈은 큰 것을 남기고 글은 둘 다 남긴다.

**둘. 자동으로 못 정하는 것을 자동으로 정하지 않는다.**
물음이 하나라도 있으면 그것을 다 고르기 전에는 안 바꾼다.

**셋. 바꾸기 전에 무엇이 바뀌는지를 보인다.**
가져오기는 누르고 나서 보였다. 합치기는 누르기 전에 보인다.

**넷. 되돌릴 수 있다.** T184 의 되돌리기는 그대로 둔다.

## 5. 무엇을 안 하는가

**합친 것을 다시 합치는 것을 안 센다.** 두 기기를 세 번 합쳐도 같은 결과여야 한다.
같은 파일을 두 번 가져와도 미해결이 두 배가 되면 안 된다.
겹침을 글자로 보기 때문에 그렇게 된다.

**날짜를 안 만든다.** 상대에게만 있는 날은 그대로 가져오고
양쪽에 없는 날은 안 생긴다.

**셋을 한 번에 안 합친다.** 기기가 둘이다. 셋이 되면 그때 다시 본다.

## 6. 가장자리 (T238)

### 6.1 세션 중에는 안 합친다

블록 칸이 그날 기록을 들고 있다. 합치면 그 기록이 밑에서 바뀌는데
**블록 칸은 다시 안 그려진다.** 그 상태에서 블록 3이 돈 카드 수를 적으면
칸에 남아 있던 옛 값이 합친 값 위에 덮인다. T216 에 겪은 그 자리다.

두 시간 중에 합칠 이유도 없다. 짝을 맞추는 자리는 세션이 끝난 뒤다 (매뉴얼 10.11).

화면을 띄운 뒤에 세션이 시작될 수도 있다. **누르는 그 순간에 다시 본다.**

### 6.2 늘어나는 것과 바뀌는 것은 다르다

처음에는 늘어나는 것만 셌다. 날 몇 개, 미해결 몇 건이다.
그러면 **발화 분이 12에서 99로 뛰는 판이 아무 말도 안 하고 지나간다.**
아무것도 안 늘어나기 때문이다.

아무것도 안 바뀌는 판과 숫자가 뛰는 판이 화면에서 같은 말을 하고 있었다.
바뀌는 셈을 따로 세서 열 줄까지 적는다. 넘으면 몇 개 더라고만 말한다.
48주를 합치면 수백 줄이 되고 그러면 아무도 안 읽는다.

### 6.3 재 본 가장자리 여섯

| 판 | 어떻게 되어야 하나 |
|---|---|
| 내 파일을 내가 다시 합친다 | **아무것도 안 바뀐다** |
| 상대 파일이 내 것보다 낡았다 | 내 값이 다 이긴다 |
| 키가 거의 없는 옛 판 | 안 깨진다. 시작일과 이름을 안 지운다 |
| 빈 파일 | 아무것도 안 바뀐다 |
| 같은 파일을 세 번 | 미해결이 두 배가 안 된다 |
| 회차를 각자 다르게 켰다 | 둘 다 켜진다 |
