## 1. 규격. 판마다 아홉 칸

**칸을 먼저 정한다.** 판마다 다른 칸을 쓰면 나중에 견줄 수 없고
빠뜨린 칸을 못 찾는다. 아홉 칸이고 **하나도 비워 두지 않는다.**

| 칸 | 무엇을 적나 | 어느 원칙이 보나 |
|---|---|---|
| 트랙 | 6트랙 중 무엇 | - |
| 구조 | 어느 놀이 구조 | - |
| 분 | 숫자. 5를 안 넘는다 | 원칙 6 |
| 쓰는 것 | 어느 자료. **없으면 없다고 적는다** | - |
| 시작 조건 | 무엇이 있어야 시작하나 | - |
| 역할 | 누가 무엇을 하고 **언제 바뀌나** | 원칙 5, P1 |
| 도는 차례 | 한 판이 어떻게 흐르나 | - |
| 판정 | **누가** 통과를 정하나 | 원칙 3 |
| 끝 조건 | 언제 끝나나. **주어가 둘이거나 없다** | 원칙 2, P2 |
| 못 했을 때 | 못 하면 무엇이 일어나나. **벌이 없다** | 원칙 4, P3 |
| 기록할 값 | 무엇을 남기나. **사람별 값이 없다** | 원칙 1, V3 |

적을 것은 열하나인데 트랙과 구조와 분을 한 줄에 적는다. 그래서 **판마다 아홉 줄**이다.

T201 에서 표 밑 문장이 표와 다른 것을 찾았다. 그 자리를 이 문서에서 또 만들 뻔했다.
처음에 열 칸이라고 적었다. **세어 보고 고쳤다.**

**"없으면 없다고 적는다" 가 쓰는 것 칸의 규칙이다.**
있는 척하면 T205 에서 못 찾는다. 없는 자료는 **없음**으로 적고 등급을 붙인다.

## 2. 이어 붙이기 구조를 먼저 뜯는다

T201 에서 찾은 것이다. 스무 판이 쓰는 구조 열셋 중 **이어 붙이기만 출처가 없다.**
이어달리기와 둘이 한 문장 두 판이 이것을 쓴다. 쓰기 전에 뜯는다.

### 2.1 무엇인가

**한 사람이 낸 것에 다른 사람이 붙여서 하나를 만든다.**

정보 격차와 다르다. 격차는 **내가 아는 것을 상대가 모르는** 구조다.
이어 붙이기는 둘 다 다 본다. 감추는 것이 없다.

그러면 무엇이 두 사람을 필요하게 만드는가.

**혼자서는 자기가 낸 것에 이어 붙이게 된다.** 자기 머리에서 나온 것이라
다음 것도 같은 자리에서 나온다. 남이 낸 것에 붙이면 **내가 안 갔을 자리에서 시작한다.**

이것이 이 구조의 값이다. 감춤이 아니라 **예측 못 함**이다.

### 2.2 왜 청크에 맞는가

청크는 **덩어리로 나오는가**를 본다. 낱말을 하나씩 고르면 그것은 청크가 아니다.

상대가 앞을 던지면 나는 생각할 시간이 없다. 그 자리에서 뒤를 붙여야 한다.
**시간이 없으면 덩어리로 나온다.** 없는 덩어리는 안 나온다.

그래서 이 구조는 청크가 있는지 없는지를 그 자리에서 가른다.
낱말을 고르는 티가 나면 그것이 곧 판정이다. 기계가 아니라 상대가 본다.

### 2.3 벌이 안 생기는 자리

끊기면 누가 끊은 것인가. 붙인 쪽이다. **그러면 붙인 쪽이 진 것 아닌가.**

아니게 만드는 규칙이 하나 필요하다. **끊기면 접고 다시 시작한다.**
끊긴 자리를 세지 않고 **몇 마디까지 갔는지만 센다.**
그리고 그 숫자는 둘의 것이다. 앞을 던진 쪽이 어려운 것을 던졌을 수도 있다.

**누가 끊었는지는 셈에 안 들어간다.** 이것이 원칙 4를 지키는 방법이다.

### 2.4 코드 요구사항

| | 요구 |
|---|---|
| R32 | 끊긴 자리를 사람별로 세지 않는다 |
| R33 | 몇 마디까지 갔는지를 **공동 값**으로 남긴다 |
| R34 | 다시 시작할 때 앞을 던지는 쪽이 **바뀐다** |

R34 가 원칙 5다. 던지는 쪽이 판을 이끈다. 그 자리를 번갈아 준다.

`bench_play.md` 의 R1~R31 을 이어 R32 부터 붙였다.

## 3. 소리 넷

### 3.1 거울

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 정보 격차 / 4분 |
| 쓰는 것 | **최소대립쌍 표. 없음. B등급 예정 (J단계)** |
| 시작 조건 | 오늘 강의 소리 회차를 마쳤다. 쌍 여덟 개가 화면에 있다 |
| 역할 | 읽는 쪽과 짚는 쪽. **넉 줄마다 바뀐다** |
| 도는 차례 | 읽는 쪽 화면에만 어느 쪽인지 뜬다. 읽는다. 짚는 쪽이 둘 중 하나를 누른다 |
| 판정 | **읽은 사람.** 자기가 무엇을 읽었는지 안다 |
| 끝 조건 | 여덟 쌍을 다 돌면 끝난다. 4분이 되면 그 자리에서 끝난다 |
| 못 했을 때 | 못 짚으면 읽는 쪽이 한 번 더 읽는다. 두 번째도 못 짚으면 넘어간다 |
| 기록할 값 | 여덟 중 몇을 짚었는가. **한 숫자다** |

읽은 사람이 판정하는 것이 이 판의 뼈대다. 기계가 발음을 안 잰다.
**짚은 것이 맞으면 그 소리가 건너간 것이고 틀리면 안 건너간 것이다.**
누구 잘못인지는 안 가른다. 읽기가 문제일 수도 듣기가 문제일 수도 있고 그 둘을 못 가른다.

### 3.2 한 줄 바꾸기

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 틀린 데 찾기 / 5분 |
| 쓰는 것 | 52과 대본 한 줄 + **바꿀 낱말 표. 없음. A등급 예정 (대본에서 뽑는다)** |
| 시작 조건 | 오늘 과의 대본이 열려 있다 |
| 역할 | 읽는 쪽과 찾는 쪽. **한 줄마다 바뀐다** |
| 도는 차례 | 읽는 쪽 화면에만 바꿀 낱말이 뜬다. 그렇게 읽는다. 찾는 쪽이 어디가 달랐는지 말한다 |
| 판정 | **읽은 사람** |
| 끝 조건 | 다섯 줄을 돌면 끝난다 |
| 못 했을 때 | 못 찾으면 읽는 쪽이 어디였는지 알려 주고 다시 읽는다 |
| 기록할 값 | 다섯 중 몇을 찾았는가 |

바꿀 낱말은 **대본에 있는 낱말끼리만** 바꾼다. 지어내면 그 자리가 C등급이 된다.
그래서 이 자료는 A등급으로 만들 수 있다. 대본에서 뽑기 때문이다.

### 3.3 내 소리는 네가

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 협력형 격차 / 5분 |
| 쓰는 것 | 오늘 과의 대본 세 줄. **있다** |
| 시작 조건 | 두 사람이 마주 앉아 있다. 기기 수는 상관없다 |
| 역할 | 말하는 쪽과 듣는 쪽. **세 줄마다 바뀐다** |
| 도는 차례 | 말하는 쪽이 읽는다. 듣는 쪽 화면에 **무엇을 들으라고** 뜬다. 듣고 짚어 준다 |
| 판정 | **듣는 사람.** 자기 발음은 자기가 못 듣는다 |
| 끝 조건 | 여섯 줄을 돌면 끝난다 |
| 못 했을 때 | 짚을 것이 없으면 없다고 말한다. **없다도 답이다** |
| 기록할 값 | 여섯 줄 중 짚을 것이 없었던 줄이 몇인가 |

**녹음을 안 쓴다.** 같은 방에 있으면 상대가 그 자리에서 듣는다.
`bench_play.md` 에서 R6~R9 가 없어진 자리가 이것이다.

듣는 쪽 화면에 뜨는 것이 이 판의 핵심이다. "잘 들어 보세요" 가 아니라
**"끝소리가 붙었는지 보세요" 처럼 무엇을 들을지를 준다.** 안 주면 둘 다 모른다.

### 3.4 전달 놀이

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 전달 변형 / 5분 |
| 쓰는 것 | 오늘 과의 대본 한 줄. **있다** |
| 시작 조건 | 대본 줄 하나를 골랐다 |
| 역할 | 처음 듣는 쪽과 옮기는 쪽. **한 바퀴마다 바뀐다** |
| 도는 차례 | A가 소리를 듣는다. B에게 말로 옮긴다. B가 적는다. 원문과 견준다 |
| 판정 | **둘이 같이 본다.** 원문이 화면에 있다 |
| 끝 조건 | 세 바퀴를 돌면 끝난다 |
| 못 했을 때 | 틀어졌으면 **어디서 틀어졌는지 되짚는다.** 그것이 이 판의 목적이다 |
| 기록할 값 | 세 바퀴에서 틀어진 자리가 몇 군데인가 |

**틀어지는 것이 이 판의 산출물이다.** 틀어진 자리가 안 들리는 자리다.
그래서 못 했을 때 칸이 벌이 아니라 **다음 할 일**이다.

## 4. 청크 셋

### 4.1 이어달리기

| 칸 | |
|---|---|
| 트랙 구조 분 | 청크 / 이어 붙이기 / 5분 |
| 쓰는 것 | 오늘 강의의 청크 목록. **있다** |
| 시작 조건 | 청크 회차를 마쳤다 |
| 역할 | 던지는 쪽과 붙이는 쪽. **한 번 접힐 때마다 바뀐다 (R34)** |
| 도는 차례 | 던지는 쪽이 청크 하나로 시작한다. 번갈아 붙여 문장을 늘린다 |
| 판정 | **둘이 같이.** 말이 되면 잇고 안 되면 접는다 |
| 끝 조건 | 5분이 되면 끝난다. **몇 마디까지 갔는지를 같이 센다** |
| 못 했을 때 | 끊기면 접고 다시 시작한다. **누가 끊었는지는 안 센다 (R32)** |
| 기록할 값 | 그 판에서 제일 길게 간 마디 수. **공동 값 하나 (R33)** |

말이 되는지를 둘이 정한다. 영어 제로 둘이서 그것을 정할 수 있는가.
**할 수 있다.** 배운 청크만 쓰기 때문이다. 배운 것끼리 붙는지는 배운 사람이 안다.

배운 것 밖으로 나가면 그 자리에서 접는다. 접는 것이 실패가 아니라 **경계 표시**다.

### 4.2 둘이 한 문장

| 칸 | |
|---|---|
| 트랙 구조 분 | 청크 / 이어 붙이기 / 4분 |
| 쓰는 것 | 오늘 강의 청크에서 만든 문장 여섯. **없음. A등급 예정 (강의에서 뽑는다)** |
| 시작 조건 | 문장 여섯이 앞뒤로 갈려 있다 |
| 역할 | 앞을 받는 쪽과 뒤를 받는 쪽. **문장마다 바뀐다** |
| 도는 차례 | 각자 화면에 절반씩 뜬다. 서로 안 보여 준다. 차례로 말해 붙인다 |
| 판정 | **둘이 같이.** 붙여서 말이 되면 통과다 |
| 끝 조건 | 여섯 문장을 돌면 끝난다 |
| 못 했을 때 | 안 붙으면 둘 다 화면을 펴고 본다. **펴 보는 것이 벌이 아니다** |
| 기록할 값 | 여섯 중 몇이 붙었는가 |

이어달리기와 구조가 같은데 다른 점이 하나 있다. **여기는 답이 있다.**
원래 문장이 있고 둘이 그것을 복원한다. 이어달리기는 답이 없다.

그래서 이 판이 쉽다. **쉬운 판을 먼저 두고 어려운 판을 뒤에 둔다.**

### 4.3 겹치면 지운다

| 칸 | |
|---|---|
| 트랙 구조 분 | 청크 / 단서 겹침 / 4분 |
| 쓰는 것 | 오늘 강의의 청크 목록. **있다** |
| 시작 조건 | 맞힐 것 하나를 앱이 골랐다. 둘 다 그것을 안다 |
| 역할 | 둘 다 같다. **역할이 없다** |
| 도는 차례 | 각자 단서 한 낱말을 적는다. 동시에 편다. **같으면 둘 다 지운다** |
| 판정 | 앱이 글자만 견준다. **같은 낱말인지만 본다** |
| 끝 조건 | 남은 단서로 맞힐 것에 닿으면 끝난다 |
| 못 했을 때 | 다 지워지면 한 바퀴를 다시 돈다. **지워진 것이 손해가 아니다** |
| 기록할 값 | 몇 바퀴 만에 닿았는가 |

이 판만 역할이 없다. 원칙 5가 안 걸린다. **역할이 없으면 굳을 자리도 없다.**
규칙서에 "역할이 없다" 를 적는 것이 비워 두는 것과 다르다.
**비우면 빠뜨린 것이고 적으면 정한 것이다.**

앱이 판정하는 유일한 판이기도 하다. 다만 앱이 보는 것은 **글자가 같은가** 하나다.
그것은 내가 검사할 수 있다. 뜻이 같은지는 안 본다. 그것은 못 검사한다.

## 5. 일곱 판을 규격에 대 봤다

| | 아홉 줄이 다 찼나 | 5분 안인가 | 사람별 값이 있나 |
|---|---|---|---|
| 일곱 판 | **다 찼다** | 4, 5, 5, 5, 5, 4, 4 | **없다** |

역할 칸에서 하나가 "역할이 없다" 다. 비운 것이 아니라 적은 것이다.
판정 칸은 읽은 사람 둘, 듣는 사람 하나, 둘이 같이 셋, 앱 하나다.
**일곱 중 여섯을 사람이 판정한다.**

없는 자료 셋을 표시했다. 최소대립쌍 표, 바꿀 낱말 표, 앞뒤로 가른 문장 여섯이다.
**T205 가 이것을 받는다.** 여기서 있는 척하면 거기서 못 찾는다.

열세 판이 남았다. T203 과 T204 에서 같은 아홉 줄로 적는다.
