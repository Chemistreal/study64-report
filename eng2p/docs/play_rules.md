## 1. 규격. 판마다 아홉 칸

**칸을 먼저 정한다.** 판마다 다른 칸을 쓰면 나중에 견줄 수 없고
빠뜨린 칸을 못 찾는다. 아홉 칸이고 **하나도 비워 두지 않는다.**

| 칸 | 무엇을 적나 | 어느 원칙이 보나 |
|---|---|---|
| 트랙 | 6트랙 중 무엇 | - |
| 구조 | 어느 놀이 구조 | - |
| 분 | 숫자. 5를 안 넘는다 | 원칙 6 |
| 쓰는 것 | 어느 자료. **없으면 없다고 적는다** | - |
| 시작 조건 | 무엇이 있어야 시작하나 | - |
| 역할 | 누가 무엇을 하고 **언제 바뀌나** | 원칙 5, P1 |
| 도는 차례 | 한 판이 어떻게 흐르나 | - |
| 판정 | **누가** 통과를 정하나 | 원칙 3 |
| 끝 조건 | 언제 끝나나. **주어가 둘이거나 없다** | 원칙 2, P2 |
| 못 했을 때 | 못 하면 무엇이 일어나나. **벌이 없다** | 원칙 4, P3 |
| 기록할 값 | 무엇을 남기나. **사람별 값이 없다** | 원칙 1, V3 |

적을 것은 열하나인데 트랙과 구조와 분을 한 줄에 적는다. 그래서 **판마다 아홉 줄**이다.

T201 에서 표 밑 문장이 표와 다른 것을 찾았다. 그 자리를 이 문서에서 또 만들 뻔했다.
처음에 열 칸이라고 적었다. **세어 보고 고쳤다.**

**"없으면 없다고 적는다" 가 쓰는 것 칸의 규칙이다.**
있는 척하면 T205 에서 못 찾는다. 없는 자료는 **없음**으로 적고 등급을 붙인다.

## 2. 이어 붙이기 구조를 먼저 뜯는다

T201 에서 찾은 것이다. 스무 판이 쓰는 구조 열셋 중 **이어 붙이기만 출처가 없다.**
이어달리기와 둘이 한 문장 두 판이 이것을 쓴다. 쓰기 전에 뜯는다.

### 2.1 무엇인가

**한 사람이 낸 것에 다른 사람이 붙여서 하나를 만든다.**

정보 격차와 다르다. 격차는 **내가 아는 것을 상대가 모르는** 구조다.
이어 붙이기는 둘 다 다 본다. 감추는 것이 없다.

그러면 무엇이 두 사람을 필요하게 만드는가.

**혼자서는 자기가 낸 것에 이어 붙이게 된다.** 자기 머리에서 나온 것이라
다음 것도 같은 자리에서 나온다. 남이 낸 것에 붙이면 **내가 안 갔을 자리에서 시작한다.**

이것이 이 구조의 값이다. 감춤이 아니라 **예측 못 함**이다.

### 2.2 왜 청크에 맞는가

청크는 **덩어리로 나오는가**를 본다. 낱말을 하나씩 고르면 그것은 청크가 아니다.

상대가 앞을 던지면 나는 생각할 시간이 없다. 그 자리에서 뒤를 붙여야 한다.
**시간이 없으면 덩어리로 나온다.** 없는 덩어리는 안 나온다.

그래서 이 구조는 청크가 있는지 없는지를 그 자리에서 가른다.
낱말을 고르는 티가 나면 그것이 곧 판정이다. 기계가 아니라 상대가 본다.

### 2.3 벌이 안 생기는 자리

끊기면 누가 끊은 것인가. 붙인 쪽이다. **그러면 붙인 쪽이 진 것 아닌가.**

아니게 만드는 규칙이 하나 필요하다. **끊기면 접고 다시 시작한다.**
끊긴 자리를 세지 않고 **몇 마디까지 갔는지만 센다.**
그리고 그 숫자는 둘의 것이다. 앞을 던진 쪽이 어려운 것을 던졌을 수도 있다.

**누가 끊었는지는 셈에 안 들어간다.** 이것이 원칙 4를 지키는 방법이다.

### 2.4 코드 요구사항

| | 요구 |
|---|---|
| R32 | 끊긴 자리를 사람별로 세지 않는다 |
| R33 | 몇 마디까지 갔는지를 **공동 값**으로 남긴다 |
| R34 | 다시 시작할 때 앞을 던지는 쪽이 **바뀐다** |

R34 가 원칙 5다. 던지는 쪽이 판을 이끈다. 그 자리를 번갈아 준다.

`bench_play.md` 의 R1~R31 을 이어 R32 부터 붙였다.

## 3. 소리 넷

### 3.1 거울

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 정보 격차 / 4분 |
| 쓰는 것 | **최소대립쌍 표. 없음. B등급 예정 (J단계)** |
| 시작 조건 | 오늘 강의 소리 회차를 마쳤다. 쌍 여덟 개가 화면에 있다 |
| 역할 | 읽는 쪽과 짚는 쪽. **넉 줄마다 바뀐다** |
| 도는 차례 | 읽는 쪽 화면에만 어느 쪽인지 뜬다. 읽는다. 짚는 쪽이 둘 중 하나를 누른다 |
| 판정 | **읽은 사람.** 자기가 무엇을 읽었는지 안다 |
| 끝 조건 | 여덟 쌍을 다 돌면 끝난다. 4분이 되면 그 자리에서 끝난다 |
| 못 했을 때 | 못 짚으면 읽는 쪽이 한 번 더 읽는다. 두 번째도 못 짚으면 넘어간다 |
| 기록할 값 | 여덟 중 몇을 짚었는가. **한 숫자다** |

읽은 사람이 판정하는 것이 이 판의 뼈대다. 기계가 발음을 안 잰다.
**짚은 것이 맞으면 그 소리가 건너간 것이고 틀리면 안 건너간 것이다.**
누구 잘못인지는 안 가른다. 읽기가 문제일 수도 듣기가 문제일 수도 있고 그 둘을 못 가른다.

### 3.2 한 줄 바꾸기

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 틀린 데 찾기 / 5분 |
| 쓰는 것 | 52과 대본 한 줄 + **바꿀 낱말 표. 없음. A등급 예정 (대본에서 뽑는다)** |
| 시작 조건 | 오늘 과의 대본이 열려 있다 |
| 역할 | 읽는 쪽과 찾는 쪽. **한 줄마다 바뀐다** |
| 도는 차례 | 읽는 쪽 화면에만 바꿀 낱말이 뜬다. 그렇게 읽는다. 찾는 쪽이 어디가 달랐는지 말한다 |
| 판정 | **읽은 사람** |
| 끝 조건 | 다섯 줄을 돌면 끝난다 |
| 못 했을 때 | 못 찾으면 읽는 쪽이 어디였는지 알려 주고 다시 읽는다 |
| 기록할 값 | 다섯 중 몇을 찾았는가 |

바꿀 낱말은 **대본에 있는 낱말끼리만** 바꾼다. 지어내면 그 자리가 C등급이 된다.
그래서 이 자료는 A등급으로 만들 수 있다. 대본에서 뽑기 때문이다.

### 3.3 내 소리는 네가

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 협력형 격차 / 5분 |
| 쓰는 것 | 오늘 과의 대본 세 줄. **있다** |
| 시작 조건 | 두 사람이 마주 앉아 있다. 기기 수는 상관없다 |
| 역할 | 말하는 쪽과 듣는 쪽. **세 줄마다 바뀐다** |
| 도는 차례 | 말하는 쪽이 읽는다. 듣는 쪽 화면에 **무엇을 들으라고** 뜬다. 듣고 짚어 준다 |
| 판정 | **듣는 사람.** 자기 발음은 자기가 못 듣는다 |
| 끝 조건 | 여섯 줄을 돌면 끝난다 |
| 못 했을 때 | 짚을 것이 없으면 없다고 말한다. **없다도 답이다** |
| 기록할 값 | 여섯 줄 중 짚을 것이 없었던 줄이 몇인가 |

**녹음을 안 쓴다.** 같은 방에 있으면 상대가 그 자리에서 듣는다.
`bench_play.md` 에서 R6~R9 가 없어진 자리가 이것이다.

듣는 쪽 화면에 뜨는 것이 이 판의 핵심이다. "잘 들어 보세요" 가 아니라
**"끝소리가 붙었는지 보세요" 처럼 무엇을 들을지를 준다.** 안 주면 둘 다 모른다.

### 3.4 전달 놀이

| 칸 | |
|---|---|
| 트랙 구조 분 | 소리 / 전달 변형 / 5분 |
| 쓰는 것 | 오늘 과의 대본 한 줄. **있다** |
| 시작 조건 | 대본 줄 하나를 골랐다 |
| 역할 | 처음 듣는 쪽과 옮기는 쪽. **한 바퀴마다 바뀐다** |
| 도는 차례 | A가 소리를 듣는다. B에게 말로 옮긴다. B가 적는다. 원문과 견준다 |
| 판정 | **둘이 같이 본다.** 원문이 화면에 있다 |
| 끝 조건 | 세 바퀴를 돌면 끝난다 |
| 못 했을 때 | 틀어졌으면 **어디서 틀어졌는지 되짚는다.** 그것이 이 판의 목적이다 |
| 기록할 값 | 세 바퀴에서 틀어진 자리가 몇 군데인가 |

**틀어지는 것이 이 판의 산출물이다.** 틀어진 자리가 안 들리는 자리다.
그래서 못 했을 때 칸이 벌이 아니라 **다음 할 일**이다.

## 4. 청크 셋

### 4.1 이어달리기

| 칸 | |
|---|---|
| 트랙 구조 분 | 청크 / 이어 붙이기 / 5분 |
| 쓰는 것 | 오늘 강의의 청크 목록. **있다** |
| 시작 조건 | 청크 회차를 마쳤다 |
| 역할 | 던지는 쪽과 붙이는 쪽. **한 번 접힐 때마다 바뀐다 (R34)** |
| 도는 차례 | 던지는 쪽이 청크 하나로 시작한다. 번갈아 붙여 문장을 늘린다 |
| 판정 | **둘이 같이.** 말이 되면 잇고 안 되면 접는다 |
| 끝 조건 | 5분이 되면 끝난다. **몇 마디까지 갔는지를 같이 센다** |
| 못 했을 때 | 끊기면 접고 다시 시작한다. **누가 끊었는지는 안 센다 (R32)** |
| 기록할 값 | 그 판에서 제일 길게 간 마디 수. **공동 값 하나 (R33)** |

말이 되는지를 둘이 정한다. 영어 제로 둘이서 그것을 정할 수 있는가.
**할 수 있다.** 배운 청크만 쓰기 때문이다. 배운 것끼리 붙는지는 배운 사람이 안다.

배운 것 밖으로 나가면 그 자리에서 접는다. 접는 것이 실패가 아니라 **경계 표시**다.

### 4.2 둘이 한 문장

| 칸 | |
|---|---|
| 트랙 구조 분 | 청크 / 이어 붙이기 / 4분 |
| 쓰는 것 | 오늘 강의 청크에서 만든 문장 여섯. **없음. A등급 예정 (강의에서 뽑는다)** |
| 시작 조건 | 문장 여섯이 앞뒤로 갈려 있다 |
| 역할 | 앞을 받는 쪽과 뒤를 받는 쪽. **문장마다 바뀐다** |
| 도는 차례 | 각자 화면에 절반씩 뜬다. 서로 안 보여 준다. 차례로 말해 붙인다 |
| 판정 | **둘이 같이.** 붙여서 말이 되면 통과다 |
| 끝 조건 | 여섯 문장을 돌면 끝난다 |
| 못 했을 때 | 안 붙으면 둘 다 화면을 펴고 본다. **펴 보는 것이 벌이 아니다** |
| 기록할 값 | 여섯 중 몇이 붙었는가 |

이어달리기와 구조가 같은데 다른 점이 하나 있다. **여기는 답이 있다.**
원래 문장이 있고 둘이 그것을 복원한다. 이어달리기는 답이 없다.

그래서 이 판이 쉽다. **쉬운 판을 먼저 두고 어려운 판을 뒤에 둔다.**

### 4.3 겹치면 지운다

| 칸 | |
|---|---|
| 트랙 구조 분 | 청크 / 단서 겹침 / 4분 |
| 쓰는 것 | 오늘 강의의 청크 목록. **있다** |
| 시작 조건 | 맞힐 것 하나를 앱이 골랐다. 둘 다 그것을 안다 |
| 역할 | 둘 다 같다. **역할이 없다** |
| 도는 차례 | 각자 단서 한 낱말을 적는다. 동시에 편다. **같으면 둘 다 지운다** |
| 판정 | 앱이 글자만 견준다. **같은 낱말인지만 본다** |
| 끝 조건 | 남은 단서로 맞힐 것에 닿으면 끝난다 |
| 못 했을 때 | 다 지워지면 한 바퀴를 다시 돈다. **지워진 것이 손해가 아니다** |
| 기록할 값 | 몇 바퀴 만에 닿았는가 |

이 판만 역할이 없다. 원칙 5가 안 걸린다. **역할이 없으면 굳을 자리도 없다.**
규칙서에 "역할이 없다" 를 적는 것이 비워 두는 것과 다르다.
**비우면 빠뜨린 것이고 적으면 정한 것이다.**

앱이 판정하는 유일한 판이기도 하다. 다만 앱이 보는 것은 **글자가 같은가** 하나다.
그것은 내가 검사할 수 있다. 뜻이 같은지는 안 본다. 그것은 못 검사한다.

## 5. 소리와 청크 일곱을 규격에 대 봤다

| | 아홉 줄이 다 찼나 | 5분 안인가 | 사람별 값이 있나 |
|---|---|---|---|
| 일곱 판 | **다 찼다** | 4, 5, 5, 5, 5, 4, 4 | **없다** |

역할 칸에서 하나가 "역할이 없다" 다. 비운 것이 아니라 적은 것이다.
판정 칸은 읽은 사람 둘, 듣는 사람 하나, 둘이 같이 셋, 앱 하나다.
**일곱 중 여섯을 사람이 판정한다.**

없는 자료 셋을 표시했다. 최소대립쌍 표, 바꿀 낱말 표, 앞뒤로 가른 문장 여섯이다.
**T205 가 이것을 받는다.** 여기서 있는 척하면 거기서 못 찾는다.

열세 판이 남았다. T203 과 T204 에서 같은 아홉 줄로 적는다.

## 6. 자동화 셋

### 6.1 배속 사다리

| 칸 | |
|---|---|
| 트랙 구조 분 | 자동화 / 속도 올리기 / 5분 |
| 쓰는 것 | 오늘 과의 대본 한 토막 + 배속 사다리 규격. **둘 다 있다** (`bench_music.md` 6.4) |
| 시작 조건 | 그 토막을 1.0 배속으로 한 번 들었다 |
| 역할 | 말하는 쪽과 세는 쪽. **한 칸 오를 때마다 바뀐다** |
| 도는 차례 | 0.8 에서 시작한다. **세 번 연달아 되면 한 칸 올린다.** 1.2 까지 |
| 판정 | **세는 사람.** 배속마다 볼 것이 다르다 |
| 끝 조건 | 1.2 가 세 번 되면 끝난다. 5분이 되면 그 칸에서 끝난다 |
| 못 했을 때 | **두 번 연달아 안 되면 한 칸 내린다.** 화면은 "한 번 더 다진다" 로 적는다 |
| 기록할 값 | 그 판에서 닿은 제일 높은 칸 |

배속마다 무엇을 보는지가 화면에 있어야 한다. 0.8 은 빠뜨린 낱말,
1.0 은 박자, 1.2 는 서두른 티다. **같은 것을 세 번 재는 것이 아니다.**

내리는 것이 벌이 아니라는 것을 화면 글이 말한다. T175 에 정한 말투 규칙이 그대로 걸린다.

### 6.2 3초 벽

| 칸 | |
|---|---|
| 트랙 구조 분 | 자동화 / 시간 압박 / 4분 |
| 쓰는 것 | 압박형 카드. **있다.** Q1 25장 Q2 이후는 분기 배정표대로 |
| 시작 조건 | 그날 카드 회차를 마쳤다 |
| 역할 | 단서를 띄우는 쪽과 받는 쪽. **다섯 장마다 바뀐다** |
| 도는 차례 | 단서가 뜬다. 제한시간 안에 받는다. 못 받으면 **상대가 대신 받는다** |
| 판정 | **띄운 사람** |
| 끝 조건 | 열 장을 돌면 끝난다 |
| 못 했을 때 | 상대가 대신 받는다. 둘 다 못 받으면 그 장을 다음 판으로 미룬다 |
| 기록할 값 | 열 장 중 시간 안에 받은 장 수. **누가 받았는지는 안 센다** |

**판 이름이 3초인데 기준서 8.1 은 분기마다 다른 값을 준다.** Q2 5초, Q3 3초, Q4 2초다.
이름을 값으로 읽으면 Q2 에서 두 초를 깎고 Q4 에서 한 초를 얹는다.

**제한시간은 분기가 정한다.** 이름은 그대로 두되 화면은 그날 분기 값을 쓴다.
판 이름은 이름일 뿐이고 값은 기준서에서 온다.

못 받은 것을 상대가 대신 받는 것이 이 판의 뼈대다.
`bench_play.md` 에서 셈을 뒤집은 자리다. **압박은 남고 벌은 없어진다.**

### 6.3 되받아치기

| 칸 | |
|---|---|
| 트랙 구조 분 | 자동화 / 시간 압박 / 4분 |
| 쓰는 것 | 오늘 강의의 청크 목록. **있다** |
| 시작 조건 | 청크 회차를 마쳤다 |
| 역할 | 던지는 쪽과 받는 쪽. **한 번 쉼이 생길 때마다 바뀐다** |
| 도는 차례 | 앞 사람 말끝을 받아 바로 잇는다. **쉼이 없어야 한다** |
| 판정 | **받은 사람이 아니라 던진 사람.** 쉼을 던진 쪽이 듣는다 |
| 끝 조건 | 4분이 되면 끝난다. **몇 번 주고받았는지를 같이 센다** |
| 못 했을 때 | 쉼이 생기면 그 자리에서 끊고 역할을 바꿔 다시 시작한다 |
| 기록할 값 | 한 번에 제일 많이 주고받은 수. **공동 값 하나** |

던진 사람이 판정하는 이유가 있다. **자기 말이 끝난 뒤의 쉼은 자기가 제일 잘 듣는다.**
받는 쪽은 생각하느라 그 쉼을 못 느낀다.

## 7. 화용 셋

### 7.1 한 사람만 본다

| 칸 | |
|---|---|
| 트랙 구조 분 | 화용 / 정보 격차 / 5분 |
| 쓰는 것 | **상황 카드. 없음. B등급 예정 (J단계)** |
| 시작 조건 | 상황 카드 한 장이 A 화면에만 떴다 |
| 역할 | 상황을 쥔 쪽과 알아내는 쪽. **한 장마다 바뀐다** |
| 도는 차례 | A가 그 상황인 것처럼 말한다. B가 묻는다. **다섯 요소 중 둘**을 알아내면 된다 |
| 판정 | **상황을 쥔 사람** |
| 끝 조건 | 둘을 알아내면 끝난다. 5분이 되면 A가 나머지를 읽어 주고 끝난다 |
| 못 했을 때 | A가 나머지 셋을 읽어 준다. **못 맞힌 것을 듣는 것도 입력이다** |
| 기록할 값 | 몇 번 물어서 닿았는가 |

T201 에서 6분을 5분으로 내리면서 다섯 요소를 둘로 줄인 판이다.
역할형 카드의 5요소(상황, 관계, 목적, 레지스터, 종료 조건)를 그대로 쓴다.
**자료를 새로 만들되 요소는 기준서 8.1 에서 가져온다.**

### 7.2 파장

| 칸 | |
|---|---|
| 트랙 구조 분 | 화용 / 눈금 맞추기 / 5분 |
| 쓰는 것 | **격식 눈금. 없음. B등급 예정 (J단계)** |
| 시작 조건 | 눈금 위 한 점이 A 화면에만 떴다 |
| 역할 | 세기를 쥔 쪽과 맞히는 쪽. **한 점마다 바뀐다** |
| 도는 차례 | A가 그 세기로 한 줄을 말한다. B가 눈금 위 자리를 짚는다 |
| 판정 | **세기를 쥔 사람.** 한 칸 안이면 닿은 것으로 본다 |
| 끝 조건 | 여섯 점을 돌면 끝난다 |
| 못 했을 때 | 두 칸 넘게 벌어지면 A가 어디였는지 보여 주고 다시 말한다 |
| 기록할 값 | 여섯 중 한 칸 안에 든 것이 몇인가 |

**한 칸 안이면 닿은 것으로 본다** 가 이 판의 규격이다. 정확히 맞히는 판이 아니다.
격식은 점이 아니라 폭이다. 폭을 인정 안 하면 통과가 안 되고 통과가 안 되면 판이 죽는다.

### 7.3 누구 말이야

| 칸 | |
|---|---|
| 트랙 구조 분 | 화용 / 뒤집힌 판정 / 4분 |
| 쓰는 것 | **같은 뜻 세 격식. 없음. B등급 예정 (J단계)** |
| 시작 조건 | 세 격식 한 벌이 화면에 있다 |
| 역할 | 자리를 고르는 쪽과 고른 것을 판정하는 쪽. **한 벌마다 바뀐다** |
| 도는 차례 | 앱이 쓸 자리를 준다. 고르는 쪽이 셋 중 하나를 고른다. 판정하는 쪽이 맞는지 본다 |
| 판정 | **판정하는 사람.** 앱은 정답을 안 준다 |
| 끝 조건 | 다섯 벌을 돌면 끝난다 |
| 못 했을 때 | 둘의 생각이 갈리면 **갈렸다고 적고 넘어간다.** 그 자리가 주 7일째 점검에 간다 |
| 기록할 값 | 다섯 중 둘의 생각이 같았던 벌이 몇인가 |

**갈리는 것을 적는 칸이 있는 유일한 판이다.** 격식은 답이 하나가 아니다.
둘이 갈리면 그것이 틀린 것이 아니라 **물어볼 것**이다. 검증 대기열로 간다.

여기서 격식 자료 둘을 하나로 만들 수 있다는 것을 적어 둔다.
**눈금 위의 세 점이 곧 세 격식이다.** 자료를 둘로 만들면 두 판이 다른 말을 하게 된다.

## 8. 문법 하나

### 8.1 거꾸로 판정

| 칸 | |
|---|---|
| 트랙 구조 분 | 문법 / 뒤집힌 판정 / 5분 |
| 쓰는 것 | 판정형 카드 + **판정 기준. 없음. B등급 예정 (J단계)** |
| 시작 조건 | 판정형 카드 다섯 장이 뽑혀 있다 |
| 역할 | 답하는 쪽과 판정하는 쪽. **한 장마다 바뀐다** |
| 도는 차례 | B가 답한다. **A 화면에는 정답이 아니라 기준만 있다.** A가 기준으로 본다 |
| 판정 | **판정하는 사람** |
| 끝 조건 | 다섯 장을 돌면 끝난다 |
| 못 했을 때 | 기준으로 못 가르면 **못 가른다고 적는다.** 그 카드가 검증 대기열로 간다 |
| 기록할 값 | 다섯 중 기준으로 갈린 장이 몇인가 |

Q1 문법은 0퍼센트다. 이 판은 Q2 부터 돈다. 규칙서에 그것을 적어 둔다.

**판정형 카드에서 A면 정답을 빼는 것이 이 판의 전제다.**
`bench_play.md` 에서 나온 것이고 600장 중 절반이 그 카드다.
정답을 두면 A는 대 보기만 한다. 기준만 주면 A도 생각한다.

기준을 못 만드는 카드가 있을 것이다. **그 카드는 이 판에 안 들어간다.**
T205 에서 몇 장이 들어가고 몇 장이 빠지는지 센다.

## 9. 열네 판 중간 점검

| | 아홉 줄이 다 찼나 | 5분 안인가 | 사람별 값이 있나 |
|---|---|---|---|
| 열네 판 | **다 찼다** | 3분 없음. 4분 여섯, 5분 여덟 | **없다** |

판정 주체를 다시 세었다.

| 누가 판정하나 | 몇 판 | 어느 판 |
|---|---|---|
| 그 자리에서만 아는 사람 | 6 | 거울, 한 줄 바꾸기, 내 소리는 네가, 3초 벽, 한 사람만 본다, 파장 |
| 판정하는 쪽으로 지정된 사람 | 4 | 배속 사다리, 되받아치기, 누구 말이야, 거꾸로 판정 |
| 둘이 같이 | 3 | 전달 놀이, 이어달리기, 둘이 한 문장 |
| 앱 | 1 | 겹치면 지운다 |

**열네 판 중 열셋을 사람이 판정한다.**

첫째 갈래가 제일 많다. **실력이 아니라 자리가 판정을 준다.**
읽은 사람은 자기가 무엇을 읽었는지 알고 세기를 쥔 사람은 자기가 무슨 세기였는지 안다.
영어를 더 잘해서 판정하는 것이 아니다. `bench_play.md` 4.3 이 적은 것이 이 숫자다.

없는 자료가 셋에서 **여섯**으로 늘었다. 최소대립쌍 표, 바꿀 낱말 표,
앞뒤로 가른 문장, 상황 카드, 격식 자료, 판정 기준이다.
격식 자료는 눈금과 3단을 하나로 묶어 센 것이다.

**여섯 중 다섯이 B등급이다.** 놀이를 만들면 검증 대기열이 늘어난다는 것을
`bench_play.md` 11.2 에 적어 뒀는데 여기서 숫자로 나왔다.

여섯 판이 남았다. repair 셋, 복습 하나, 전 트랙 둘이다.
