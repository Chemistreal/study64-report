# 기기 둘. 무엇이 갈리고 무엇이 건너가야 하는가

신뢰도: A 생성 (진단)
상위 규격: docs/spec.md 2.3, 2.4 / docs/roadmap.md 12.13 D단계
작성일: 2026-08-09 (T233)

검증로그: 2026-08-09 / 기기별로 갈리는 값과 건너가야 하는 값을 세었다 / 통과 / 카메라와 망을 못 쓴다. 사람이 치는 코드로 건널 수 있는 것은 숫자뿐이다

## 1. D단계가 여기서 시작한다

로드맵 12.13 이 이렇게 적었다. **"정보 격차 놀이는 화면이 갈려야 성립한다."**

그런데 화면을 가르기 전에 먼저 볼 것이 있다. **지금은 기기가 둘이면 기록이 갈린다.**
`renderSidePick` 이 그 자리에 이렇게 적어 두고 있다.

> 기록은 한 기기에만 남긴다. 다른 기기는 보기만 한다.

그것이 규칙이었다. 규칙으로 막아 둔 것이지 푼 것이 아니다.
D단계는 그 규칙을 푸는 단계다. **풀기 전에 무엇이 갈리는지부터 센다.**

## 2. 못 쓰는 것 셋

먼저 못 하는 것을 적는다. 할 수 있는 것을 고르기 전에 이것이 정해진다.

| | 왜 |
|---|---|
| 서버 | 이 물건은 파일 하나다. 1년을 쓰는데 남의 서버에 매달지 않는다 |
| 망 | 세션 두 시간 중에 밖으로 나가는 것은 영상뿐이다. 그것도 안 되는 날이 있다 |
| 카메라 | `file://` 은 안전한 자리가 아니라 브라우저가 카메라를 안 준다 |

**카메라가 없다는 것이 제일 크다.** 코드를 화면에 그려 상대가 찍는 방식이 막힌다.
남는 것은 **사람이 눈으로 보고 손으로 치는 것**이다.

그리고 파일을 주고받는 길이 하나 더 있다. JSON 내보내기와 가져오기가 이미 있다.
그것은 기기 사이에 파일을 옮길 수 있을 때만 된다.

## 3. 무엇이 갈리는가

기록은 브라우저 저장소에 있고 그것은 기기마다 따로다. 값을 갈래로 나눴다.

| 갈래 | 값 | 건너가야 하나 |
|---|---|---|
| 진도 | `start` `days[].status` `lecRound` `media.pass` | **건너가야 한다** |
| 활동량 | `days[].speak` `cards` `lre` | 건너가야 한다 |
| 글 | `days[].unres` `coll` `aim` `xchk` `wchk` | 건너가야 한다 |
| 카드 간격 | `cardDue` | 건너가야 한다 |
| 이름 | `names` | 한 번만 맞추면 된다 |
| 기기 쪽 | `device` | **안 건너간다.** 기기마다 다르다 |
| 글자 크기 | `fs` | **안 건너간다.** 눈이 다르고 기기가 다르다 |
| 보던 자리 | `session` `card` `wk` `cardMode` `veil` `rate` | 안 건너간다 |

**안 건너가는 것이 여섯이다.** 그중 `fs` 는 T148 에 이미 그렇게 정해 뒀다.
나머지 다섯도 같은 이유다. 그 기기에서 지금 무엇을 보고 있는가는 그 기기의 일이다.

## 4. 건너갈 수 있는 양

사람이 치는 코드에 얼마나 담기는가를 재 봤다.

| 담는 것 | 길이 |
|---|---|
| 하루 기록 전부 (글 포함) | 329글자. 압축해도 **452글자** |
| 숫자만 (날, 상태, 발화, 카드, LRE, 미해결 수, 채집 수, 겹침, 안 겹침) | **19글자** |

압축이 오히려 길어진다. 짧은 것을 압축하면 머리말이 본문보다 크다.

**19글자는 칠 수 있다.** 452글자는 못 친다.
그래서 코드로 건너가는 것은 **숫자뿐**이고 글은 다른 길로 가야 한다.

### 4.1 갈래를 둘로 나눈다

| | 무엇 | 어떻게 |
|---|---|---|
| 셈 | 진도와 활동량과 겹침 수 | **짧은 코드.** 스무 글자 안 |
| 글 | 미해결 LRE, 채집, 적은 것, 주간 점검 | JSON 파일 |

**셈이 먼저다.** 셈이 어긋나면 진도가 어긋나고 그것이 48주를 밀어낸다.
글이 어긋나는 것은 나중에 합칠 수 있다. 같은 날짜에 둘 다 남으면 된다.

## 5. 지금 무엇이 잘못되는가

기기 둘을 쓰고 규칙을 안 지키면 이렇게 된다.

| 하는 일 | 지금 결과 |
|---|---|
| 양쪽에서 회차 끝냈다를 누른다 | 한 과가 이틀 만에 세 회차를 다 채운다 |
| 양쪽에서 카드를 돈다 | 간격 반복이 기기마다 다른 날을 가리킨다 |
| 한쪽에서만 적는다 | 다른 기기는 그날이 빈 날로 남는다 |
| 나중에 JSON 을 가져온다 | **덮어쓴다.** 합치지 않는다 |

마지막이 제일 나쁘다. `imFile` 이 통째로 덮는다. T184 에 되돌리기를 붙여 뒀지만
**되돌리는 것과 합치는 것은 다르다.**

## 6. D단계가 만들 것

| 턴 | 무엇 |
|---|---|
| T234~T236 | 짝 코드. 셈을 스무 글자로 주고받는다 |
| T237~T238 | 합치기. 둘이 다른 값을 들고 만났을 때 무엇을 남기는가 |
| T239~T240 | 두 기기가 각자 다른 것을 보는 판 |
| T241 | 기기가 하나뿐인 날의 정식 절차 |

그리고 이 문서가 정한 것 셋을 그 턴들이 지킨다.

**하나. 안 건너가는 여섯은 안 건너간다.** 코드에도 파일에도 안 담는다.
**둘. 셈은 코드로, 글은 파일로.** 사람이 452글자를 치게 만들지 않는다.
**셋. 가져오기는 덮는 것이고 합치는 것이 아니다.** 합치는 자리를 따로 만든다.

## 7. 코드 규격 (T234)

### 7.1 열세 글자다

4장에서 숫자만 담으면 19글자라고 쟀다. 그것은 쉼표로 이은 길이다.
**자리마다 폭을 정해 비트로 쌓으면 열세 글자**가 된다.

| 자리 | 폭 | 무엇 |
|---|---|---|
| done | 9 | **끝낸 세션 수.** 0에서 288. 이것이 진도다 |
| status | 2 | 없음 정상 비상판 결석 |
| speak | 8 | 발화 분 |
| cards | 8 | 드릴 장수 |
| lre | 6 | LRE 횟수 |
| unres | 6 | 미해결 **건수**. 글이 아니다 |
| coll | 6 | 채집 **건수**. 같다 |
| round | 2 | 그날 강의 회차 |
| same | 6 | 블록 4에서 겹친 것 |
| diff | 6 | 블록 4에서 안 겹친 것 |

합이 59비트다. 다섯 비트씩 잘라 열두 글자가 되고 검사 글자 하나가 붙는다.

### 7.2 헷갈리는 글자를 뺐다

서른두 글자를 쓰되 **I 와 L 과 O 와 U 를 뺐다.**
1 과 I, 0 과 O 는 손으로 칠 때 섞인다. U 는 V 와 섞인다.

그리고 **친 것을 받아 준다.** 상대가 I 를 쳤으면 1 로 읽는다.
잘못이 아니라 손이 아는 대로 친 것이다.

### 7.3 검사 글자 하나

한 글자를 잘못 친 것과 **두 글자를 바꿔 친 것**을 잡는다.
자리마다 무게를 달리 줘서 뒤엣것도 걸린다. 사람이 제일 흔히 하는 실수가 그것이다.

**틀렸다고만 말하지 않는다.** 무엇이 안 맞는지를 말한다. 안 그러면 다시 칠 수가 없다.

### 7.4 담지 않는 것

`docs/pair.md` 3장이 정한 여섯은 안 담는다. 그리고 **글도 안 담는다.**
미해결 LRE 와 채집은 건수만 간다. 문장은 JSON 파일로 간다.

건수만 가도 쓸모가 있다. **한쪽이 둘을 적고 한쪽이 0이면 그날 대조를 안 한 것이다.**

## 8. 화면과 바로잡음 (T235)

### 8.1 바로잡음. 오늘 것만 만든다

7장을 쓸 때 첫 자리를 `session` 으로 두고 날을 골라 코드를 만들게 했다.
**그것이 틀렸다.** 진도는 오늘 세는 값이고 활동량은 그날 값이다.

어제를 골라 코드를 만들면 **오늘의 진도와 어제의 활동량**이 한 코드에 담긴다.
둘 다 그럴듯해 보이는데 둘 다 못 믿는다. 어긋난 것이 안 보이는 꼴이다.

고친 것 둘이다.

| 전 | 후 |
|---|---|
| 날을 고른다 | **오늘 것만 만든다.** 맞출 자리는 세션이 끝난 직후다 |
| `session` (몇 번째를 하는 중) | `done` (끝낸 세션 수). 두 기기가 바로 견줄 수 있는 값 |

### 8.2 진도와 활동량은 무게가 다르다

**활동량은 원래 다르다.** 둘이 같은 분을 말할 이유가 없다.
진도가 갈리면 48주가 밀린다. 그래서 화면이 그 둘을 따로 센다.

| 갈래 | 자리 | 갈리면 |
|---|---|---|
| 진도 | `done` `status` `round` | **갈린 자리를 이름으로 적고** 맞추라고 시킨다 |
| 활동량 | 나머지 일곱 | 다르다고만 적는다. 맞추라고 안 한다 |

### 8.3 화면은 읽기만 한다

**상대 코드를 읽어 무엇이 다른지만 보인다. 안 고친다.**
합치는 것은 다른 일이고 다른 자리다 (T237).

6장에 "가져오기는 덮는 것이고 합치는 것이 아니다" 라고 적어 놓고
여기서 또 덮으면 같은 잘못을 두 번 하는 것이다.

### 8.4 손으로 치는 자리에서 챙긴 것 셋

| 무엇 | 왜 |
|---|---|
| 네 글자씩 끊고 검사 글자를 뗀다 | 열두 글자를 한 줄로 두면 읽다가 자리를 잃는다 |
| 길이가 틀리면 길이를 말한다 | 빠뜨린 것을 "마지막 글자가 안 맞는다" 고 하면 엉뚱한 자리를 본다 |
| 덜 친 동안 몇 글자인지만 센다 | 틀렸다고는 안 한다. 그렇다고 조용하면 왜 조용한지를 모른다 |

## 9. 코드가 못 잡는 것 (T253)

**짝 코드는 시작일을 안 담는다.** 그것이 틀린 것은 아니다.
진도는 끝낸 세션 수로 세고 시작일은 그 셈에 안 든다 (`plan()`).
시작일이 하루 밀려도 몇 주 며칠은 그대로다.

그런데 **판 씨앗에는 시작일이 든다** (`docs/round.md` 3장).
그래서 이런 자리가 생긴다.

| | |
|---|---|
| 두 기기의 시작일 | 다르다 |
| 짝 코드 | **같다.** 진도가 안 갈렸다 |
| 판 차례 | **갈렸다.** 씨앗이 다르다 |

세션 끝에 코드만 견주면 "다 같다" 고 나오고 다음 판에서 둘이 다른 것을 본다.

코드에 시작일을 담자면 자리가 늘고 글자가 는다.
**날짜 하나는 사람이 읽으면 된다.** 화면이 코드 밑에 시작일을 적고
그것도 읽으라고 말한다. 읽는 데 3초다.

기기가 못 하는 것을 사람이 한다는 것과 같은 자리인데 방향이 반대다.
여기서는 **기계가 할 수는 있는데 값이 안 맞는다.** 그래서 사람에게 준다.
