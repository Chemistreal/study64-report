# 외부 제작 음성 반입 규격

신뢰도: A 생성 (2인 프로토콜, 제작 관리)
지위: **제안.** docs/spec.md 로 승격되기 전까지 임시 규격이다.
spec.md 와 충돌하면 spec.md 가 이긴다. 승격 여부는 사용자만 정한다.
등록: state/journal.md 기준서 개정 대기 6번

---

## 0. 왜 이 문서가 필요한가

기준서 1.2는 음성 자료 전부를 C등급으로 두고 "만들지 않고 외부를 겨눈다"고 정했다.
그 조항의 근거는 하나였다. 음성을 만들 수 없다는 것.

이제 외부에서 생성된 음성이 들어온다. 전제가 바뀌었다.
전제가 바뀌면 조항을 그대로 쓰거나 그대로 버리는 게 아니라 다시 쓴다.

이 문서가 다시 쓴 결과다. 핵심은 한 줄이다.
**생성된 음성은 음성 문제를 푼 게 아니라 1층 문제를 푼 것이다.**

---

## 1. 등급 분리 (신설)

기준서 1.2의 C등급을 둘로 가른다.

| 등급 | 대상 | 층 |
|---|---|---|
| C-real | 사람이 실제로 말한 것을 녹음한 것 | 1층과 2층 둘 다 가능 |
| C-gen | 기계가 생성한 음성 | **1층 전용** |

C-real 예시: VOA Learning English, LibriVox, Santa Barbara Corpus.
C-gen 예시: GPT 계열이 만든 음성, 브라우저 음성 합성, 상용 TTS.

C-gen 은 2층을 대체하지 못한다. 이유는 5장에 있다.

---

## 2. 반입 조건

넷을 다 충족해야 반입한다. 하나라도 빠지면 돌려보낸다.

### 2.1 대본 동반 필수

대본 없는 음성은 받지 않는다. 예외 없다.

이유는 기준서 1.3이다. 이 과정의 구조적 최대 위험은
학습자 두 사람이 영어 제로라 오류를 검출할 사람이 없다는 것이다.
나는 음성을 들을 수 없다. 대본은 검사할 수 있다.
그러니 검사 가능한 형태로 들어와야 한다.

대본이 없으면 그 음성은 아무도 검사하지 않은 채로
학습자 귀에 그대로 들어간다. 그게 이 과정이 제일 피해야 하는 경로다.

### 2.2 메타 명시

대본 상단에 다음을 적는다. 하나라도 없으면 반입 거부다.

```
신뢰도: C-gen
종류: 생성 음성
음성 파일: eng2p_audio_q1_001.mp3
화자 수: 2
속도: 느림
길이: 2분 40초
트랙: 청크
분기: Q1
제작: 외부 생성
학습용 인공물: 예
```

화자 수와 속도와 길이는 기준서 10.2 재료 조건과 대조하기 위한 것이다.
조건에 안 맞으면 그 분기에 못 쓴다.

### 2.3 인공물 표기

C-gen 대본은 상단에 학습용 인공물이라고 밝힌다.
기준서 6.2가 1층 대화에 요구하는 것과 같은 표기다.

표기를 빼면 학습자가 생성 음성을 실제 영어로 오인한다.
소리 훈련에서 그 오인은 텍스트에서보다 훨씬 비싸다. 귀에 박히기 때문이다.

### 2.4 파일명

기준서 15장을 따른다. ASCII 만 쓴다.

```
eng2p_audio_q1_001.md    대본
eng2p_audio_q1_001.mp3   음성
```

대본과 음성은 확장자만 다르고 이름이 같아야 한다.
음성 파일은 저장소에 담지 않는다. 8장을 본다.

## 3. 대본 검사

반입한 대본은 `python3 scripts/check.py out/audio/<파일>` 을 통과해야 한다.
통과 못 하면 미반입이다. 검사 항목은 다음과 같다.

| 항목 | 판정 |
|---|---|
| 신뢰도 표시가 C-gen 또는 C-real 인가 | 실패 |
| 메타 8항목이 다 있는가 | 실패 |
| C-gen 인데 인공물 표기가 없는가 | 실패 |
| C-gen 인데 2층 자료라고 적혀 있는가 | 실패 |
| 화자 수와 속도가 분기 조건에 맞는가 | 경고 |
| 한글 음차가 있는가 | 경고 |
| 금지 문자, 파일명 규약 | 실패 |

검사는 형식만 본다. 영어가 맞는지는 못 잡는다.
그건 5장 판정 루프에서 처리한다.

## 4. 쓸 수 있는 곳과 없는 곳

이 표가 이 문서의 실질이다.

### 4.1 쓴다

| 용도 | 왜 생성 음성이 오히려 나은가 |
|---|---|
| 청크 반복 노출 | 같은 청크를 원하는 횟수만큼 정확히 반복시킬 수 있다 |
| 문형 집중 노출 | 목표 형식만 골라 담을 수 있다. 실제 자료는 그게 안 된다 |
| repair 대본 연습 | 되묻기 5단계 강도를 순서대로 배치할 수 있다 |
| 3레지스터 대조 | 같은 내용을 격식과 중립과 친근으로 정확히 맞춰 낼 수 있다 |
| 역할형 카드 재료 | 상황과 관계와 목적을 지정한 대로 만들 수 있다 |
| A가 못 읽는 재료의 발음 참조 | Q1 초반에 A도 영어 제로다. 이 구멍을 메운다 |

생성 음성의 강점은 통제다. 실제 자료로는 절대 못 하는 걸 한다.

### 4.2 안 쓴다

| 용도 | 왜 안 되는가 |
|---|---|
| Q1 축약 20종 청취 식별의 **통과 판정** | 5장 |
| 2층 실제 발화 자료 | 겹침과 중단과 자기수정이 없다. 있어도 흉내다 |
| 대화의 중단과 겹침 양상 관찰 | 같은 이유 |
| 현행 구어 빈도의 근거 | 생성물의 빈도는 실제 빈도가 아니다 |
| 지역 변이와 화자 변이 | 통제된 목소리다. 변이가 아니라 설정이다 |

## 5. Q1 소리 트랙에 관한 단서

이 장이 제일 중요하다.

Q1은 730시간 중 첫 180시간이고 소리에 40%를 쓴다.
그 이유는 하나다. 지금 안 잡으면 굳어서 나중에 못 잡기 때문이다.
1년 목표 자체가 "소리가 굳지 않은 채로 2년차에 진입하는 것"이다.

생성 음성에는 두 가지 문제가 있다.

**첫째, 과발음 경향.**
합성 음성은 또박또박 읽는 쪽으로 기운다.
실제 원어민이 대부분의 발화에서 쓰는 약형이 잘 안 나온다.
학습자가 이 소리에 귀를 맞추면 실제 발화를 못 알아듣는다.
Q1 통과 조건인 축약 20종 식별이 정확히 그 능력이다.

**둘째, 축약이 나와도 그건 합성된 축약이다.**
철자를 gonna 로 써 주면 음성은 gonna 라고 읽는다.
그건 연결발화에서 자연히 줄어든 소리가 아니라 줄어든 철자를 읽은 소리다.
둘은 다르다. 후자에 귀를 맞추면 전자를 못 잡는다.

그래서 규칙은 이렇다.

> **Q1 소리 트랙의 통과 판정은 C-real 로만 한다.**
> C-gen 은 연습에 쓰고 판정에는 안 쓴다.

연습과 판정을 가르는 게 핵심이다. 연습은 통제된 자료가 낫고
판정은 실제 자료로만 의미가 있다.

## 6. 판정 루프에서의 위치

기준서 5.3의 역방향 판정 루프에 한 줄이 추가된다.

주 1회 판정 세션의 입력은 이제 셋이다.

1. 미해결 LRE 목록
2. 채집 표현 목록
3. **반입 음성 대본에서 학습자가 의심한 지점**

3번이 새로 생긴다. 학습자는 영어를 모르지만
"이 문장은 다른 데서 본 것과 다르다"는 감각은 생긴다.
그 감각을 버리지 않고 입력으로 받는다.

반복해서 같은 지점이 올라오면 그 대본은 폐기한다.
고쳐 쓰지 않는다. 한 번 귀에 박힌 소리는 텍스트보다 비싸다.

## 7. 반입 절차 요약

```
1. 대본과 음성을 받는다. 대본 없으면 거부
2. 대본을 out/audio/eng2p_audio_q1_001.md 로 저장
3. python3 scripts/check.py out/audio/eng2p_audio_q1_001.md
4. 실패면 돌려보낸다. 통과면 4.1 용도로만 배치
5. 음성 파일은 저장소에 넣지 않는다. 학습자 기기에 둔다
6. english.html 클립 탭에서 대본과 구간을 맞춘다
7. state/journal.md 에 반입 기록
```

## 8. 음성 파일을 저장소에 담지 않는 이유

기준서와 무관한 실무 사유다.

- `https://chemistreal.github.io/study64-report/` 는 공개 주소다
- GitHub Pages 에는 비밀번호 기능이 없다
- 저장소를 private 으로 돌리면 Enterprise 가 아닌 이상 Pages 가 안 뜬다

생성 음성 자체는 저작권 문제가 덜하지만, 저장소를 음성 저장고로 쓰기
시작하면 나중에 저작권 있는 자료가 섞여 들어간다. 경계를 처음부터 긋는다.

대본은 텍스트라 저장소에 넣는다. 검사 대상이므로 넣어야 한다.
음성은 학습자 기기에 두고 클립 탭으로 다룬다.

## 부록. 트랙 표기 (2026-08-07 추가)

원자료의 머리말 `트랙:` 은 `미지정 (강의가 정한다)` 으로 적을 수 있다.

트랙은 자료의 속성이 아니다. 그 자료를 어느 트랙 훈련에 쓰는지는
강의가 정한다. 같은 음성을 소리 트랙에서도 청크 트랙에서도 쓸 수 있다.

VOA 52과는 처음에 전부 소리로 일괄 입력돼 있었다. 근거가 없어서 미지정으로 바꿨다.
지어낸 값을 남기는 것보다 비워 두는 쪽이 낫다.
