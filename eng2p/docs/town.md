**실제 호놀룰루를 바탕으로 실제보다 화려하고 자세하게, 사는 것처럼 짓는다** (사용자 2026-10-07).

동네는 **지은 것**이다. 실제 거리를 그대로 옮기지 않는다. 그 까닭은 셋이다.

| 까닭 | 무엇 |
|---|---|
| 가게와 사람은 가상이다 | game.md 2장. 실제 거리를 옮기면 실제 가게 자리가 따라온다 |
| 장소는 열넷이다 | 도시 전체가 필요하지 않다. 걸어서 3분 안에 다 닿아야 하루 120분 안에 돈다 |
| 권리 | 거리 자료를 체계적으로 옮기면 ODbL 이 걸린다 (`docs/sources.md`) |

**배경은 실제다.** Lēʻahi(다이아몬드 헤드)의 능선, 뒤의 Koʻolau 산맥, 해안선과 산호초에 부서지는 파도는
퍼블릭 도메인 지형 자료(미국 지질조사국, 해양대기청)에서 깎는다. 멀리 보이는 것은 진짜고 걸어 다니는 동네는 지은 것이다.

이 문서의 표가 원본이다. `scripts/derive_town.py` 가 읽어 `out/game/town.json` 을 낸다.
**손으로 JSON 을 안 고친다.**

**하와이어 지명은 바로 적는다.** ʻokina 는 U+02BB 한 글자로만 쓰고 장음은 ā ē ī ō ū 로 쓴다.
곧은 따옴표나 굽은 따옴표가 ʻokina 자리에 들어가면 `derive_town.py` 가 실패로 낸다. 지도와 표지도 이 글자를 쓴다.

## 1. 판

| 무엇 | 값 |
|---|---|
| 좌표 | 미터. x 는 동쪽(Lēʻahi 쪽), y 는 북쪽(산 쪽). 해안선이 y = 0 이다 |
| 크기 | 동서 1200, 남북 900 |
| 바다 | y 가 0 보다 작은 곳. 산호초 선이 y = -350 |
| 바람 | 북동 무역풍. 야자수와 깃발과 빨래가 남서쪽으로 기운다 |
| 해 | 뜨는 자리가 철 따라 옮긴다. 겨울에는 Lēʻahi 위로 뜨고 여름에는 산 쪽으로 비켜 뜬다. 저녁에 바다로 진다 |
| 지도 나침반 | 동서남북 대신 mauka(산 쪽), makai(바다 쪽), ʻEwa 쪽, Lēʻahi 쪽 넷. 지도 글자로만 쓴다 (대사 규칙은 그대로) |

## 2. 배경. 실제 지형

| 배경 | 어디 | 어떻게 보이나 |
|---|---|---|
| Lēʻahi (다이아몬드 헤드) | 동남동 3km | 분화구 능선. 겨울 아침 해가 그 위로 뜬다 |
| Koʻolau 산맥 | 북쪽 8km | 초록 주름 능선. 오후에 구름이 걸리고 계곡에 무지개가 선다. 산 쪽은 비가 잦다 |
| 해안선과 산호초 | 남쪽 | 얕은 곳은 옥빛, 산호초 너머는 짙은 남색. 산호초 선에서 흰 파도가 부서진다 |
| 바다 위 | 남쪽 수평선 | 저녁에 동네 카누 클럽이 연습한다. 이름 있는 실제 배는 그리지 않는다 |

## 3. 화려하게. 실제보다 더하는 것

실제 호놀룰루에도 있는 것을 **더 자주, 더 짙게** 보여 준다. 없는 것을 만들지는 않는다.

| 실제 | 게임에서 |
|---|---|
| 오후 소나기 뒤 무지개 | 소나기가 지나간 날은 거의 늘 선다. 두 겹 무지개도 잦다 |
| 저녁 노을 | 블록 4 는 늘 노을이나 그 직후다. 하늘이 주황에서 보라로 넘어간다 |
| 꽃나무 | 길마다 꽃이 핀다. 플루메리아, 히비스커스, 부겐빌레아, 레인보우 샤워 트리, 붉은 봉황목, ʻilima, 해안의 naupaka. 철마다 색이 바뀐다 (6장) |
| 큰 반얀나무 | 도서관 마당에 하나. 그 그늘이 블록 1 의 자리다 (Q2) |
| 밤 | 산책로에 줄 전구, 시장에 등불. 밤에 도마뱀(gecko)이 운다 |
| 명절 | 그 주에 꾸밈이 바뀐다 (6장. 날은 world.md 6.1 달력이 정한다) |
| 물 | 운하에 비친 하늘, 파도 거품, 젖은 길의 반사 |

**안 더하는 것.** 실제 상표와 간판, 실제 사람, 하와이 원주민의 신성한 상징을 꾸밈으로 쓰는 것 (world.md 3.1).
티키, 풀치마, 훌라 인형, 횃불 쇼, 늘 알로하 셔츠에 레이를 건 원주민 그림도 안 쓴다. 배경 음악을 우쿨렐레로 채우지 않는다.

## 7. 사는 것처럼

장면 밖에서도 동네가 돈다. **누구도 두 사람에게 말을 걸지 않는다.** 말은 장면 안에서만 한다.
아래는 관광 엽서가 아니라 사는 사람의 습관이다. 출처 없는 생활 관찰이라 B등급이다.

| 무엇 | 언제 |
|---|---|
| 버스 | 15분마다 큰길에 선다. 앞문으로 타고 뒷문으로 내린다. 내릴 때 줄을 당기고 기사에게 고맙다고 한다. 앞자리는 노인 자리다. 정류장 이름은 Kalākaua, Kapiʻolani, Mōʻiliʻili 처럼 하와이어다. 실제 회사 이름 없이 그냥 시내버스다 |
| 사이렌 시험 | 매달 첫 근무일 11시 45분에 1분 동안 같은 음이 울린다. 동네 사람은 신경 쓰지 않는다 |
| 신발 벗기 | 새 집과 이웃집 현관. 슬리퍼(고무 샌들)가 줄지어 있다 |
| 포틀럭 | 동네 모임, 연말, 집들이. 알루미늄 쟁반과 큰 밥솥. 빈손으로 가지 않는다. 남은 음식은 싸 가는 접시에 담아 준다 |
| 망고 나누기 | 망고 철에 이웃이 봉지에 담아 문 앞에 두고 간다 |
| 해변 청소 | 한 달에 한 번 토요일 아침. 동네 모임이 오래 해 온 일이고 두 사람은 자원봉사자로 낀다. 장갑과 자루, 미세 플라스틱 체. 산호를 밟지 않는다. 쉬는 바다거북에서 3m, 몽크물범에서 15m, 어미와 새끼에게서 45m 떨어진다. 몽크물범 둘레에 줄과 표지가 선다. 리프 세이프 자외선 차단제. 운하 물에는 들어가지 않는다 |

**뒤의 웅성임은 알아들을 수 없어야 한다.** 알아들리는 영어가 뒤에 깔리면 두 사람이 장면 말과 섞어 듣는다.
에셋 조사가 그렇게 일렀다 (CC0 군중 녹음을 낮은 음역만 남겨 겹친다). 웅성임에 Pidgin 이 섞여도 되지만 우스개로 쓰지 않는다.

## 8. 기계가 안 보는 것

**걷고 싶은 동네인가.** 표는 장소와 사람과 빛을 맞췄다. 거기 서 있고 싶은지는 4주 리허설에서 두 사람이 말해 준다.
