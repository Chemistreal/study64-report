# 동네. 두 사람이 1년을 사는 곳

신뢰도: B 생성 (설계. 호놀룰루 지리는 공개 자료 조사 결과를 따르되 동네 자체는 지은 것이다)
검증로그: 2026-10-07 / 장소와 사람과 건물 표를 game.md 4장, world.md 4장과 맞춤 / derive_town.py 통과 / 배경 지형의 방향과 거리는 sources.md 지리 조사로 다시 본다
상위 규격: docs/game.md 4장 / docs/world.md 4장 6장
작성일: 2026-10-07

**실제 호놀룰루를 바탕으로 실제보다 화려하고 자세하게, 사는 것처럼 짓는다** (사용자 2026-10-07).

동네는 **지은 것**이다. 실제 거리를 그대로 옮기지 않는다. 그 까닭은 셋이다.

| 까닭 | 무엇 |
|---|---|
| 가게와 사람은 가상이다 | game.md 2장. 실제 거리를 옮기면 실제 가게 자리가 따라온다 |
| 장소는 열넷이다 | 도시 전체가 필요하지 않다. 걸어서 3분 안에 다 닿아야 하루 120분 안에 돈다 |
| 권리 | 거리 자료를 체계적으로 옮기면 ODbL 이 걸린다 (`docs/sources.md`) |

**배경은 실제다.** 다이아몬드 헤드의 능선, 뒤의 산맥, 해안선과 산호초에 부서지는 파도는
퍼블릭 도메인 지형 자료(미국 지질조사국, 해양대기청)에서 깎는다. 멀리 보이는 것은 진짜고 걸어 다니는 동네는 지은 것이다.

이 문서의 표가 원본이다. `scripts/derive_town.py` 가 읽어 `out/game/town.json` 을 낸다.
**손으로 JSON 을 안 고친다.**

## 1. 판

| 무엇 | 값 |
|---|---|
| 좌표 | 미터. x 는 동쪽(다이아몬드 헤드 쪽), y 는 북쪽(산 쪽). 해안선이 y = 0 이다 |
| 크기 | 동서 1200, 남북 900 |
| 바다 | y 가 0 보다 작은 곳. 산호초 선이 y = -350 |
| 바람 | 북동 무역풍. 야자수와 깃발과 빨래가 남서쪽으로 기운다 |
| 해 | 아침에 다이아몬드 헤드 위로 뜨고 저녁에 바다로 진다 |

## 2. 배경. 실제 지형

| 배경 | 어디 | 어떻게 보이나 |
|---|---|---|
| 다이아몬드 헤드 | 동남동 3km | 분화구 능선. 아침 해가 그 위로 뜬다 |
| 산맥 | 북쪽 8km | 초록 주름 능선. 오후에 구름이 걸리고 계곡에 무지개가 선다 |
| 해안선과 산호초 | 남쪽 | 얕은 곳은 옥빛, 산호초 너머는 짙은 남색. 산호초 선에서 흰 파도가 부서진다 |
| 바다 위 | 남쪽 수평선 | 저녁에 범선과 카누가 지나간다 |

## 3. 화려하게. 실제보다 더하는 것

실제 호놀룰루에도 있는 것을 **더 자주, 더 짙게** 보여 준다. 없는 것을 만들지는 않는다.

| 실제 | 게임에서 |
|---|---|
| 오후 소나기 뒤 무지개 | 소나기가 지나간 날은 거의 늘 선다. 두 겹 무지개도 잦다 |
| 저녁 노을 | 블록 4 는 늘 노을이나 그 직후다. 하늘이 주황에서 보라로 넘어간다 |
| 꽃나무 | 길마다 꽃이 핀다. 플루메리아, 히비스커스, 부겐빌레아, 레인보우 샤워 트리. 철마다 색이 바뀐다 |
| 큰 반얀나무 | 도서관 마당에 하나. 그 그늘이 블록 1 의 자리다 (Q2) |
| 밤 | 산책로에 줄 전구, 시장에 등불 |
| 명절 | 달마다 꾸밈이 바뀐다 (6장) |
| 물 | 운하에 비친 하늘, 파도 거품, 젖은 길의 반사 |

**안 더하는 것.** 실제 상표와 간판, 실제 사람, 하와이 원주민의 신성한 상징을 꾸밈으로 쓰는 것 (world.md 3.1).

## 7. 사는 것처럼

장면 밖에서도 동네가 돈다. **누구도 두 사람에게 말을 걸지 않는다.** 말은 장면 안에서만 한다.

| 무엇 | 언제 |
|---|---|
| 버스 | 15분마다 큰길에 선다 |
| 조깅하는 사람, 개 산책 | 아침 산책로 |
| 서핑하는 사람 | 산호초 선 앞. 오전 |
| 장 보는 사람 | 한낮 시장이 가장 붐빈다 |
| 일하는 사람 | 평일 사무실 불이 켜진다 |
| 아이들 | 오후 공원 |
| 이웃의 저녁 | 라나이에 불이 켜지고 고기 굽는 연기 |

**뒤의 웅성임은 알아들을 수 없어야 한다.** 알아들리는 영어가 뒤에 깔리면 두 사람이 장면 말과 섞어 듣는다.
에셋 조사가 그렇게 일렀다 (CC0 군중 녹음을 낮은 음역만 남겨 겹친다).

## 8. 기계가 안 보는 것

**걷고 싶은 동네인가.** 표는 장소와 사람과 빛을 맞췄다. 거기 서 있고 싶은지는 4주 리허설에서 두 사람이 말해 준다.
