## 현재 자료와 구분

새 자유 대화 선택기나 파생 JSON 또는 엔진 코드를 만들지 않았어요. town 7장의 기존 배경 생활은 누구도 먼저 말을 걸지 않는다고 적어요. 이번 TASK가 새 greet·meet·place 후보 집필을 청했으므로 후보만 새 파일에 만들었고, 기존 배경에서 자동으로 말이 나온다고 주장하지 않아요. 인물 표에 없는 의료·입국 정책·실제 가게 사실을 추가하지 않았어요. 이름 자리는 0줄, option은 0줄이에요. 모든 영어는 새로 지었으므로 점검 B예요. Q1에는 한국어 풀이가 있고 나머지는 -예요.
