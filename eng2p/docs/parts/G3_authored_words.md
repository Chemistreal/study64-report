# G3 이후 미션 추가 낱말 등급표

신뢰도: B (장면에서 쓰는 뜻으로 직접 매긴 근사 등급이며 공식 CEFR 목록이 아니에요.)
검증로그: 2026-10-11 / 기존 authored_words.md·어간 중복·해당 미션 뜻 대조 / 보류 / 기존 어간의 등급을 바꾸지 않았고 새 낱말은 검수자가 뜻과 등급을 확인해야 해요.

기존 등급표에 이어 붙이는 fenced block 형식이에요. 이미 표에 있는 어간은 다시 올리지 않았어요. 같은 어간의 새 판단이 겹치면 낮은 등급으로 통과시키지 않고 의미를 검토해요. 지역 고유 이름은 각 미션의 허용 이름 메타에서만 다뤄요.

```A1
camera sky teacher was
```

```A2
anytime beside choice closer done easily enter felt flower group host instead mark notice parade path quite rest rule sheet shorter sunset usually visitor wave while
```

```B1
accept allow aloud arrow calm conditions decision describe discuss display either explanation farther guide instruction length loose pause program rather review route safety separate signal staff suitable surf warn
```

조각을 합칠 때 guide, staff, program의 판단이 A2와 B1로 겹쳤어요. guide는 투어 안내자, staff는 현장 안내를 확인할 직원들, program은 공연 안내 자료나 방문 프로그램이라는 뜻으로 대조했어요. 하나의 어간에 한 등급만 쓰는 기존 형식에 맞춰 세 낱말 모두 B1을 유지했고, 관문을 통과하려고 낮추지 않았어요. 이 보수적인 판단도 공식 등급 확정은 아니며 사람 검수가 필요해요.

while은 잠시 동안과 두 행동의 동시 진행, either는 부정문에서 역시 또는 어느 쪽에도 해당하지 않는 범위, rather는 would rather의 선호로 쓰여요. was와 felt는 불규칙 과거형이고, warn은 warning을 기존 검사기가 줄인 어간이에요. 안전 관련 낱말은 직원에게 확인을 요청하는 언어 연습용이며 실제 안전 지침을 제공하는 표가 아니에요.
