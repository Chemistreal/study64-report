## 선택 조건과 한계

같은 역할이라도 first-release 미션의 같은 목소리 서명으로 이어져야 해요. 장소에서만 새 물건을 가리키는 말을 선택하며 표의 탁자·상자·종이·의자 등은 가상 장면 소품 제안이라 실제 게임에 보인다고 확인하지 않았어요. 반복 방문과 선택 기억은 저장된 만남이 있을 때만 선택하고 Q1의 again·back도 같은 조건을 지켜요. 선택기·자유 대화 UI·이미지·TTS·소품은 구현하지 않았어요. 실제 매장 가격·일정·재고·대여 규칙이나 안전 신호를 새로 만들지 않았어요.

Q1에서 기존 A2와 B1로 등급이 있는 welcome·would·receipt·shirt·mask·gear 등을 임의로 내리지 않았어요. 이미 알고 있는 말과 눈앞의 대상 this·things·paper로 고쳐서 말하고 나중 분기에는 원래 물건 이름으로 질문해요. 엄격한 기존 grade와 새 낱말 규칙을 지키는 안이지만 지나치게 막연한 지시어가 실제 장면에서 알맞은지는 B예요.

미션별 같은 가게의 안내·서빙이나 매장·계산 역할은 서로 다른 사람이고 같은 얼굴이나 이름을 공유하게 만들지 않아요. 이웃은 실제 랜드마크 없는 복도라 제안 장소 id만 유지해요. 새 인물의 개인 연도나 가족·출신 이야기를 지어내지 않았어요.
