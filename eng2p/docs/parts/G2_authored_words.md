# G2 이후 미션 추가 낱말 등급표

신뢰도: B (장면에서 쓰는 뜻으로 직접 매긴 근사 등급이며 공식 CEFR 목록이 아니에요.)
검증로그: 2026-10-11 / 기존 authored_words.md·어간 중복·해당 미션 뜻 대조 / 보류 / 기존 어간의 등급을 바꾸지 않았고 새 낱말은 검수자가 뜻과 등급을 확인해야 해요.

기존 등급표에 이어 붙이는 fenced block 형식이에요. 이미 표에 있는 어간은 다시 올리지 않았어요. 같은 어간의 새 판단이 겹치면 낮은 등급으로 통과시키지 않고 의미를 검토해요. 지역 고유 이름은 각 미션의 허용 이름 메타에서만 다뤄요.

```A1
answer both by close date end fifteen keep longer meal paper problem side sit stand understand use window
```

```A2
account add address altogether amount appointment cost counter cross details drawer dryer envelope extra form groceries guitar heat higher hold hurt id include included information label line list loaf local machine mail main may moment offer paid passport printed reach sauce screen service setting shall shelves shown sign since style text throat through topping toppings traffic udon used washer
```

```B1
balance charge cough delivery detergent document drop head insert lower original partner pharmacist purchase reader sore steps trunk volume
```


## 뜻과 겹친 판단을 정리한 기준

add는 음식 고명과 장바구니에 더 넣는 동작, list는 물건이나 복용 목록, address는 주소 서류의 주소 뜻으로 A2에 두었어요. partner는 동행하는 배우자나 함께 온 사람의 뜻으로 B1에 두었어요. 각 작성자의 A1/A2 또는 A2/B1 판단이 겹쳤지만 더 낮은 등급으로 관문을 통과시키지 않았어요. 이 뜻의 난이도 경계는 여전히 사람 검수가 필요해요.

account와 balance는 은행 계좌와 잔액, charge는 청구 요금, trunk는 자동차 짐칸, directions는 약품의 사용법 뜻도 포함해요. udon은 일본 음식 이름이며 하와이어로 다루지 않아요. 세탁기와 전화 요금의 전문 낱말은 해당 장면의 질문과 설명에서만 써요. 공식 CEFR 등급이나 실제 지역 사용 빈도를 검증했다는 뜻은 아니에요.
