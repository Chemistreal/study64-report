# G28 카드 양면 내용 검토

신뢰도: B 생성 (600장 직접 읽기와 자료 대조)
검증로그: 2026-10-13 / 카드 원문, 현재 세션, 기존 기계 열쇠 / 보류 / 원어민·실제 음성·학습자 검토는 못 했어요

카드 600장 양면 1,200개를 모두 읽었어요. 판정표의 ok는 문면에서 추가 문제를 찾지 않았다는 뜻이며 전체 영어 등급이나 음성 검증 합격이 아니에요. A면은 NPC/게임, B면은 두 학습자의 공용 수행 지시예요. 두 면은 같은 공동 과제의 서로 다른 역할이어야 하며 단순히 문장 일부가 같다는 이유로 중복 결함으로 세지 않았어요.

공식 CEFR 등급표가 없어 wordlist만으로 전체 영어 등급을 확정할 수 없어요. G28_words.csv는 모든 영어 철자형과 승인 목록 여부, 핵심 대본 최초 등장과 카드 최초 세션을 비교해요. 문법 설명 속 영어, 의도된 잘못된 예, 인명, 참조 id도 후보에 포함되므로 미학습 위반으로 단정하지 않아요. Q1~Q4는 실제 CEFR 경계와 달라요.

생존어/강세 정답은 실제 녹음과 문맥을 필요로 해요. 검사기는 원형 낱말 수, 재료에 있는 정답 낱말, 명시한 l 위치 등 문맥 없이 계산 가능한 작은 범위만 계산해요. 모든 140 판정형의 의미 정답은 직접 읽었으나 실제 음성의 강세·쉼·삭제·억양과 동적 NPC 선택은 확인하지 못했어요. 기존 judge.json이 카드의 정답을 옮겨 담았다는 사실은 그 정답의 의미 정확성을 증명하지 않아요.

빈 재료나 장면/종이/물건 지적은 카드 원문에 필요한 구현 연결이 적혀 있지 않다는 뜻이에요. game의 전체 기능이 없다고 확정하는 주장이 아니에요. ground, 판 자료와 기계 열쇠의 일부는 이미 존재하고 특정 원문 참조를 언제 어떻게 실행하는지는 실제 게임에서 확인해야 해요. 역할 NPC 응답 후보도 이미 존재하므로 NPC 자체가 없다고 쓰지 않았어요.

현재 세션 3블록은 상한이 없고 오늘/복습 카드 전부를 해요. playblocks.json의 옛 30분 표와 현재 세션의 무제한 값을 모두 기록했어요. 카드 예상 시간보다 다섯 발화의 최소 시간이 긴 사례는 시간 추정 수정 요청이며 카드 생략이나 30분 상한 제안이 아니에요.

중복 CSV는 같은 분기의 동일 영어 재료 목록, near CSV는 한 철자형 교체만 다른 재료 목록이에요. 대조·속도·복습 목표가 다를 수 있어 전부 삭제 결함으로 세지 않아요. Q4-051/101, 052/102, 053/103, 054/104처럼 같은 목표를 다시 쓰는 것은 계단 차이 또는 의도적 반복 표시를 요청했어요.
