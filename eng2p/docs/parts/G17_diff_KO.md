## 메타와 차례 설명 변경

마트의 grs-25 갈래에는 새 NPC 한 줄을 연결했어요. 버스·은행/우편·반품의 반복 갈래는 기존 NPC 답을 그대로 써요. 같은 차례의 다른 기존 후보가 두 번째 답이므로 선택은 실제로 다시 받아요. 은행/우편의 두 번째 선택은 도착 날짜를 다시 들은 뒤 총비용 확인이에요.

원본의 상황값·가상 가격·안내 자료 전제는 보존하고 A/B 고정 자리 안내만 명시했어요. 건너뜀은 전부 -예요. 마루카메의 결제 중복은 이미 G6에서 준비 질문과 결제 방법 질문으로 분리됐고, 다른 장에도 앞 답으로 이미 확정된 값을 다시 요구하는 강제 차례를 새로 발견하지 못했어요. 불필요한 차례를 만들기 위해 skip을 덧붙이지 않았어요.

## 검사 사본 구성

미션을 본문에 올린 검증 사본에서 기존 G2 보관본의 같은 장은 제외하고, outings.md 해당 12행의 집필 상태만 집필 완료로 맞췄어요. 공개는 계속 이후, 해금 시각·등급·장소·첫 공개 상한은 그대로예요. 낱말은 G2/G3/G5 보관본의 새 어간만 현재 등급표에 합쳤고 원래 등급은 바꾸지 않았어요. derive_authored·derive_outings를 돌려 scratch 파생과 B 목록을 재생성한 뒤 원본 check_authored를 실행했어요. 이 준비는 지은 장을 정상 입력으로 놓는 구성이고 검사기나 시험 수정은 아니에요. 실제 원본이나 반환 파일에 이런 비소유 경로 변경은 없어요.
