# 2인 전용 영어 1년 과정 · 전체 설계 기준서 v2

이 문서는 모든 제작물의 상위 규격이다.
이 문서와 충돌하는 개별 판단은 무효로 한다.
규격 변경이 필요하면 개별 제작물을 고치지 말고 이 문서를 먼저 개정한다.

v1 대비 주요 변경: 6트랙으로 확장, 대화문 3층 구조, LRE 지표 도입,
관계 유형 점검 신설, 주제 3축 회전, 슬랭 전면 제외, 검증 프로토콜 신설.

---

## 0. 문서의 지위

이 기준서가 고정하는 것은 다섯 가지다.

1. 무엇을 만들 것인가 (산출물 규격)
2. 어떤 문장으로 쓸 것인가 (문체 규정)
3. 무엇을 하지 않을 것인가 (금지 목록)
4. 무엇을 내가 만들지 않고 조준만 할 것인가 (신뢰도 등급)
5. 만든 것이 맞는지 어떻게 확인할 것인가 (검증 프로토콜)

4번과 5번이 v2에서 신설된 축이다. 이 과정의 구조적 최대 위험이
"오류를 검출할 사람이 없다"는 점이므로, 그 위험을 문서 차원에서 관리한다.

## 1. 불변 전제

12개월간 변경하지 않는다.

| 항목 | 값 |
|---|---|
| 학습자 | 성인 부부 2인, 영어 제로 시작 |
| 시간 | 하루 2시간, 주 6일, 48주, 총 730시간 |
| 수행 형태 | 100% 2인 동시 수행. 개인 학습 블록 없음 |
| 1년 목표 | 화석화 없는 B1+ ~ B2 하단 |
| 최우선 기준 | 학습 효율이 아니라 완주 생존률 |
| 설명 대 연습 | 15 대 85 |

### 1.1 목표에 대한 정직한 명시

원어민급은 2,000~2,500시간이 필요하다. 730시간은 전체의 약 30%다.
1년 과정의 목표는 "영어를 잘하게 되는 것"이 아니라
"소리가 굳지 않은 채로, 청크가 쌓인 채로 2년차에 진입하는 것"이다.

이 문장은 운영 매뉴얼 1장에 그대로 싣는다.
12개월차에 좌절하지 않게 하는 것이 이 명시의 목적이다.

### 1.2 제작 신뢰도 등급 (신설)

모든 제작 항목은 다음 세 등급 중 하나로 분류한다.
등급은 해당 항목을 다루는 모든 제작물에 표시한다.

| 등급 | 의미 | 처리 |
|---|---|---|
| A 생성 | 내가 만들어도 신뢰할 수 있다 | 그대로 제작 |
| B 조건부 | 만들되 검증을 붙인다 | 제작 후 검증 프로토콜 통과 필수 |
| C 조준 | 만들지 않고 외부를 겨눈다 | 채집 지시 + 판정 루프 |

**A 생성**
커리큘럼 설계와 순서, 한국어 화자 대조 설명, 드릴 구조,
복습 스케줄, 2인 프로토콜, 문법 설명, 학습용 기능 대화(인공물 표기 조건)

**B 조건부**
연어와 청크 목록, 레지스터 구분, 화용 표현,
사어 판정, 난이도 등급, 구조적 유머 패턴

**C 조준**
음성 자료 전부, 현행 구어 빈도, 슬랭(전면 제외),
시사 레퍼런스, 실제 대화의 중단과 겹침 양상, 지역 변이

### 1.3 이 과정의 구조적 최대 위험

학습자 두 사람이 영어 제로이므로 제작물의 오류를 검출할 수 없다.
지금까지 성공한 다른 시리즈는 학습자가 해당 분야 전문가였기에
검출기 역할을 했으나, 이 과정에는 그 장치가 없다.

따라서 오류 억제는 두 축으로 한다.
첫째, 제작 시점 웹 검색 검증 (5장).
둘째, 학습자가 실제 자료에서 채집한 것을 내가 판정하는 역방향 루프.
생성보다 판정이 정확하므로, 가능한 한 판정 쪽으로 무게를 옮긴다.

## 2. 구조 규격

### 2.1 6트랙 (v1의 5트랙에서 확장)

| 트랙 | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| 소리 | 40% | 20% | 10% | 5% |
| 청크 | 28% | 32% | 22% | 17% |
| 자동화 | 18% | 26% | 34% | 25% |
| 문법 | 0% | 9% | 13% | 13% |
| 화용 | 8% | 5% | 9% | 25% |
| repair | 6% | 8% | 12% | 15% |

**repair 트랙 신설 근거**
코퍼스 연구는 교재의 대화가 상호작용이 매끄럽고 문제가 없으며
아무도 끼어들거나 동시에 말하지 않는 세계를 그린다고 지적한다.
실제 대화는 중단, 되묻기, 자기수정, 겹침으로 굴러간다.
교재가 안 다루는 영역이면서 실사용 가치는 가장 높다.
제로 시작 학습자에게는 특히 그렇다. 못 알아들었을 때 처리하는 법이
알아듣는 법보다 먼저 필요하기 때문이다.

repair 트랙 내용:
- 못 알아들었을 때 되묻기 (5단계 강도)
- 자기수정과 말 고쳐잡기
- 말 끊기와 끊김 처리
- 이해 확인과 명료화 요청
- 시간 벌기 (머뭇거림의 영어식 형태)
- 대화 유지와 종료

### 2.2 분기별 통과 조건

| 분기 | 누적 | 통과 조건 |
|---|---|---|
| Q1 | 180h | 축약 20종 청취 식별 90%, 강세 박자 재현, 되묻기 3형 자동 |
| Q2 | 365h | 고빈도 600청크 0.5초 인출, 90초 무중단, 자기수정 자연화 |
| Q3 | 550h | 3초 내 반응, LRE 세션당 8회 이상, 겹침 상황 처리 |
| Q4 | 730h | 3분 발화, 3레지스터 구분, 대화 주도권 전환 |

분기 이동은 날짜가 아니라 통과 조건으로 한다. 트랙마다 따로 넘어간다.

### 2.3 표준 2시간 세션

| 블록 | 시간 | 형태 | 대화 |
|---|---|---|---|
| ① 병렬 침묵 | 40분 | 같은 공간, 각자 헤드폰 | 금지 |
| ② 대조 교차 | 30분 | A 설명 → B 재구성 | 필수 |
| ③ 페어 드릴 | 30분 | A 출제 → B 반응, 시간 압박 | 필수 |
| ④ 공동 입력 | 20분 | 동일 자료 함께 청취 | 부분 |

주 7일째는 주간 점검 30분. 누적 기록과 다음 주 실행 의도 확정.

### 2.4 관계 유형 관리 (신설, v2 핵심 추가)

짝 활동 연구는 네 가지 관계 유형을 식별한다.
협력형, 전문가-초보형, 지배-수동형, 지배-지배형.
그리고 협력적으로 상호작용할 때 상대의 숙련도와 무관하게
더 높은 학습 성과가 나온다는 결과가 있다.

**즉 실력 격차보다 관계 유형이 결정적이다.**

v1은 진도 격차를 위험으로 봤으나 이는 부정확했다.
진짜 위험은 격차가 아니라 지배-수동형으로 고착되는 것이다.
부부는 이미 굳은 대화 패턴을 갖고 있어 이 위험이 특히 크다.

**대응 1: 역할 교대 강제**
A와 B는 매일 교대한다. 짝수 날 남편 = A, 홀수 날 아내 = A.
교대의 목적은 성향 편중 교정이 아니라 관계 유형 고착 방지다.

**대응 2: 분기별 관계 유형 자가 점검**
분기마다 다음을 각자 따로 기록하고 대조한다.

| 점검 항목 | 측정 |
|---|---|
| 발화 지분 | 대략 몇 대 몇인가 |
| 주도권 | 주제를 누가 바꾸는가 |
| 수정 방향 | 교정이 한쪽으로만 흐르는가 |
| 질문 발생 | 누가 더 묻는가 |

지분이 7대 3을 넘거나 수정이 한 방향으로만 흐르면
지배-수동형 신호로 보고 매뉴얼의 교정 절차를 적용한다.

**대응 3: 침묵을 손해로 규정하지 않는다**
침묵하고 있다고 해서 학습이 없는 것은 아니며 내적 발화로
언어화하고 있을 수 있다는 연구가 있다. 또한 LRE의 양보다
질이 학습에 영향을 준다.
따라서 "말수가 적으면 손해"라는 전제를 어떤 제작물에도 넣지 않는다.

## 3. 측정 규격 (v1에서 전면 교체)

### 3.1 주 지표: LRE

LRE는 학습자가 자기가 산출하는 언어에 대해 이야기하거나,
언어 사용에 의문을 제기하거나, 스스로 또는 서로를 교정하는
대화의 부분을 말한다.

v1의 "누적 산출량"을 이 지표로 교체한다.
산출량은 셀 수는 있으나 학습과의 연결이 약하다.
LRE는 2인 학습에서만 발생하며, 대조 교차 블록이 정확히 이것을
생성하도록 설계돼 있어 지표로 바로 쓸 수 있다.

### 3.2 기록 항목

| 항목 | 단위 | 주기 |
|---|---|---|
| LRE 발생 횟수 | 회 | 매 세션 |
| LRE 해결 여부 | 해결/미해결/보류 | 매 세션 |
| 미해결 LRE 목록 | 문장 | 매 세션 |
| 발화 시간 | 분 | 매일 |
| 드릴 소화량 | 장 | 매일 |
| 수행 여부 | 정상/비상판/결석 | 매일 |
| 관계 유형 점검 | 4항목 | 분기 |
| 통과 조건 대조 | 트랙별 | 분기 |

미해결 LRE 목록이 중요하다. 이것이 나에게 가져올 질문 목록이 되고,
역방향 판정 루프의 입력이 된다.

### 3.3 측정 주기

성과 측정은 분기 1회만 한다.
주 단위로 재면 노이즈에 흔들려 좌절한다.
LRE 횟수만 매 세션 기록하되, 이것은 성과 측정이 아니라
활동량 기록으로 취급한다.

## 4. 주제 규격 (신설)

### 4.1 3축 관리

| 축 | 수 | 역할 |
|---|---|---|
| 영역 | 12 | 무엇에 대해 말하는가 |
| 관계 | 6 | 누구에게 말하는가 |
| 기능 | 10 | 무엇을 하려고 말하는가 |

영역만 늘리면 어휘만 는다. 실력은 관계 x 기능 조합에서 갈린다.
같은 거절도 상사에게와 친구에게가 다르고, 그 차이가 상급의 관문이다.

### 4.2 12영역 (학습자 실사용 기준, 80대 20)

핵심 8 (사용 확률 높음)
일상과 집 / 음식 / 게임과 놀이 / 관계와 사람 /
일과 가르침 / 돈과 계획 / 판단과 생각 / 실용 처리

확장 4 (확률 무관, 폭 확보용)
몸과 건강 / 사회와 뉴스 / 문화 / 이동과 장소

확장 4를 빼면 익숙한 얘기만 유창한 사람이 되고, 그 상태는
2년차 확장이 막힌다. 20%는 비효율이 아니라 보험이다.

### 4.3 6관계

배우자와 가족 / 친한 친구 / 동료 / 상사와 권위 /
서비스 상황 / 처음 만난 사람

### 4.4 10기능

요청 / 거절 / 제안 / 불동의 / 사과 /
불평 / 칭찬 / 설명 / 협상 / 잡담

### 4.5 추상도와 언어 난이도의 분리 (v2 핵심 원칙)

일반 커리큘럼은 추상 주제를 상급으로 미룬다.
이 학습자에게는 그 설계가 맞지 않는다. 실제 대화 주제가
게임, 교육, 투자, 철학으로 추상도가 높기 때문이다.
초급 주제만 1년을 주면 반드시 이탈한다.

두 축은 묶을 이유가 없다. 어휘는 초급, 사고는 성인으로 간다.

각 영역이 재등장할 때 언어는 그대로 두고 추상도만 올린다.

| 회차 | 예시 (게임 영역) | 언어 |
|---|---|---|
| 1 | 어제 뭐 했는지 | A1 |
| 2 | 왜 이 종족을 고르는지 | A2 |
| 3 | 이길 때와 질 때 뭐가 다른지 | A2+ |
| 4 | 실력과 운을 어떻게 구분하는지 | B1 |

4회차는 사실상 인식론 대화지만 문장은 여전히 단순하다.

### 4.6 잡담의 배치 역전

잡담은 쉬워 보이나 실제로는 가장 어렵다.
속도가 빠르고 관용구 밀도가 높으며 문화 코드가 많이 걸린다.
깊은 대화는 느리게 말해도 되고 논리로 밀 수 있다.

따라서 깊은 대화를 먼저 트고 잡담을 Q4 주력으로 보낸다.
직관과 반대 순서이나 이 학습자에게는 이쪽이 맞다.

### 4.7 회전 대장

제작 중 어떤 영역 x 관계 x 기능 조합을 썼는지 표로 관리한다.
관리하지 않으면 익숙한 조합(일상 x 친구 x 잡담)에 몰린다.
제작자 편향이므로 의식적으로 막아야 한다.

각 영역은 도입 후 최소 4회 재등장하며, 매번 다른 관계와 기능에 붙는다.

## 5. 검증 프로토콜 (신설)

### 5.1 도입 근거

코퍼스 대조 연구에서 한 교재의 동의 표현 54개 중
실제 언어 사용에 나타난 것은 7개뿐이었고, 그 원인으로
실제 데이터가 아닌 집필자의 직관에 의존한 개발이 지목됐다.

내가 정확히 그 실패 모드다. 슬랭만이 아니라 평범한 표현의
빈도 감각도 신뢰할 수 없다.

### 5.2 B등급 항목 검증 절차

B등급 항목을 포함한 제작물은 다음을 거친다.

1. 초안 작성
2. 핵심 표현 목록 추출 (제작물당 10개 이내)
3. 웹 검색으로 현행 사용 여부 확인
4. 확인 실패 항목은 삭제하거나 A등급 대체 표현으로 교체
5. 검증 로그를 제작물 하단에 기록

검증 로그 양식:
```
검증일 / 항목 / 결과 / 조치
```

### 5.3 역방향 판정 루프

학습자가 외부 자료에서 채집한 표현을 나에게 가져와 판정받는다.
이것이 이 과정의 주된 품질 보증 장치다. 생성보다 판정이 정확하다.

주 1회 판정 세션을 고정한다. 입력은 다음 둘이다.
- 미해결 LRE 목록 (3.2)
- 채집 표현 목록 (입력 조준표 지시)

판정 결과는 진행 대장에 기록하고, 반복 등장하는 오해는
다음 분기 제작에 반영한다.

## 6. 대화 스크립트 3층 구조 (신설)

### 6.1 층 구분

| 층 | 출처 | 표기 | 용도 |
|---|---|---|---|
| 1층 기능 대화 | 내가 작성 | "학습용 인공물" 명시 | 목표 형식 집중 노출 |
| 2층 실제 발화 | 외부 채집 | 출처 기록 | 실제 양상 관찰 |
| 3층 대조판 | 1층과 2층 병치 | 차이 표시 | 인공성 인식 |

### 6.2 1층 규칙

- 반드시 상단에 학습용으로 만들어진 문장이라는 표기를 넣는다.
  이 표기를 빼면 학습자가 이것을 실제 영어로 오인한다.
- 문법 항목을 억지로 넣기 위해 문장을 비틀지 않는다.
- 3레지스터 대조판을 기본으로 한다. 같은 내용을 격식/중립/친근으로.

### 6.3 2층 규칙

- 내가 창작하지 않는다. 조준표가 채집 조건만 지정한다.
- 관찰 대상은 의미가 아니라 양상이다.
  누가 먼저 말하는가, 어디서 끊기는가, 어떻게 고쳐 말하는가.
- 채집물은 학습자가 가져오고 내가 판정한다.

### 6.4 3층 규칙

- 1층과 2층을 나란히 놓고 무엇이 다른지 학습자가 찾게 한다.
- 정답을 먼저 주지 않는다. 차이를 발견하는 것이 과제다.
- Q2부터 도입한다. Q1에는 비교할 언어 자산이 없다.

## 8. 페어 드릴 카드 규격

### 8.1 총량과 배분

600장.

| 분기 | 장수 | 판정형 | 압박형 | 확장형 | 역할형 | repair형 |
|---|---|---|---|---|---|---|
| Q1 | 150 | 75 | 25 | 20 | 10 | 20 |
| Q2 | 150 | 35 | 40 | 40 | 15 | 20 |
| Q3 | 150 | 20 | 45 | 35 | 25 | 25 |
| Q4 | 150 | 10 | 25 | 30 | 55 | 30 |

### 8.2 물리 규격

앞면 A 지시, 뒷면 B 지시. 한 장을 양쪽에서 본다.
B가 정답을 미리 보면 판정이 무의미해지므로 이 형태를 강제한다.

각 면 구성:
```
[번호] [유형] [분기] [소요시간] [신뢰도]

지시문 (2문장 이내)
재료
성공 기준 (1문장)
```

지시문 3문장 초과 금지. 실행 중 읽는 데 시간이 간다.

### 8.3 유형별 규칙

**판정형** : A 발화, B 복원. Q1 주력. 음성 자료 부재를 상대의 귀로 대체한다.
정답은 A 면에만 둔다.

**압박형** : 제한 시간 숫자 명시. Q2는 5초, Q3은 3초, Q4는 2초.
A는 예측 불가능한 순서로 던진다. 정확성보다 속도 우선을 카드에 명시.

**확장형** : 변형 축 명시(시제, 레지스터, 극성, 관점).
모범 답안을 A 면에 두되 유일 정답이 아님을 명시.

**역할형** : 상황, 관계, 목적, 레지스터 네 요소 필수. 종료 조건 필수.

**repair형** (신설) : 의도적으로 대화를 무너뜨리고 복구하게 한다.
A가 일부러 빠르게 말하거나, 모르는 단어를 섞거나, 중간에 끊는다.
B는 복구 전략으로 대응한다.
이 유형만 유일하게 "실패가 정상"이라고 카드에 명시한다.

## 9. 대조 교차 세트 규격

### 9.1 총량

288세트. 세트당 30분.

### 9.2 구조

```
[번호] [대응 강의] [분기]

1단계 A 설명 (8분)
   설명 대상, 필수 포함 요소 3개

2단계 B 재구성 (8분)
   예시 추가 / 반례 제시 / 상황 적용 / 요약 압축 중 하나

3단계 상호 검토 (10분)
   합의 지점과 불일치 지점 각 1개 이상

4단계 기록 (4분)
   LRE 횟수, 미해결 항목 기록
```

### 9.3 규칙

- 2단계 지시는 1단계와 다른 인지 작업이어야 한다.
  같은 것을 반복하면 B에게 학습이 없다.
- 3단계에서 "틀렸다"를 쓰지 않는다. "나는 이렇게 이해했다" 형식만.
  이 규칙은 매 세트 하단에 인쇄한다.
- 4단계의 미해결 항목이 주간 판정 세션의 입력이 된다.

## 10. 입력 조준표 규격

### 10.1 존재 이유

음성을 생성할 수 없으므로 재료는 외부에서 온다.
조준표는 재료가 아니라 재료를 겨누는 방법이다.
주목 없는 입력은 통과할 뿐이므로 매 회차 찾을 대상을 지정한다.

### 10.2 구성 (분기별 1권)

| 항목 | 내용 |
|---|---|
| 재료 조건 | 길이, 속도, 화자 수, 주제 범위 |
| 대체 재료 유형 | 조건 충족 유형 5종 이상 |
| 회차별 청취 과제 | 무엇을 찾으며 들을지 |
| 채집 지시 | 무엇을 적어 와서 판정받을지 |
| 반복 횟수 | 같은 자료를 몇 회 |
| 상호 확인 절차 | 2인이 서로 확인하는 방법 |

### 10.3 규칙

- 과제는 항상 단일 초점. 한 번에 두 가지를 찾게 하지 않는다.
- Q1 과제는 의미가 아니라 소리를 향한다.
  "무슨 말인지" 대신 "어디가 줄었는지".
- 같은 자료를 최소 3회. 회차마다 초점 변경.
  1회 소리, 2회 청크, 3회 의미.
- 채집 지시는 2층 대화 자료 확보를 겸한다. 특히 중단과 수정 양상.

## 11. 나머지 산출물 규격

### 11.1 산출 과제집

48주분. 주 1개. 2인 공동 산출.
분량 Q1 100자에서 Q4 600자로 증가.
교정 요청 프롬프트를 미리 써 둔다. 매번 설명을 다시 하지 않기 위함.
각자 쓰고 합치는 형태가 아니라 한 문장씩 번갈아 만드는 형태가 기본.

### 11.2 비상판

60개. 각 15분. 1인 수행 가능. 이 과정 유일한 1인 예외.
인출 10분 + 청크 5분. 신규 학습 없음.
쓴 날도 수행일로 계산한다. 이것이 이 장치의 전부다.
연속 2일 사용 시 경고, 3일이면 주간 점검에서 원인 기록.

2인 전용 설계의 최대 위험은 결석의 동기화다.
한 사람이 야근하면 둘 다 0이 된다. 비상판은 이 구멍만 막는다.

### 11.3 진행 대장

3장 측정 규격을 따른다.

### 11.4 운영 매뉴얼

필수 수록:
1. 12개월간 방법론 변경 금지 (1항)
2. 1년 목표의 정직한 명시
3. 두 번 연속 결석 금지
4. 실행 의도 확정 양식 (시간, 장소, 첫 동작)
5. 금지 목록 (13장)
6. 세션 규칙 카드 (벽에 붙이는 1장)
7. 관계 유형 점검 절차와 교정 방법
8. 실패 지점 3곳과 대응 (12장)

1항이 변경 금지인 이유:
학습자 두 사람 모두 구조 재설계에 흥미를 갖는 성향이다.
6개월차에 방법론 재검토 충동이 온다.
커리큘럼 재설계에 재미를 붙이면 학습은 그 시점에 멈춘다.
이 조항은 학습 규칙이 아니라 이탈 방지 장치다.
