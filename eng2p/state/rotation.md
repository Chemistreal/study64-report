# 2인 전용 영어 1년 과정 · 회전 대장

신뢰도: A 생성 (커리큘럼 설계와 순서)
상위 규격: docs/spec.md 4장
용도: 제작자 전용. 학습자는 보지 않아도 된다.

이 대장의 목적은 하나다. 제작자 편향을 막는 것이다.
관리하지 않으면 익숙한 조합(일상 x 친구 x 잡담)에 몰린다.
몰리면 학습자는 익숙한 얘기만 유창한 사람이 되고, 2년차 확장이 막힌다.

기준서 17장 절차의 3번과 8번이 이 파일을 연다.
제작 전에 편중을 확인하고, 제작 후에 조합을 기록한다.

## 2. 배치 원칙

### 2.1 잡담은 뒤로, 깊은 대화는 앞으로

잡담(F10)은 쉬워 보이나 실제로는 가장 어렵다.
속도가 빠르고 관용구 밀도가 높고 문화 코드가 많이 걸린다.
깊은 대화는 느리게 말해도 되고 논리로 밀 수 있다.

그래서 F10은 Q4 주력이다. 직관과 반대지만 이 순서가 맞다.
같은 이유로 R6(처음 만난 사람)도 뒤로 간다.
`D__-R6-F10`은 이 과정 최난도 조합이고 Q4에만 쓴다.

### 2.2 분기별 허용 관계

| 분기 | 새로 여는 관계 | 누적 사용 가능 |
|---|---|---|
| Q1 | R1, R5 | R1 R5 |
| Q2 | R3, R2 | R1 R2 R3 R5 |
| Q3 | R4 | R1 R2 R3 R4 R5 |
| Q4 | R6 | 전부 |

R5(서비스 상황)를 Q1에 넣는 이유는 대화가 정형적이기 때문이다.
말의 순서가 거의 정해져 있어서 제로 시작이 붙을 데가 있다.
R2(친한 친구)를 Q1에 안 넣는 이유는 그 반대다. 정형이 없다.

### 2.3 분기별 허용 기능

| 분기 | 새로 여는 기능 | 누적 사용 가능 |
|---|---|---|
| Q1 | F01, F08, F05 | F01 F05 F08 |
| Q2 | F03, F06, F07 | F01 F03 F05 F06 F07 F08 |
| Q3 | F02, F04 | F10 제외 전부 |
| Q4 | F09, F10 | 전부 |

F02(거절)와 F04(불동의)를 Q3까지 미룬다.
둘 다 레지스터를 못 맞추면 관계를 상하게 하는 기능이라서다.
3레지스터 구분이 서기 전에는 쓰지 않는다.

### 2.4 추상도는 언어 난이도와 따로 간다

일반 커리큘럼은 추상 주제를 상급으로 미룬다. 여기서는 아니다.
어휘는 초급으로 두고 사고는 성인으로 간다.
초급 주제만 1년을 주면 이 학습자는 반드시 이탈한다.

각 영역이 재등장할 때 언어는 그대로 두고 추상도만 올린다.
아래 사다리를 제작 시 그대로 쓴다.

| 영역 | 1회차 (A1) | 2회차 (A2) | 3회차 (A2+) | 4회차 (B1) |
|---|---|---|---|---|
| D01 | 오늘 집에서 뭘 했는지 | 집안일을 어떻게 나누는지 | 집이 편할 때와 답답할 때가 뭐가 다른지 | 사는 공간이 습관을 얼마나 바꾸는지 |
| D02 | 어제 뭘 먹었는지 | 이 음식을 왜 좋아하는지 | 만든 것과 사 먹는 것의 차이 | 입맛이 기억과 어떻게 붙어 있는지 |
| D03 | 어제 뭐 했는지 | 왜 이 종족을 고르는지 | 이길 때와 질 때 뭐가 다른지 | 실력과 운을 어떻게 구분하는지 |
| D04 | 오늘 누구를 만났는지 | 어떤 사람이 편한지 | 친한 사이와 편한 사이의 차이 | 오래 가는 관계에 뭐가 있어야 하는지 |
| D05 | 오늘 무슨 일을 했는지 | 이 일을 어떻게 배웠는지 | 가르쳐서 되는 것과 안 되는 것 | 잘 가르친다는 게 뭘 뜻하는지 |
| D06 | 오늘 뭘 샀는지 | 무엇에 돈을 안 아끼는지 | 지금 쓰는 것과 나중에 쓰는 것의 차이 | 위험을 어디까지 감수할지 어떻게 정하는지 |
| D07 | 오늘 뭘 정했는지 | 왜 그렇게 정했는지 | 빨리 정할 때와 오래 볼 때의 차이 | 확신과 근거를 어떻게 구분하는지 |
| D08 | 뭐가 고장 났는지 | 어떻게 고쳤는지 | 직접 하는 것과 맡기는 것의 차이 | 문제를 어디까지 파고들지 어떻게 정하는지 |
| D09 | 어디가 아픈지 | 뭘 하면 나아지는지 | 몸이 괜찮을 때와 아닐 때 하루의 차이 | 건강을 관리한다는 말이 뭘 뜻하는지 |
| D10 | 오늘 무슨 소식을 봤는지 | 그 소식이 왜 눈에 띄었는지 | 같은 일을 두 곳이 다르게 전할 때의 차이 | 무엇을 믿을지 어떻게 고르는지 |
| D11 | 뭘 보고 뭘 들었는지 | 왜 그게 좋았는지 | 좋아하는 것과 잘 만든 것의 차이 | 취향이 어디서 오는지 |
| D12 | 오늘 어디에 갔는지 | 거기까지 어떻게 갔는지 | 익숙한 길과 처음 가는 길의 차이 | 낯선 곳에서 방향을 어떻게 잡는지 |

4회차는 전부 사실상 추상 대화지만 문장은 여전히 단순하다.
문장을 어렵게 만들지 마라. 주제만 올린다.

### 2.5 등장 횟수 규칙

기준서 4.7은 "도입 후 최소 4회 재등장"이라고 쓴다.
그런데 2.4의 사다리는 4단계다. 운용상 다음으로 읽는다.

- 영역당 최소 등장 5회 = 도입 1회 + 재등장 4회
- 추상도 사다리는 1회차부터 4회차까지 붙는다
- 5회차 이상 등장하면 추상도는 4단계에 두고 관계와 기능만 바꾼다
- 재등장할 때마다 관계와 기능 중 최소 하나는 반드시 달라진다

이 해석은 기준서 개정 사항이다. 기준서를 고치기 전까지 임시로 이 규칙을 쓴다.

## 3. 조합 등록부

제작물 하나를 끝낼 때마다 한 줄 추가한다.
기준서 17장 8번이 이 표를 갱신하는 절차다.

```
제작물 ID | 분기 | 종류 | 영역 | 관계 | 기능 | 회차 | 등록일
----------|------|------|------|------|------|------|--------
          |      |      |      |      |      |      |

종류 : 강의 / 카드 / 세트 / 조준표 / 과제
회차 : 그 영역의 몇 번째 등장인가 (1~4는 사다리 단계와 같음)
```

### 3.0 소리 트랙 강의는 등록하지 않는다

조합은 무엇에 대해 어떤 관계에서 무엇을 하려고 말하는가를 관리하는 축이다.
소리 트랙 강의는 그 축을 쓰지 않는다. 음운 현상을 다루지 주제를 다루지 않는다.

Q1 강의 24편 중 15편이 소리 트랙이다. 이 15편은 등록 대상이 아니다.
빈칸을 채우려고 억지로 조합을 붙이면 대장이 거짓말을 하게 된다.

조합이 실제로 발생하는 곳은 셋이다.
화용 트랙 강의, 역할형 카드, 대조 교차 세트의 상황 지정.
Q1에서 등록될 항목은 화용 2편과 역할형 카드 10장과 세트의 역할 상황이다.

### 3.1 현재 등록 내역

3.0에 따라 등록 대상이 아니다. 청크와 repair 트랙도 주제 축을 쓰지 않는다.
덩어리 목록과 대화 복구 절차를 다루지 무엇에 대해 말할지를 정하지 않기 때문이다.

역할형 10장이 T10에서 등록됐다. 카드 132는 l020의 조합과 같고 카드 149는 l024와 같다.
두 강의가 그 카드를 대표 자리로 쓰기 때문이다. 같은 조합이 두 번 쓰인 것이 아니라
같은 자리를 강의와 카드가 나눠 적은 것이다. 그래서 4.4 중복 목록에는 여덟 줄만 는다.

그것을 20강에서야 배우기 때문이다. Q1에서는 이 배치 말고는 방법이 없다.

역할형 카드 132가 그 자리를 쓴다. 상황은 물건을 빌리는 자리, 관계는 서비스 상황,
목적은 요청, 레지스터는 중립, 종료 조건은 상대가 답을 하면 끝이다.

D01을 1회차로 여는 이유는 2.4 사다리의 A1 칸이 집과 일상이기 때문이다.
제로 시작의 첫 화용 강의를 확장 영역에서 열면 어휘 부담이 두 배가 된다.

l024는 Q1 마지막 강이고 화용 두 번째다. 대화를 여닫는 법을 다룬다.
역할형 카드 149가 대표 자리다. 처음 가는 가게에서 길을 묻고 닫기까지 한다.
영역을 D12로 잡은 것은 5장의 확장 영역 부족 경보 때문이다.
l020 하나만 있으면 확장 4 합계가 0이다. D12를 넣어 두 건 중 하나로 만들었다.

Q1 화용 두 편이 관계는 둘 다 R5이고 기능도 둘 다 F01이다.
2.2가 Q1에 R1과 R5만 열고 2.3이 F01, F05, F08만 열기 때문에 폭이 좁다.
Q1 단위로는 편중을 판정하지 않는다. 4.3 아래에 적어 둔 대로 균등선은 48주 기준이다.

### 4.4 조합 중복 감시

같은 `D__-R_-F__` 조합은 전 과정에서 한 번만 쓴다.
두 번째로 쓰려고 하면 관계나 기능을 바꾼다.

이미 쓴 조합 목록:
```
D01-R5-F01   eng2p_q1_l020 / 카드 132   2026-08-07

D06-R5-F01   카드 146   2026-08-07

D04-R1-F01   카드 148   2026-08-07
D09-R5-F08   카드 150   2026-08-07
```

열 조합이 다 다르다. 영역은 열 개가 서로 다르고 관계는 R1과 R5 둘, 기능은 F01과 F08 둘이다.
Q1이 R1과 R5, F01과 F05와 F08만 열어 두어서 관계와 기능 축이 좁다.
Q2에서 R3과 R2와 F03과 F06과 F07이 열리면 조합이 넓어진다.

F05(사과)는 Q1에 열려 있는데 한 번도 안 썼다.
Q1 강의에 사과를 다루는 편이 없어서 붙일 자리가 없었다.
Q2 역할형에서 F05를 먼저 쓴다.

5장의 관계 편중과 기능 편중 경보에 R5(58%)와 F01(58%)이 걸린다.
Q1이 두 관계와 세 기능만 열어 두었으므로 구조적으로 피할 수 없다.
4.3 아래에 적은 대로 균등선은 48주 기준이고 분기 단위로는 판정하지 않는다.
다만 Q2 제작 전에 이 숫자를 먼저 보고 R3과 R2 쪽으로 몰아 준다.
