| 소리 | 15 |

## 4. B등급 검증 대기

state/verify_queue.md 가 자동 생성한다. `python3 scripts/collect_b.py` 로 갱신한다.
현재 대기 0건. 단계 1 산출물은 전부 A등급이다.

검증은 Claude Code에서 하지 않는다. 대화 세션에서 웹 검색으로 한다.
대량 생성 중에는 검증을 건너뛰기 쉽고, 그럴듯한 표현이 그대로 통과한다.

### 완료된 검증

english.html 소리 탭의 축약 20종 목록. 신뢰도 B.

```
검증일 2026-08-07 / 축약 20종 목록 / 결과 통과 / 조치 목록 유지
```

- 대상: gonna, wanna, gotta, hafta, hasta, oughta, kinda, sorta, lotta, outta,
  gimme, lemme, dunno, cuz, whatcha, wouldya, couldya, shoulda, woulda, coulda
- 확인한 것: 20종 모두 ESL 청취 교육에서 표준으로 다루는 reduced forms 다.
  슬랭이나 유행어가 아니라 규칙적인 약형이라 13.2 슬랭 금지에 걸리지 않는다.
  원어민은 약형을 대부분의 발화에서 쓰고, 교사는 강형으로 말하는 경향이 있어
  학습자가 실제 발화를 못 알아듣는 원인이 된다는 지적이 있다.
- 확인한 것 둘: 약형은 산출이 아니라 청취 이해를 위해 가르치라는 것이 정설이다.
  이 과정 Q1 통과 조건이 "축약 20종 청취 식별"인 것과 방향이 같다.
  학습자에게 약형을 말하라고 시키지 않는다.
- 남은 불확실: 철자 표기가 자료마다 갈린다. wouldya/wouldja, couldya/couldja,
  cuz/'cause 가 그렇다. 그래서 B등급을 유지한다. 강의에 실을 때 다시 검증한다.
- 출처:
  - https://www.proofreadingservices.com/blogs/esl/15345345-cheat-sheet-25-reduced-forms-you-need-to-know
  - https://commonsense-esl.com/2020/09/01/teach-reduced-forms-for-comprehension-not-for-speaking/
  - https://www.learnenglishsounds.com/en/blog/gonna-wanna-hafta-gotta-reductions-rule-connected-speech

### GPT 미디어 라이브러리 판정 (PR #2)

VOA Let's Learn English Level 1 52과가 media/english/ 로 들어왔다.
audio_intake.md 규격으로 판정한 결과는 다음과 같다.

| 항목 | 판정 |
|---|---|
| 등급 | **C-real.** 사람이 실제로 말한 것의 녹음이다. 생성 음성이 아니다 |
| 라이선스 | VOA 자체 제작 Learning English 자료는 퍼블릭 도메인. catalog.json 에 출처와 약관 URL, 확인일이 있다 |
| 저장소 반입 | 가능. audio_intake.md 8장은 저작권 있는 자료가 섞이는 것을 막으려는 조항이라 퍼블릭 도메인에는 걸리지 않는다 |
| 대본 동반 | `media/english/transcripts/`에 52개 모두 저장. C-real 메타와 원문 출처를 포함하고 `check.py`를 통과한다 |
| Q1 소리 트랙 통과 판정 | **쓸 수 있다.** C-real 이므로 5장 제한에 걸리지 않는다 |
| 2층 자료 | 못 쓴다. 대본 있는 학습용 대화라 겹침과 중단이 없다 |

이 판정이 실질적인 진전이다. 지금까지 Q1 통과 조건인
"축약 20종 청취 식별 90%"를 잴 실제 음성이 없었는데 생겼다.

조치
- 미디어 탭 등급 표기를 "C 조준 자료"에서 C-real 로 고치고
  Q1 통과 판정에 쓸 수 있다는 것과 2층은 못 된다는 것을 같이 적었다
- 라이브러리와 클립 도구를 연결했다. 레슨을 클립으로 보내면
  구간 반복과 대본 동기화가 그대로 걸린다
- 이로써 파이프라인이 하나로 돈다.
  레슨 -> 구간 반복 -> 들린 표현 채집 -> 주간 판정 -> 간격 반복 복습

남은 것
- catalog 의 focus 는 52과 전체에 붙어 있으나 기준서 10.3의
  "같은 자료를 최소 3회, 회차마다 초점 변경"과는 아직 연결되지 않았다
- 대본 형식 검사는 52개 모두 통과했다. 다만 17개는 해당 분기 화자 수 상한을
  넘는다는 경고가 있으므로 2인 세션에는 무경고 자료 또는 1~2인 발췌 구간을 쓴다

### 클립을 저장소에 담지 않는 이유 (사실 확인)

사용자가 "개인 공부용이니 클립을 담아도 되고 서버에 비번을 걸면 된다"고 했다.
확인해 보니 이 구성에는 적용되지 않는다.

- `https://chemistreal.github.io/study64-report/english.html` 이 HTTP 200 으로 응답한다.
  사이트는 이미 공개 상태다.
- GitHub Pages 에는 비밀번호 기능이 없다. 저장소를 private 으로 돌리면
  Enterprise 가 아닌 이상 Pages 자체가 배포되지 않는다.
- 따라서 클립을 저장소에 넣는 것은 사적 보관이 아니라 공개 배포가 된다.
- Santa Barbara Corpus 는 CC BY-ND 라 가공 자체가 금지다.

대응: 저장소에 담는 대신 english.html 에 로컬 클립 도구를 넣었다.
파일은 objectURL 로만 다루고 업로드하지 않는다.
저장되는 것은 파일 이름, 시작과 끝 시각, 라벨, 메모뿐이다.
개인 기기 안에서만 도는 구조라 배포 문제가 발생하지 않는다.

퍼블릭 도메인인 VOA 와 LibriVox 음원은 저장소에 담아도 법적 문제가 없다.
다만 archive.org metadata 엔드포인트가 이 환경의 프록시 뒤에서 열리지 않아
자동 수집은 보류했다. 필요하면 파일 목록과 용량을 먼저 뽑고 결정한다.

BY-ND 는 가공 금지다. 자르거나 편집해서 재배포하지 않는다.
저작권 있는 팟캐스트와 영상 클립을 잘라 저장소에 담는 것은 하지 않는다.
이 저장소는 GitHub Pages 로 공개 배포되므로 그대로 침해가 된다.
기준서 1.2가 음성 자료를 C등급으로 둔 것과 결론이 같다. 링크로 겨누고 재생은 원본에서 한다.

확인 안 한 후보: Mozilla Common Voice, Tatoeba, Internet Archive 개별 항목.
항목마다 라이선스가 달라서 쓰기 전에 그 페이지를 직접 읽어야 한다.
