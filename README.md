# PRISM · 학습 성향 진단 (study64-report)

**제작·진단·상담: 다원교육 영재관 조준모T**

12극·96문항 자기보고식 학습 성향 진단. 영재고·전국자사고·과학고·메디컬 입시를
준비하는 초중등 영재 학생 대상. 단일 HTML 파일로 돌고 서버·설치가 필요 없다.

> 이 파일은 **저장소의 지금 모습**을 적는다. 2026-08-10 이전 판은 "업로드 파일
> 목록 (총 15개)" 를 적고 있었는데 그 가운데 **아홉이 이 저장소에 없었고**
> (`prism_apps_script.gs` · `PRISM_설문지_OMR.pdf` · `기준선_검토용.md` ·
> `12극해설_01~06.md`), 거꾸로 **저장소에 있는 열하나가 한 줄도 안 적혀**
> 있었다(`report.html` · `answers.html` · `english.html` · `v2.html` ·
> `관리자.html` · `eng2p/` · `media/` · `scripts/` · `tools/` 등).

### 진단 구조

6개 축 × 2극 = 12극, 극마다 8문항 = 96문항. 극 점수 = (그 8문항 응답 평균)
÷ 5 × 100.

| 축 | 두 극 |
|---|---|
| 이해 방식 | 심층이해 / 반복숙달 |
| 실행 방식 | 계획실행 / 상황반응 |
| 학습 구조 | 자기주도 / 외부구조 |
| 막힘 처리 | 질문·확인 / 자기해결 |
| 오류 처리 | 완성추구 / 시행착오 |
| 지속 동기 | 미래목표 / 즉시피드백 |

## 돌리는 법

```bash
npm install --no-save jsdom
node prism_regression.js                 # 회귀 75개 (기본: 이 저장소의 index.html)
python3 tools/audit_pages.py --check     # 화면 전수 검수
```

**바깥 CSS·JS 파일로 빼지 않는다.** 바깥 stylesheet 를 만나면 브라우저는
그리기를 멈추고 기다린다. 같은 조각을 화면마다 안에 박아 넣고, 갈라지지 않게
자로 잰다.

> ⚠ `prism_regression.js` 는 **아무도 안 돌리고 있었다**(2026-08-10 에 걸었다).
> 파일은 2026-06 부터 있었는데 CI 가 부른 적이 없고, 기본 경로도 산출물을 zip
> 으로 내보내던 시절의 `/mnt/user-data/outputs/index.html` 이라 저장소에서
> 인자 없이 돌리면 '파일 없음' 이었다. 걸어 놓고 보니 **75개 전부 통과**한다.

## 아직 안 한 것

**입력칸 이름은 다 달았다**(2026-08-10). 106칸 가운데 73칸은 자가 이어 주었고,
남은 33칸은 무엇을 넣는 칸인지 화면을 보고 손으로 달았다 — 발화 시간(분) ·
드릴 소화량(장) · A 시각(초) · 응답 원본(b64) 처럼. 이제 125칸 전부에 이름이
있고 `--check` 를 CI 에 걸었다.

**`tools/theme.py` 는 안 들여왔다.** exam·DT·KMChC 는 이 자로 팔레트를 한 벌로
모으는데, PRISM 은 자기 옷(크림 바탕·세리프)을 따로 입고 있다. 기계가 남의
팔레트를 덮어씌우면 학부모가 보는 화면이 통째로 달라진다 — **선생님이 정할
칸이다.**
